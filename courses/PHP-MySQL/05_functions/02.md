# پارامترها، مقادیر پیش‌فرض، انواع داده و دستور return

## ۱. پارامترهای اجباری و اختیاری

در تعریف تابع، پارامترها می‌توانند دو حالت داشته باشند:

- **پارامتر اجباری (Required):** هنگام فراخوانی، حتماً باید برای آن آرگومان پاس شود؛ در غیر این صورت PHP خطا می‌دهد.
- **پارامتر اختیاری (Optional):** برای آن مقدار پیش‌فرض تعیین شده است؛ اگر هنگام فراخوانی آرگومانی پاس نشود، مقدار پیش‌فرض به کار می‌رود.

```php
<?php
function greet($name, $greeting = "Hello") {
    return $greeting . ", " . $name;
}

echo greet("Ali");            // Hello, Ali
echo "<br>";
echo greet("Sara", "Hi");     // Hi, Sara
?>
```

در تابع بالا، `$name` اجباری و `$greeting` اختیاری است؛ زیرا برای آن مقدار پیش‌فرض `"Hello"` تعیین شده است.

---

## ۲. مقدار پیش‌فرض پارامترها (Default Values)

### قاعدهٔ ترتیب پارامترها

پارامترهای دارای مقدار پیش‌فرض باید **بعد از** پارامترهای اجباری نوشته شوند. رعایت نکردن این قاعده باعث خطای نحوی (Syntax Error) می‌شود.

```php
<?php
// صحیح
function f1($a, $b = 2) { }

// نادرست — خطای نحوی
// function f2($a = 1, $b) { }
?>
```

> **نکته:** مقدار پیش‌فرض باید یک مقدار **ثابت (Constant Expression)** باشد؛ یعنی عدد، رشته، `true`/`false`، `null` یا آرایهٔ ثابت. استفاده از متغیر یا فراخوانی تابع به‌عنوان مقدار پیش‌فرض مجاز نیست.

```php
<?php
function showMessage($text = "No message") {
    echo $text;
}

showMessage();          // No message
echo "<br>";
showMessage("Welcome"); // Welcome
?>
```

## ۳. تعیین نوع داده برای پارامترها (Parameter Type Declaration)

از PHP 7 به بعد می‌توان نوع دادهٔ مورد انتظار برای هر پارامتر را در تعریف تابع مشخص کرد. این کار باعث می‌شود تابع فقط ورودی‌های صحیح بپذیرد و کد خواناتر و مطمئن‌تر شود.

**انواع قابل استفاده برای پارامترها:**

| نوع | توضیح |
|------|--------|
| `int` | عدد صحیح |
| `float` | عدد اعشاری |
| `string` | رشته |
| `bool` | مقدار درست/غلط |
| `array` | آرایه |
| `object` | شیء |
| `callable` | تابع قابل فراخوانی |
| `?type` | نوع nullable (می‌تواند `null` هم باشد) |

```php
<?php
function checkGrade(int $score): string {
    if ($score >= 10) {
        return "Passed";
    }
    return "Failed";
}

echo checkGrade(15);   // Passed
echo "<br>";
echo checkGrade(8);    // Failed
?>
```

> **توجه:** بدون فعال‌سازی حالت سخت‌گیرانه (که در بخش ۶ توضیح داده می‌شود)، اگر نوع آرگومان با نوع پارامتر هم‌خوان نباشد، PHP تلاش می‌کند آن را **تبدیل نوع (Type Juggling)** کند. مثلاً رشتهٔ `"15"` به عدد `15` تبدیل می‌شود.

## ۴. تعیین نوع مقدار بازگشتی (Return Type Declaration)

می‌توان نوع مقدار بازگشتی تابع را نیز پس از پرانتز پارامترها و با علامت `:` مشخص کرد.

```php
<?php
function addNumbers(int $a, int $b): int {
    return $a + $b;
}

function getAverage(float $a, float $b): float {
    return ($a + $b) / 2;
}

echo addNumbers(3, 4);        // 7
echo "<br>";
echo getAverage(10, 15);      // 12.5
?>
```

**انواع مهم برای مقدار بازگشتی:**

- `: int`، `: float`، `: string`، `: bool`، `: array`
- `: void` — تابع هیچ مقداری بازنمی‌گرداند (فقط دستورات را اجرا می‌کند).
- `: ?string` — تابع یا رشته برمی‌گرداند یا `null`.
- `: mixed` — هر نوعی مجاز است (PHP 8 به بعد).

```php
<?php
function printTitle(string $title): void {
    echo "<h2>" . $title . "</h2>";
}

printTitle("Student Report");
?>
```

> **نکته:** در تابع با نوع بازگشتی `void`، استفاده از دستور `return` با مقدار، خطا ایجاد می‌کند. اما `return;` بدون مقدار مجاز است و اجرای تابع را متوقف می‌کند.

## ۵. دستور return و انواع خروجی

دستور `return` دو وظیفه دارد:

1. **مقدار را به فراخواننده بازمی‌گرداند.**
2. **اجرای تابع را در همان نقطه متوقف می‌کند.**

```php
<?php
function checkGrade(int $score): string {
    if ($score < 0 || $score > 20) {
        return "Invalid score";
    }
    if ($score >= 10) {
        return "Passed";
    }
    return "Failed";
}

echo checkGrade(25);   // Invalid score
echo "<br>";
echo checkGrade(12);   // Passed
echo "<br>";
echo checkGrade(5);    // Failed
?>
```

**تحلیل:** به‌محض رسیدن اجرا به اولین `return`، تابع پایان می‌یابد. به همین دلیل نیازی به `else` نیست؛ این سبک نوشتار را **بازگشت زودهنگام (Early Return)** می‌نامند و خوانایی کد را افزایش می‌دهد.

### تابع بدون return

اگر تابعی هیچ مقداری برنگرداند، مقدار بازگشتی آن به‌طور پیش‌فرض `null` است.

```php
<?php
function doNothing() {
    $x = 5;
}

var_dump(doNothing());   // NULL
?>
```

### بازگرداندن چند مقدار با آرایه

هر تابع فقط **یک** مقدار می‌تواند برگرداند. برای بازگرداندن چند مقدار، آن‌ها را در یک آرایه قرار می‌دهیم.

```php
<?php
function analyzeScore(int $score): array {
    $status = "Failed";
    if ($score >= 10) {
        $status = "Passed";
    }

    return [
        "score"  => $score,
        "status" => $status,
        "valid"  => ($score >= 0 && $score <= 20)
    ];
}

$result = analyzeScore(14);
echo $result["status"];   // Passed
echo "<br>";
var_dump($result["valid"]);  // bool(true)
?>
```

## ۶. حالت سخت‌گیرانهٔ انواع داده (strict_types)

به‌طور پیش‌فرض، PHP در برخورد با نوع‌های ناهمخوان، تبدیل نوع انجام می‌دهد. اگر بخواهیم این تبدیل انجام نشود و خطا صادر گردد، باید در **اولین خط فایل** (پیش از هر دستور دیگری) اعلان زیر را بنویسیم:

```php
<?php
declare(strict_types=1);

function checkGrade(int $score): string {
    if ($score >= 10) {
        return "Passed";
    }
    return "Failed";
}

echo checkGrade(15);      // Passed
// echo checkGrade("15"); // خطای TypeError
?>
```

> **نکتهٔ مهم:** این اعلان **فقط بر فایلی که در آن نوشته شده** اثر دارد و بر فایل‌های الحاق‌شده (با `include` یا `require`) تأثیر نمی‌گذارد.

## ۷. ارسال با مقدار (By Value) و ارسال با ارجاع (By Reference)

به‌طور پیش‌فرض، آرگومان‌ها **با مقدار** به تابع پاس می‌شوند؛ یعنی تابع یک کپی از مقدار دریافت می‌کند و تغییر آن، متغیر اصلی را تغییر نمی‌دهد.

```php
<?php
function changeValue(int $n): void {
    $n = $n + 100;
}

$number = 5;
changeValue($number);
echo $number;   // 5  (تغییر نکرد)
?>
```

اگر بخواهیم تابع بتواند متغیر اصلی را تغییر دهد، از علامت `&` پیش از نام پارامتر استفاده می‌کنیم. این حالت **ارسال با ارجاع** نام دارد.

```php
<?php
function addBonus(int &$score): void {
    $score = $score + 1;
}

$studentScore = 9;
addBonus($studentScore);
echo $studentScore;   // 10  (تغییر کرد)
?>
```

> **کاربرد:** ارسال با ارجاع وقتی مفید است که بخواهیم تابع چند مقدار را تغییر دهد یا از کپی‌برداری سنگین (مثلاً آرایه‌های بزرگ) جلوگیری کنیم.

## ۸. آرگومان‌های متغیر (Variadic) و آرگومان‌های نام‌دار

### آرگومان‌های متغیر

اگر تعداد آرگومان‌های ورودی از پیش مشخص نباشد، از عملگر `...` پیش از نام پارامتر استفاده می‌کنیم. PHP همهٔ آرگومان‌های پاس‌شده را در قالب یک **آرایه** در آن پارامتر قرار می‌دهد.

```php
<?php
function calculateAverage(float ...$scores): float {
    $total = 0;
    foreach ($scores as $score) {
        $total = $total + $score;
    }
    return $total / count($scores);
}

echo calculateAverage(10, 20, 30);      // 20
echo "<br>";
echo calculateAverage(5, 15);           // 10
?>
```

> **قاعده:** پارامتر variadic باید **آخرین** پارامتر تابع باشد.

### آرگومان‌های نام‌دار (PHP 8 به بعد)

می‌توان آرگومان‌ها را با نام پارامتر و بدون رعایت ترتیب پاس داد:

```php
<?php
function createStudent(string $name, int $score, string $grade = "A") {
    return $name . " - " . $score . " - " . $grade;
}

echo createStudent(score: 18, name: "Ali");
// Ali - 18 - A
?>
```

## ۹. مثال ۱: تشخیص نام ماه شمسی از روی عدد

در این مثال، تابعی می‌نویسیم که عددی بین ۱ تا ۱۲ دریافت کرده و نام ماه شمسی متناظر را بازمی‌گرداند. از نوع داده برای پارامتر و مقدار بازگشتی و نیز یک پارامتر اختیاری برای پیام خطا استفاده می‌کنیم.

```php
<?php
function getPersianMonth(int $monthNumber, string $fallback = "Invalid month number"): string {
    $months = [
        1  => "Farvardin",
        2  => "Ordibehesht",
        3  => "Khordad",
        4  => "Tir",
        5  => "Mordad",
        6  => "Shahrivar",
        7  => "Mehr",
        8  => "Aban",
        9  => "Azar",
        10 => "Dey",
        11 => "Bahman",
        12 => "Esfand"
    ];

    if ($monthNumber >= 1 && $monthNumber <= 12) {
        return $months[$monthNumber];
    }

    return $fallback;
}

echo getPersianMonth(1);     // Farvardin
echo "<br>";
echo getPersianMonth(7);     // Mehr
echo "<br>";
echo getPersianMonth(12);    // Esfand
echo "<br>";
echo getPersianMonth(13);    // Invalid month number
echo "<br>";
echo getPersianMonth(0, "Out of range");   // Out of range
?>
```

**خروجی:**
```
Farvardin
Mehr
Esfand
Invalid month number
Out of range
```

**تحلیل:**
- پارامتر `$monthNumber` از نوع `int` و مقدار بازگشتی از نوع `string` تعیین شده است.
- پارامتر `$fallback` اختیاری است و در صورت نامعتبر بودن ورودی به کار می‌رود.
- در فراخوانی آخر، مقدار پیش‌فرض با پاس دادن آرگومان دوم بازنویسی شده است.

## ۱۰. مثال ۲: پردازش گروهی دانش‌آموزان با آرایهٔ دوبعدی انجمنی

در این مثال، اطلاعات چند دانش‌آموز در یک **آرایهٔ دوبعدی انجمنی** ذخیره شده است: کلید سطح اول، شناسهٔ دانش‌آموز و مقدار آن، آرایه‌ای انجمنی شامل نام و نمره است. سپس با توابع، وضعیت هر دانش‌آموز و گزارش کلی را تولید می‌کنیم.

### گام ۱: تعریف داده‌ها

```php
<?php
$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12],
    "s104" => ["name" => "Mina", "score" => 7],
    "s105" => ["name" => "Omid", "score" => 15]
];
?>
```

### گام ۲: تابع تشخیص وضعیت یک دانش‌آموز

```php
<?php
function getStudentStatus(array $student, int $passMark = 10): string {
    if ($student["score"] >= $passMark) {
        return "Passed";
    }
    return "Failed";
}
?>
```

**تحلیل:** این تابع یک آرایهٔ انجمنی (یک دانش‌آموز) و یک حد قبولی اختیاری دریافت می‌کند. تعیین حد قبولی به‌صورت پارامتر، انعطاف تابع را افزایش می‌دهد.

### گام ۳: تابع تولید گزارش برای کل گروه

```php
<?php
function printStudentReport(array $studentList, int $passMark = 10): void {
    foreach ($studentList as $id => $student) {
        echo $id . " | " . $student["name"] . " | " . $student["score"] . " | "
             . getStudentStatus($student, $passMark) . "<br>";
    }
}
?>
```

### گام ۴: تابع محاسبهٔ میانگین نمرات

```php
<?php
function calculateClassAverage(array $studentList): float {
    $total = 0;
    foreach ($studentList as $student) {
        $total = $total + $student["score"];
    }
    return $total / count($studentList);
}
?>
```

### گام ۵: فراخوانی و اجرا

```php
<?php
printStudentReport($students);
echo "<br>";
echo "Class average: " . calculateClassAverage($students);
echo "<br><br>";
echo "With pass mark 15: <br>";
printStudentReport($students, 15);
?>
```

**خروجی:**
```
s101 | Ali | 18 | Passed
s102 | Sara | 9 | Failed
s103 | Reza | 12 | Passed
s104 | Mina | 7 | Failed
s105 | Omid | 15 | Passed

Class average: 12.2

With pass mark 15:
s101 | Ali | 18 | Passed
s102 | Sara | 9 | Failed
s103 | Reza | 12 | Failed
s104 | Mina | 7 | Failed
s105 | Omid | 15 | Passed
```

**تحلیل کلی مثال:**
- داده‌ها در آرایهٔ دوبعدی انجمنی ساختار یافته‌اند: `$students[$id]["name"]` و `$students[$id]["score"]`.
- هر تابع تنها یک وظیفهٔ مشخص دارد (**اصل تک‌مسئولیتی**): یکی وضعیت را تعیین می‌کند، یکی گزارش می‌سازد و یکی میانگین را محاسبه می‌کند.
- تابع `getStudentStatus` درون تابع `printStudentReport` فراخوانی شده است؛ این نشان می‌دهد توابع می‌توانند یکدیگر را فراخوانی کنند.
- با تغییر پارامتر `$passMark`، رفتار کل گزارش بدون تغییر در منطق توابع عوض می‌شود.

## ۱۱. نکات کلیدی این بخش

- پارامترهای اختیاری باید پس از پارامترهای اجباری قرار گیرند.
- مقدار پیش‌فرض باید ثابت باشد (عدد، رشته، `null`، آرایهٔ ثابت و مانند آن).
- تعیین نوع داده، هم برای پارامترها و هم برای مقدار بازگشتی، خوانایی و امنیت کد را افزایش می‌دهد.
- اعلان `declare(strict_types=1)` تبدیل نوع خودکار را غیرفعال می‌کند و فقط در همان فایل اثر دارد.
- دستور `return` هم مقدار بازمی‌گرداند و هم اجرای تابع را متوقف می‌کند.
- تابع بدون `return` مقدار `null` برمی‌گرداند.
- هر تابع فقط یک مقدار بازمی‌گرداند؛ برای چند مقدار از آرایه استفاده کنید.
- ارسال با ارجاع (`&`) به تابع اجازهٔ تغییر متغیر اصلی را می‌دهد.
- عملگر `...` برای دریافت تعداد نامشخصی آرگومان به کار می‌رود و باید آخرین پارامتر باشد.
- توابع می‌توانند یکدیگر را فراخوانی کنند.

## تست‌های چهارگزینه‌ای

**سؤال ۱.** کدام تعریف تابع از نظر نحوی صحیح است؟
- الف) `function f($a = 1, $b) { }`
- ب) `function f($b, $a = 1) { }`
- ج) `function f($a = 1, $b = 2, $c) { }`
- د) هر سه صحیح هستند

**سؤال ۲.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
function greet($name, $greeting = "Hello") {
    return $greeting . ", " . $name;
}
echo greet("Sara", "Hi");
?>
```
- الف) `Hello, Sara`
- ب) `Hi, Sara`
- ج) `Hi, Hello`
- د) خطا

**سؤال ۳.** در تعریف `function f(int $x): string`، بخش `string` چه چیزی را مشخص می‌کند؟
- الف) نوع پارامتر ورودی
- ب) نوع مقدار بازگشتی
- ج) نام تابع
- د) مقدار پیش‌فرض

**سؤال ۴.** اگر تابعی هیچ دستور `return` نداشته باشد، مقدار بازگشتی آن چیست؟
- الف) `0`
- ب) رشتهٔ خالی
- ج) `null`
- د) خطا صادر می‌شود

**سؤال ۵.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
function test(int $x) {
    if ($x > 0) {
        return "Positive";
    }
}
var_dump(test(-1));
?>
```
- الف) `string(8) "Positive"`
- ب) `int(0)`
- ج) `NULL`
- د) خطای TypeError

**سؤال ۶.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
function increase(int &$n) {
    $n = $n + 1;
}
$a = 5;
increase($a);
echo $a;
?>
```
- الف) `5`
- ب) `6`
- ج) `1`
- د) خطا

**سؤال ۷.** برای دریافت تعداد نامشخصی آرگومان در یک تابع از کدام عملگر استفاده می‌شود؟
- الف) `&`
- ب) `*`
- ج) `...`
- د) `?`

**سؤال ۸.** نوع بازگشتی `?string` چه معنایی دارد؟
- الف) تابع حتماً رشته برمی‌گرداند.
- ب) تابع رشته یا `null` برمی‌گرداند.
- ج) تابع هرگز مقداری برنمی‌گرداند.
- د) تابع آرایه‌ای از رشته‌ها برمی‌گرداند.

**سؤال ۹.** اعلان `declare(strict_types=1);` چه اثری دارد؟
- الف) تمام فایل‌های پروژه را سخت‌گیرانه می‌کند.
- ب) تبدیل نوع خودکار را در همان فایل غیرفعال می‌کند.
- ج) از بروز هر خطایی جلوگیری می‌کند.
- د) نوع همهٔ پارامترها را به `int` تبدیل می‌کند.

**سؤال ۱۰.** با توجه به تابع زیر، خروجی `getPersianMonth(15)` چیست؟
```php
<?php
function getPersianMonth(int $monthNumber, string $fallback = "Invalid month number"): string {
    $months = [1 => "Farvardin", 2 => "Ordibehesht", 3 => "Khordad"];
    if ($monthNumber >= 1 && $monthNumber <= 3) {
        return $months[$monthNumber];
    }
    return $fallback;
}
echo getPersianMonth(15);
?>
```
- الف) `Farvardin`
- ب) `Khordad`
- ج) `Invalid month number`
- د) `null`

## پاسخنامهٔ تشریحی

**۱. پاسخ: ب** — پارامترهای دارای مقدار پیش‌فرض باید بعد از پارامترهای اجباری بیایند. در گزینه‌های «الف» و «ج»، پارامتر بدون پیش‌فرض بعد از پارامتر دارای پیش‌فرض آمده است که خطای نحوی است.

**۲. پاسخ: ب** — آرگومان دوم (`"Hi"`) مقدار پیش‌فرض `$greeting` را بازنویسی می‌کند و خروجی `Hi, Sara` می‌شود.

**۳. پاسخ: ب** — بخش پس از `:` نوع مقدار بازگشتی تابع را مشخص می‌کند؛ `int` پیش از `$x` نوع پارامتر است.

**۴. پاسخ: ج** — تابع بدون `return` مقدار `null` برمی‌گرداند.

**۵. پاسخ: ج** — شرط `$x > 0` برای `-1` برقرار نیست، بنابراین `return` اجرا نمی‌شود و تابع به‌طور طبیعی با مقدار `null` پایان می‌یابد.

**۶. پاسخ: ب** — پارامتر با `&` (ارجاع) تعریف شده است؛ بنابراین تغییر `$n` درون تابع، متغیر `$a` را نیز تغییر می‌دهد و مقدار `6` چاپ می‌شود.

**۷. پاسخ: ج** — عملگر `...` (Variadic) همهٔ آرگومان‌های پاس‌شده را در قالب یک آرایه در پارامتر جمع می‌کند.

**۸. پاسخ: ب** — علامت `?` پیش از نوع، حالت nullable را فعال می‌کند؛ یعنی مقدار بازگشتی می‌تواند از نوع مشخص‌شده یا `null` باشد.

**۹. پاسخ: ب** — این اعلان فقط در همان فایلی که نوشته شده اثر دارد و تبدیل نوع خودکار را غیرفعال می‌کند؛ در صورت ناهم‌خوانی نوع، `TypeError` صادر می‌شود.

**۱۰. پاسخ: ج** — عدد `15` در بازهٔ ۱ تا ۳ نیست، بنابراین پارامتر `$fallback` با مقدار پیش‌فرض خود بازگردانده می‌شود.
