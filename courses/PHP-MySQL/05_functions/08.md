# تابع بازگشتی تبدیل عدد به حروف فارسی

https://code.secad.ir/digit_to_text3.php

## هدف کلی تابع

تابع `convertNumberToWords` یک عدد صحیح می‌گیرد و معادل حروفی فارسی آن را برمی‌گرداند. مثلاً `1234` را به `«یک هزار و دویست و سی و چهار»` تبدیل می‌کند.

نکتهٔ کلیدی این است که این تابع **بازگشتی (Recursive)** است؛ یعنی برای حل یک عدد بزرگ، آن را به قطعات کوچک‌تر می‌شکند و **خودش را برای هر قطعه دوباره فراخوانی می‌کند**.

---

## بخش اول: تعریف تابع و آرایهٔ کلمات

```php
function convertNumberToWords($number) {
    $words = [
        0 => 'صفر',
        1 => 'یک',
        ...
        1000 => 'هزار',
        1000000 => 'میلیون',
        1000000000 => 'میلیارد'
    ];
```

**توضیح:** این آرایه یک «فرهنگ لغت» است که عددهای پایه را به کلمه نگاشت می‌کند. عددهایی که در آرایه هستند عبارت‌اند از:

- **۰ تا ۲۰** (عددهای کوچک که نام مستقل دارند)
- **مضرب‌های ده تا ۹۰** (بیست، سی، چهل، …)
- **مضرب‌های صد تا ۹۰۰** (صد، دویست، …)
- **واحدهای بزرگ** (هزار، میلیون، میلیارد)

> **نکته:** فقط همین عددها در آرایه ذخیره شده‌اند. بقیهٔ عددها (مثل ۲۴، ۳۴۵، ۱۲۳۴) در آرایه نیستند و باید **با ترکیب** ساخته شوند. ترکیب هم همان کاری است که بخش‌های بازگشتی انجام می‌دهند.

---

## بخش دوم: شرط توقف برای عدد منفی

```php
if ($number < 0) {
    return 'منفی ' . convertNumberToWords(-$number);
}
```

**توضیح:**

- اگر عدد منفی باشد، کلمهٔ `«منفی »` را اضافه می‌کند.
- سپس با `-$number` علامت منفی را حذف می‌کند و **تابع را دوباره برای عدد مثبت فراخوانی می‌کند**.
- **این یک فراخوانی بازگشتی است.** اما چون بعد از این خط، عدد مثبت شده و دیگر وارد این شرط نمی‌شود، بازگشت بی‌پایان رخ نمی‌دهد.

**مثال:** ورودی `-۵` → خروجی `«منفی پنج»`

- `convertNumberToWords(-5)` → `'منفی ' . convertNumberToWords(5)`
- `convertNumberToWords(5)` → `'پنج'`
- نتیجه: `«منفی پنج»`

---

## بخش سوم: شرط توقف اصلی (عدد کمتر از ۲۰)

```php
if ($number < 20) {
    return $words[$number];
}
```

**توضیح:** این مهم‌ترین **شرط توقف (Base Case)** است.

- اگر عدد بین ۰ تا ۱۹ باشد، مستقیماً از آرایه خوانده و برگردانده می‌شود.
- **دیگر هیچ فراخوانی بازگشتی انجام نمی‌شود.** بازگشت در همین‌جا متوقف می‌شود.
- بدون این شرط، تابع برای همیشه خودش را فراخوانی می‌کرد و برنامه با خطا متوقف می‌شد.

**مثال:** `convertNumberToWords(7)` → `'هفت'`

---

## بخش چهارم: عددهای دو رقمی (۱۰ تا ۹۹)

```php
if ($number < 100) {
    $tens = floor($number / 10) * 10;
    $units = $number % 10;
    return $words[$tens] . ($units ? ' و ' . $words[$units] : '');
}
```

**توضیح خط به خط:**

1. `floor($number / 10) * 10` → **دهگان** را جدا می‌کند. مثلاً برای ۳۴: `floor(34/10)=3`، سپس `3*10=30` → سی
2. `$number % 10` → **یکان** را جدا می‌کند. مثلاً `34 % 10 = 4` → چهار
3. خروجی: کلمهٔ دهگان + (اگر یکان صفر نبود) « و » + کلمهٔ یکان

**نکتهٔ مهم دربارهٔ بازگشت:** در این بخش **فراخوانی بازگشتی وجود ندارد**، چون هم دهگان و هم یکان مستقیماً در آرایه هستند (۳۰ → «سی»، ۴ → «چهار»).

**مثال:** `34` → `'سی' . ' و ' . 'چهار'` → `«سی و چهار»`

**مثال:** `30` → یکان صفر است، پس فقط `«سی»` برگردانده می‌شود.

---

## بخش پنجم: عددهای سه رقمی (۱۰۰ تا ۹۹۹) — **اولین بازگشت واقعی**

```php
if ($number < 1000) {
    $hundreds = floor($number / 100) * 100;
    $remainder = $number % 100;
    return $words[$hundreds] . ($remainder ? ' و ' . convertNumberToWords($remainder) : '');
}
```

**توضیح خط به خط:**

1. `floor($number / 100) * 100` → **صدگان** را جدا می‌کند. مثلاً برای ۲۳۴: `floor(234/100)=2`، سپس `2*100=200` → دویست
2. `$number % 100` → **باقی‌مانده** (دو رقم آخر) را جدا می‌کند. مثلاً `234 % 100 = 34`
3. خروجی: کلمهٔ صدگان + (اگر باقی‌مانده صفر نبود) « و » + **`convertNumberToWords($remainder)`**

**اینجا بازگشت رخ می‌دهد:** برای باقی‌مانده (۳۴) تابع **دوباره خودش را فراخوانی می‌کند**. آن فراخوانی وارد بخش چهارم می‌شود و ۳۴ را به «سی و چهار» تبدیل می‌کند.

**ردیابی کامل برای ۲۳۴:**

```
convertNumberToWords(234)
  → صدگان = 200 → 'دویست'
  → باقی‌مانده = 34
  → return 'دویست' . ' و ' . convertNumberToWords(34)

      convertNumberToWords(34)    ← فراخوانی بازگشتی
        → وارد بخش دو رقمی می‌شود
        → return 'سی' . ' و ' . 'چهار'  = 'سی و چهار'

  → نتیجهٔ نهایی: 'دویست و سی و چهار'
```

**چرا بازگشت متوقف می‌شود؟** چون هر بار باقی‌مانده **کوچک‌تر** می‌شود (۲۳۴ → ۳۴ → ۴) و در نهایت به شرط توقف (کمتر از ۲۰) می‌رسد.

## بخش ششم: عددهای هزار تا یک میلیون — **دو فراخوانی بازگشتی**

```php
if ($number < 1000000) {
    $thousands = floor($number / 1000);
    $remainder = $number % 1000;
    return convertNumberToWords($thousands) . ' هزار' . ($remainder ? ' و ' . convertNumberToWords($remainder) : '');
}
```

**توضیح خط به خط:**

1. `floor($number / 1000)` → **تعداد هزارها** را جدا می‌کند. برای ۱۲۳۴: `floor(1234/1000)=1`
2. `$number % 1000` → **باقی‌ماندهٔ کمتر از هزار** را جدا می‌کند. برای ۱۲۳۴: `1234 % 1000 = 234`
3. خروجی: `convertNumberToWords($thousands)` + کلمهٔ «هزار» + (اگر باقی‌مانده صفر نبود) « و » + `convertNumberToWords($remainder)`

**اینجا دو بازگشت داریم:**

- **بازگشت اول:** `convertNumberToWords($thousands)` → تعداد هزارها را به حروف تبدیل می‌کند (مثلاً ۱ → «یک»).
- **بازگشت دوم:** `convertNumberToWords($remainder)` → باقی‌مانده را به حروف تبدیل می‌کند (مثلاً ۲۳۴ → «دویست و سی و چهار»).

**ردیابی کامل برای ۱۲۳۴:**

```
convertNumberToWords(1234)
  → هزارها = 1
  → باقی‌مانده = 234
  → return convertNumberToWords(1) . ' هزار' . ' و ' . convertNumberToWords(234)

      convertNumberToWords(1) = 'یک'          ← بازگشت اول (به شرط توقف می‌رسد)
      convertNumberToWords(234) = 'دویست و سی و چهار'   ← بازگشت دوم

  → نتیجهٔ نهایی: 'یک هزار و دویست و سی و چهار'
```

## بخش هفتم: میلیون — همان الگو با دو بازگشت

```php
if ($number < 1000000000) {
    $millions = floor($number / 1000000);
    $remainder = $number % 1000000;
    return convertNumberToWords($millions) . ' میلیون' . ($remainder ? ' و ' . convertNumberToWords($remainder) : '');
}
```

**توضیح:** ساختار **دقیقاً** مانند بخش هزار است، فقط واحد از «هزار» به «میلیون» تغییر کرده و مقسوم‌علیه از ۱۰۰۰ به ۱۰۰۰۰۰۰ رسیده است.

- `convertNumberToWords($millions)` → تعداد میلیون‌ها را به حروف تبدیل می‌کند.
- `convertNumberToWords($remainder)` → باقی‌ماندهٔ کمتر از یک میلیون را به حروف تبدیل می‌کند.

---

## بخش هشتم: میلیارد — همان الگو

```php
if ($number < 1000000000000) {
    $billions = floor($number / 1000000000);
    $remainder = $number % 1000000000;
    return convertNumberToWords($billions) . ' میلیارد' . ($remainder ? ' و ' . convertNumberToWords($remainder) : '');
}
```

**توضیح:** همان ساختار میلیون و هزار، با واحد «میلیارد» و مقسوم‌علیه ۱۰۰۰۰۰۰۰۰۰.

---

## بخش نهم: شرط توقف نهایی برای عددهای خیلی بزرگ

```php
return 'عدد بزرگتر از ۱۰۰۰ میلیارد است';
```

**توضیح:** اگر عدد از ۱۰۰۰ میلیارد بزرگ‌تر باشد، هیچ‌یک از شرط‌های بالا برقرار نمی‌شود و این خط اجرا می‌گردد. این خط نقش **شرط توقف پیش‌فرض** را دارد و از بازگشت بی‌پایان جلوگیری می‌کند.

---

## خلاصهٔ منطق بازگشتی

| بخش | شرط | بازگشت دارد؟ |
|------|------|----------------|
| منفی | `$number < 0` | بله (۱ بار) |
| کمتر از ۲۰ | `$number < 20` | **خیر — شرط توقف اصلی** |
| دو رقمی | `$number < 100` | خیر |
| سه رقمی | `$number < 1000` | بله (۱ بار: باقی‌مانده) |
| هزار | `$number < 1000000` | بله (۲ بار: هزارها و باقی‌مانده) |
| میلیون | `$number < 1000000000` | بله (۲ بار) |
| میلیارد | `$number < 1000000000000` | بله (۲ بار) |
| بزرگ‌تر | — | خیر (خطای پیش‌فرض) |

**قاعدهٔ طلایی بازگشت در این تابع:** هر فراخوانی بازگشتی، عدد را **کوچک‌تر** می‌کند. مثلاً ۱۲۳۴ → ۱ و ۲۳۴ → ۲۳۴ → ۳۴ → ۴. چون عدد در هر مرحله کوچک‌تر می‌شود، دیر یا زود به شرط توقف (کمتر از ۲۰) می‌رسد و بازگشت پایان می‌یابد.

## درخت فراخوانی برای ۱۲۳۴ (نمای کلی)

```
convertNumberToWords(1234)
├── convertNumberToWords(1)        → 'یک'         (توقف: <20)
└── convertNumberToWords(234)
    ├── 'دویست'  (صدگان)
    └── convertNumberToWords(34)
        ├── 'سی'   (دهگان)
        └── 'چهار' (یکان)          (توقف: <20)

نتیجه: یک هزار و دویست و سی و چهار
```

## نکات پایانی دربارهٔ بخش‌های غیر بازگشتی کد

برای تکمیل توضیح، بخش‌های بیرون از تابع را کوتاه مرور می‌کنیم:

- `if (isset($_POST['number']))` → بررسی می‌کند فرم ارسال شده است یا نه.
- `intval($_POST['number'])` → ورودی را به عدد صحیح تبدیل می‌کند.
- `isset($number)` پس از `intval` **همیشه درست است**؛ بنابراین این شرط عملاً هیچ کاری نمی‌کند و می‌توان آن را حذف کرد.
- در HTML، فرم با `method="post"` عدد را به همان صفحه می‌فرستد و نتیجه نمایش داده می‌شود.
- `htmlspecialchars($number)` برای جلوگیری از تزریق HTML به کار رفته است.
