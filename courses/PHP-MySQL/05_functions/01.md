# مقدمه‌ای بر توابع و توابع تعریف‌شده توسط کاربر

## ۱-۱. تابع چیست و چرا به آن نیاز داریم؟

**تابع (Function)** مجموعه‌ای از دستورات است که برای انجام یک وظیفهٔ مشخص، تحت یک نام واحد بسته‌بندی شده است. تابع تنها زمانی که **فراخوانی (Call)** شود، اجرا می‌گردد.

اهمیت توابع را می‌توان در سه اصل خلاصه کرد:

1. **اصل DRY (Don't Repeat Yourself):** به‌جای تکرار یک قطعه کد در چندین نقطه از برنامه، آن را یک‌بار در قالب تابع می‌نویسیم و هر جا لازم شد، فراخوانی می‌کنیم.
2. **خوانایی و نگهداری آسان‌تر:** برنامه به قطعات کوچک و قابل‌فهم تقسیم می‌شود و اصلاح یک بخش، سایر بخش‌ها را تحت تأثیر قرار نمی‌دهد.
3. **قابلیت استفادهٔ مجدد (Reusability):** یک تابع را می‌توان در پروژه‌های مختلف یا در چندین نقطه از یک پروژه به کار برد.

> **نکته:** توابع در PHP دو دسته‌اند:
> - **توابع تعریف‌شده توسط کاربر (User-Defined Functions):** که برنامه‌نویس خود آن‌ها را می‌سازد.
> - **توابع پیش‌ساخته (Built-in Functions):** که در خود PHP وجود دارند.

---

## ۱-۲. ساختار تعریف یک تابع

ساختار کلی تعریف یک تابع در PHP به‌صورت زیر است:

```
function functionName(parameter1, parameter2, ...) {
    // بدنهٔ تابع (دستورات)
    return result;   // اختیاری
}
```

**اجزای ساختار:**

| جزء | توضیح |
|------|--------|
| `function` | کلیدواژهٔ ثابت PHP برای تعریف تابع |
| `functionName` | نام تابع؛ باید با حرف یا زیرخط (`_`) شروع شود و از حروف، اعداد و زیرخط تشکیل شود. نام‌ها در PHP **حساس به حروف بزرگ و کوچک (Case-Sensitive)** نیستند. |
| `parameter1, ...` | لیست پارامترها؛ می‌تواند خالی باشد. |
| `{ ... }` | بدنهٔ تابع؛ شامل دستوراتی که هنگام فراخوانی اجرا می‌شوند. |
| `return` | مقدار خروجی تابع را مشخص می‌کند. |

> **قاعدهٔ مهم:** نام تابع نمی‌تواند با عدد شروع شود و نباید با نام توابع پیش‌ساختهٔ PHP یکسان باشد.

## ۱-۳. فراخوانی (Invoke) تابع

پس از تعریف تابع، برای اجرای آن باید **فراخوانی** شود. فراخوانی با نوشتن نام تابع و پرانتز انجام می‌شود:

```php
<?php
function sayHello() {
    echo "Hello, World!";
}

sayHello();   // فراخوانی تابع
?>
```

**خروجی:**
```
Hello, World!
```

> **نکته:** تا زمانی که تابع فراخوانی نشود، دستورات درون بدنهٔ آن هرگز اجرا نمی‌شوند.

---

## ۱-۴. تفاوت پارامتر (Parameter) و آرگومان (Argument)

این دو اصطلاح اغلب به‌جای یکدیگر به کار می‌روند، اما تفاوت ظریفی دارند:

- **پارامتر (Parameter):** متغیری است که در **تعریف** تابع در پرانتز نوشته می‌شود (مثل `$name` در تعریف زیر).
- **آرگومان (Argument):** مقدار واقعی است که هنگام **فراخوانی** تابع به آن پاس داده می‌شود (مثل `"Ali"` در فراخوانی زیر).

```php
<?php
function greet($name) {          // $name یک پارامتر است
    echo "Hello, " . $name;
}

greet("Ali");                    // "Ali" یک آرگومان است
?>
```

## ۱-۵. مثال ۱: تابع تشخیص قبولی یا مردودی

دانش‌آموزان با دستور `if` آشنایی دارند. اکنون همان منطق را در قالب یک تابع می‌نویسیم تا تفاوت و مزیت تابع را بهتر درک کنند.

**بدون تابع (تکرار منطق):**
```php
<?php
$score1 = 15;
if ($score1 >= 10) {
    echo "Passed";
} else {
    echo "Failed";
}

$score2 = 8;
if ($score2 >= 10) {
    echo "Passed";
} else {
    echo "Failed";
}
?>
```

**با تابع (حذف تکرار):**
```php
<?php
function checkGrade($score) {
    if ($score >= 10) {
        return "Passed";
    } else {
        return "Failed";
    }
}

echo checkGrade(15);   // Passed
echo "<br>";
echo checkGrade(8);    // Failed
echo "<br>";
echo checkGrade(10);   // Passed
?>
```

**خروجی:**
```
Passed
Failed
Passed
```

**تحلیل:** منطق تشخیص قبولی/مردودی یک‌بار در تابع `checkGrade` نوشته شد و سه بار با نمرات مختلف فراخوانی گردید. اگر روزی شرط قبولی تغییر کند (مثلاً ۱۲ شود)، فقط یک خط در تابع اصلاح می‌شود.

## ۱-۶. مثال ۲: تابع تشخیص روز هفته از روی عدد

در این مثال، تابعی می‌نویسیم که عددی بین ۱ تا ۷ دریافت کرده و نام روز هفته را برمی‌گرداند. این مثال نشان می‌دهد که تابع می‌تواند بر اساس ورودی، خروجی‌های متفاوتی تولید کند.

```php
<?php
function getDayName($dayNumber) {
    if ($dayNumber == 1) {
        return "Saturday";
    } elseif ($dayNumber == 2) {
        return "Sunday";
    } elseif ($dayNumber == 3) {
        return "Monday";
    } elseif ($dayNumber == 4) {
        return "Tuesday";
    } elseif ($dayNumber == 5) {
        return "Wednesday";
    } elseif ($dayNumber == 6) {
        return "Thursday";
    } elseif ($dayNumber == 7) {
        return "Friday";
    } else {
        return "Invalid day number";
    }
}

echo getDayName(1);   // Saturday
echo "<br>";
echo getDayName(5);   // Wednesday
echo "<br>";
echo getDayName(7);   // Friday
echo "<br>";
echo getDayName(9);   // Invalid day number
?>
```

**خروجی:**
```
Saturday
Wednesday
Friday
Invalid day number
```

**تحلیل:** تابع `getDayName` یک پارامتر به نام `$dayNumber` می‌گیرد و با زنجیره‌ای از `if/elseif/else` مقدار مناسب را برمی‌گرداند. این مثال اهمیت **حالت پیش‌فرض (else)** را نیز نشان می‌دهد: ورودی نامعتبر باید مدیریت شود.

## ۱-۷. نکات مهم 

- تابع بدون فراخوانی اجرا نمی‌شود.
- نام تابع نباید با عدد شروع شود و نباید با توابع پیش‌ساختهٔ PHP هم‌نام باشد.
- پارامتر در تعریف و آرگومان در فراخوانی ظاهر می‌شود.
- استفاده از تابع، کد را کوتاه‌تر، خواناتر و قابل نگهداری‌تر می‌کند.
- برای حالت‌های نامعتبر ورودی، همیشه یک مسیر پیش‌فرض (مثل `else`) در نظر بگیرید.

## تست‌های چهارگزینه‌ای

**سؤال ۱.** کدام کلیدواژه برای تعریف یک تابع در PHP استفاده می‌شود؟
- الف) `def`
- ب) `function`
- ج) `fun`
- د) `void`

**سؤال ۲.** تابع در PHP چه زمانی اجرا می‌شود؟
- الف) به‌محض تعریف شدن
- ب) هنگام بارگذاری فایل
- ج) فقط زمانی که فراخوانی شود
- د) هنگام خروج از فایل

**سؤال ۳.** کدام گزینه دربارهٔ نام تابع در PHP صحیح است؟
- الف) نام تابع به حروف بزرگ و کوچک حساس است.
- ب) نام تابع می‌تواند با عدد شروع شود.
- ج) نام تابع به حروف بزرگ و کوچک حساس نیست.
- د) نام تابع باید حداقل ۵ کاراکتر باشد.

**سؤال ۴.** در تابع `greet($name)`، عبارت `$name` چه نامیده می‌شود؟
- الف) آرگومان
- ب) پارامتر
- ج) مقدار بازگشتی
- د) متغیر سراسری

**سؤال ۵.** در فراخوانی `greet("Ali")`، عبارت `"Ali"` چه نامیده می‌شود؟
- الف) پارامتر
- ب) آرگومان
- ج) کلیدواژه
- د) شناسه

**سؤال ۶.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
function checkGrade($score) {
    if ($score >= 10) {
        return "Passed";
    } else {
        return "Failed";
    }
}
echo checkGrade(10);
?>
```
- الف) `Failed`
- ب) `Passed`
- ج) `10`
- د) خطا

**سؤال ۷.** اصل DRY در برنامه‌نویسی به چه معناست؟
- الف) استفاده از حداکثر توابع پیش‌ساخته
- ب) تکرار نکردن کد و استفادهٔ مجدد از آن
- ج) نوشتن کد در یک خط
- د) عدم استفاده از شرط‌ها

**سؤال ۸.** در تابع `getDayName`، اگر ورودی `0` باشد، کدام خروجی صحیح است؟
- الف) `Saturday`
- ب) `Sunday`
- ج) `Invalid day number`
- د) خطا

**سؤال ۹.** کدام گزینه دربارهٔ ساختار تعریف تابع صحیح است؟
- الف) بدنهٔ تابع باید حتماً شامل `return` باشد.
- ب) پارامترها اجباری هستند.
- ج) پارامترها می‌توانند خالی باشند.
- د) نام تابع باید با حرف بزرگ شروع شود.

**سؤال ۱۰.** کدام گزینه مزیت استفاده از تابع را بیان می‌کند؟
- الف) افزایش سرعت اینترنت
- ب) خوانایی و نگهداری آسان‌تر کد
- ج) حذف کامل شرط‌های `if`
- د) حذف نیاز به متغیرها

## پاسخنامهٔ تشریحی

**۱. پاسخ: ب** — در PHP برای تعریف تابع از کلیدواژهٔ `function` استفاده می‌شود.

**۲. پاسخ: ج** — تابع تا زمانی که فراخوانی نشود، اجرا نمی‌شود.

**۳. پاسخ: ج** — نام توابع در PHP حساس به حروف بزرگ و کوچک **نیست** (برخلاف نام متغیرها).

**۴. پاسخ: ب** — `$name` در تعریف تابع، **پارامتر** است.

**۵. پاسخ: ب** — `"Ali"` در فراخوانی، **آرگومان** است.

**۶. پاسخ: ب** — چون شرط `$score >= 10` برای ورودی `10` برقرار است، مقدار `Passed` برگردانده می‌شود.

**۷. پاسخ: ب** — DRY یعنی «خودت را تکرار نکن»؛ یعنی کد تکراری را در قالب تابع یک‌بار بنویسیم.

**۸. پاسخ: ج** — ورودی `0` در هیچ‌یک از شروط `1` تا `7` صدق نمی‌کند، پس شاخهٔ `else` اجرا می‌شود.

**۹. پاسخ: ج** — پارامترها می‌توانند خالی باشند (تابع بدون پارامتر).

**۱۰. پاسخ: ب** — مهم‌ترین مزیت تابع، خوانایی و نگهداری آسان‌تر کد است.
