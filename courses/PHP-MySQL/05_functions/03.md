# محدودهٔ متغیرها (Variable Scope)

## ۱. مفهوم Scope و اهمیت آن

**محدودهٔ متغیر (Scope)** به ناحیه‌ای از برنامه گفته می‌شود که در آن یک متغیر قابل دسترسی است. به عبارت دیگر، Scope مشخص می‌کند که یک متغیر «از کجا تا کجا» شناخته شده است.

درک صحیح Scope از آن جهت اهمیت دارد که:

- از **تغییر ناخواستهٔ** متغیرها توسط بخش‌های دیگر برنامه جلوگیری می‌کند.
- از بروز خطای **«متغیر تعریف‌نشده» (Undefined Variable)** پیشگیری می‌کند.
- به **سازمان‌دهی منطقی** کد کمک می‌کند و از وابستگی‌های پنهان میان بخش‌ها می‌کاهد.

در PHP به‌طور کلی سه محدودهٔ اصلی وجود دارد:

| نوع Scope | محل تعریف | قابلیت دسترسی |
|-----------|-----------|----------------|
| **محلی (Local)** | درون تابع | فقط درون همان تابع |
| **سراسری (Global)** | بیرون از همهٔ توابع | در سراسر فایل، اما **نه** به‌طور مستقیم درون توابع |
| **ایستا (Static)** | درون تابع با کلیدواژهٔ `static` | فقط درون همان تابع، اما مقدار آن میان فراخوانی‌ها حفظ می‌شود |

---

## ۲. متغیرهای محلی (Local Variables)

هر متغیری که درون یک تابع تعریف شود، **متغیر محلی** است و تنها در همان تابع قابل دسترسی است. پس از پایان اجرای تابع، متغیر محلی از بین می‌رود.

```php
<?php
function showScore() {
    $score = 18;
    echo "Inside function: " . $score;
}

showScore();
echo "<br>";
// echo $score;   // خطا: Undefined variable
?>
```

**خروجی:**
```
Inside function: 18
```

> **نکتهٔ مهم:** متغیرهای محلی **هیچ ارتباطی** با متغیرهای همنام در بیرون از تابع ندارند؛ حتی اگر نامشان یکسان باشد، دو متغیر کاملاً مستقل‌اند.

```php
<?php
$score = 5;

function changeScore() {
    $score = 20;
    echo "Inside: " . $score;    // Inside: 20
}

changeScore();
echo "<br>";
echo "Outside: " . $score;       // Outside: 5
?>
```

**تحلیل:** متغیر `$score` درون تابع، یک متغیر محلی مستقل است و تغییری در متغیر سراسری `$score` ایجاد نمی‌کند.

---

## ۳. متغیرهای سراسری (Global Variables) و کلیدواژهٔ global

متغیری که **بیرون از همهٔ توابع** تعریف شود، متغیر سراسری است. این متغیر در سراسر فایل قابل دسترسی است، **اما درون توابع به‌طور پیش‌فرض قابل دسترسی نیست.**

```php
<?php
$passMark = 10;

function checkGrade($score) {
    // echo $passMark;   // خطا: داخل تابع قابل دسترسی نیست
    if ($score >= 10) {
        return "Passed";
    }
    return "Failed";
}
?>
```

برای دسترسی به متغیر سراسری درون تابع، از کلیدواژهٔ `global` استفاده می‌کنیم.

```php
<?php
$passMark = 10;

function checkGrade($score) {
    global $passMark;
    if ($score >= $passMark) {
        return "Passed";
    }
    return "Failed";
}

echo checkGrade(12);   // Passed
echo "<br>";
echo checkGrade(8);    // Failed
?>
```

> **هشدار مهم:** استفاده از `global` باعث ایجاد **وابستگی پنهان** میان تابع و محیط بیرونی می‌شود؛ تابع دیگر خودکفا نیست و رفتارش به مقدار متغیری بیرونی وابسته است. به همین دلیل، در برنامه‌نویسی اصولی، **پاس دادن متغیر به‌صورت پارامتر** بر استفاده از `global` ترجیح داده می‌شود.

**مقایسهٔ دو سبک:**

```php
<?php
// سبک نامطلوب: وابستگی به متغیر سراسری
$passMark = 10;
function checkGradeBad($score) {
    global $passMark;
    return ($score >= $passMark) ? "Passed" : "Failed";
}

// سبک مطلوب: پاس دادن به‌صورت پارامتر
function checkGradeGood($score, $limit = 10) {
    return ($score >= $limit) ? "Passed" : "Failed";
}

echo checkGradeGood(12, 15);   // Failed
echo "<br>";
echo checkGradeGood(12);       // Passed
?>
```

**تحلیل:** نسخهٔ دوم خودکفاست؛ هر کسی با خواندن امضای تابع می‌فهمد چه ورودی‌هایی لازم است و رفتار تابع قابل پیش‌بینی است.

## ۴. آرایهٔ $GLOBALS

PHP یک **آرایهٔ سراسری ویژه** به نام `$GLOBALS` دارد که همهٔ متغیرهای سراسری را به‌صورت جفت‌های کلید-مقدار نگه می‌دارد. کلید هر عضو، **نام متغیر بدون علامت `$`** است.

با استفاده از `$GLOBALS` می‌توان بدون کلیدواژهٔ `global` به متغیرهای سراسری درون تابع دسترسی داشت:

```php
<?php
$passMark = 10;
$failMark = 9;

function analyzeScore($score) {
    if ($score >= $GLOBALS["passMark"]) {
        return "Passed";
    }
    return "Failed";
}

echo analyzeScore(12);   // Passed
?>
```

همچنین `$GLOBALS` امکان **تغییر** متغیر سراسری از درون تابع را نیز فراهم می‌کند:

```php
<?php
$counter = 0;

function increaseGlobalCounter() {
    $GLOBALS["counter"]++;
}

increaseGlobalCounter();
increaseGlobalCounter();
echo $GLOBALS["counter"];   // 2
?>
```

> **نکته:** `$GLOBALS` در PHP 8.1 به بعد **فقط خواندنی** است؛ یعنی نمی‌توان کل آرایه را بازنویسی کرد، اما می‌توان اعضای آن را تغییر داد.

## ۵. متغیرهای ایستا (Static Variables)

گاهی لازم است متغیری محلی داشته باشیم که مقدارش **میان فراخوانی‌های متوالی تابع حفظ شود**. برای این کار از کلیدواژهٔ `static` استفاده می‌کنیم.

```php
<?php
function countCalls() {
    static $count = 0;
    $count++;
    echo "Call number: " . $count . "<br>";
}

countCalls();   // Call number: 1
countCalls();   // Call number: 2
countCalls();   // Call number: 3
?>
```

**تحلیل:** متغیر `$count` تنها **یک‌بار** و در نخستین فراخوانی مقداردهی می‌شود. در فراخوانی‌های بعدی، همان مقدار قبلی حفظ می‌شود و از بین نمی‌رود. با این حال، این متغیر همچنان **فقط درون تابع** قابل دسترسی است.

### مقایسه با متغیر محلی معمولی

```php
<?php
function normalCounter() {
    $count = 0;
    $count++;
    echo "Normal: " . $count . "<br>";
}

function staticCounter() {
    static $count = 0;
    $count++;
    echo "Static: " . $count . "<br>";
}

normalCounter();   // Normal: 1
normalCounter();   // Normal: 1
staticCounter();   // Static: 1
staticCounter();   // Static: 2
?>
```

### مقدار اولیهٔ متغیر ایستا

مقدار اولیهٔ متغیر `static` باید یک **مقدار ثابت** باشد؛ نمی‌توان آن را با فراخوانی تابع یا متغیر دیگری مقداردهی کرد.

```php
<?php
function f() {
    static $n = 5;      // مجاز
    // static $m = someFunc();   // نادرست
    $n++;
    return $n;
}

echo f();   // 6
echo "<br>";
echo f();   // 7
?>
```

> **کاربرد رایج:** متغیرهای ایستا در توابع بازگشتی، شمارنده‌ها، و کش کردن نتایج محاسبات سنگین به کار می‌روند.

## ۶. مثال ۱: استفادهٔ نامناسب از global و اصلاح آن با آرایهٔ دوبعدی انجمنی

فرض کنید گروهی از دانش‌آموزان در یک آرایهٔ دوبعدی انجمنی ذخیره شده‌اند و می‌خواهیم وضعیت هرکدام را بر اساس حد قبولی تعیین کنیم.

**نسخهٔ نامطلوب (وابسته به متغیر سراسری):**

```php
<?php
$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12]
];
$passMark = 10;

function printReportBad($list) {
    global $passMark;
    foreach ($list as $id => $student) {
        $status = ($student["score"] >= $passMark) ? "Passed" : "Failed";
        echo $id . " | " . $student["name"] . " | " . $student["score"] . " | " . $status . "<br>";
    }
}

printReportBad($students);
?>
```

**نسخهٔ مطلوب (خودکفا و بدون global):**

```php
<?php
$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12]
];

function printReportGood($list, $limit = 10) {
    foreach ($list as $id => $student) {
        $status = ($student["score"] >= $limit) ? "Passed" : "Failed";
        echo $id . " | " . $student["name"] . " | " . $student["score"] . " | " . $status . "<br>";
    }
}

printReportGood($students);
echo "<br>";
echo "With limit 15:<br>";
printReportGood($students, 15);
?>
```

**خروجی:**
```
s101 | Ali | 18 | Passed
s102 | Sara | 9 | Failed
s103 | Reza | 12 | Passed

With limit 15:
s101 | Ali | 18 | Passed
s102 | Sara | 9 | Failed
s103 | Reza | 12 | Failed
```

**تحلیل:** نسخهٔ دوم هیچ وابستگی به بیرون ندارد؛ حد قبولی به‌صورت پارامتر پاس می‌شود و امکان آزمودن رفتار تابع با حدهای مختلف بدون تغییر کد فراهم است.

---

## ۷. مثال ۲: روزهای هفته با استفاده از آرایهٔ سراسری

در این مثال، نام روزهای هفته در یک آرایهٔ سراسری نگهداری می‌شود و تابع با استفاده از `$GLOBALS` به آن دسترسی پیدا می‌کند. سپس مقایسه‌ای با نسخهٔ پارامتری ارائه می‌شود.

**نسخهٔ مبتنی بر $GLOBALS:**

```php
<?php
$days = [
    1 => "Saturday",
    2 => "Sunday",
    3 => "Monday",
    4 => "Tuesday",
    5 => "Wednesday",
    6 => "Thursday",
    7 => "Friday"
];

function getDayNameGlobal($number) {
    if (isset($GLOBALS["days"][$number])) {
        return $GLOBALS["days"][$number];
    }
    return "Invalid day number";
}

echo getDayNameGlobal(1);   // Saturday
echo "<br>";
echo getDayNameGlobal(5);   // Wednesday
echo "<br>";
echo getDayNameGlobal(9);   // Invalid day number
?>
```

**نسخهٔ مطلوب (پاس دادن آرایه به‌صورت پارامتر):**

```php
<?php
function getDayName(array $days, $number, $fallback = "Invalid day number") {
    if (isset($days[$number])) {
        return $days[$number];
    }
    return $fallback;
}

$days = [
    1 => "Saturday",
    2 => "Sunday",
    3 => "Monday",
    4 => "Tuesday",
    5 => "Wednesday",
    6 => "Thursday",
    7 => "Friday"
];

echo getDayName($days, 3);    // Monday
echo "<br>";
echo getDayName($days, 7);    // Friday
echo "<br>";
echo getDayName($days, 0);    // Invalid day number
echo "<br>";
echo getDayName($days, 8, "Out of range");   // Out of range
?>
```

**تحلیل:** در نسخهٔ دوم، وابستگی تابع به محیط بیرونی حذف شده و تابع می‌تواند با هر مجموعهٔ دیگری از نام روزها (مثلاً انگلیسی یا فارسی) فراخوانی شود. این ویژگی همان **استفادهٔ مجدد** است.

## ۸. مثال ۳: متغیر ایستا برای شمارش تعداد دانش‌آموزان پردازش‌شده

```php
<?php
function processStudent($student) {
    static $processedCount = 0;
    $processedCount++;

    $status = ($student["score"] >= 10) ? "Passed" : "Failed";
    echo $processedCount . ". " . $student["name"] . " | " . $status . "<br>";
}

$students = [
    ["name" => "Ali",  "score" => 18],
    ["name" => "Sara", "score" => 8],
    ["name" => "Reza", "score" => 13]
];

foreach ($students as $student) {
    processStudent($student);
}
?>
```

**خروجی:**
```
1. Ali | Passed
2. Sara | Failed
3. Reza | Passed
```

**تحلیل:** متغیر `$processedCount` درون تابع تعریف شده و تنها در همان تابع قابل دسترسی است، اما مقدارش میان فراخوانی‌ها حفظ می‌شود؛ به همین دلیل شمارنده به‌درستی افزایش می‌یابد.

## ۹. متغیرهای ابرسراسری (Superglobals) — اشارهٔ کوتاه

علاوه بر `$GLOBALS`، PHP چند متغیر سراسری ویژهٔ دیگر نیز دارد که در **همهٔ محدوده‌ها**، از جمله درون توابع، بدون نیاز به `global` قابل دسترسی‌اند:

- `$_GET` — داده‌های ارسالی با متد GET
- `$_POST` — داده‌های ارسالی با متد POST
- `$_SERVER` — اطلاعات سرور و درخواست
- `$_SESSION` — داده‌های نشست
- `$_COOKIE` — کوکی‌ها
- `$_FILES` — فایل‌های بارگذاری‌شده
- `$_ENV` — متغیرهای محیطی

> **نکته:** این متغیرها در این مجموعه به‌طور تفصیلی بررسی نمی‌شوند و ذکر آن‌ها تنها برای تکمیل مبحث Scope است.

---

## ۱۰. نکات کلیدی این بخش

- هر متغیر تعریف‌شده درون تابع، **محلی** است و بیرون از تابع وجود ندارد.
- متغیرهای محلی همنام با متغیرهای سراسری، **کاملاً مستقل** هستند.
- برای دسترسی به متغیر سراسری درون تابع از `global` استفاده می‌شود، اما این کار **وابستگی پنهان** ایجاد می‌کند.
- `$GLOBALS` آرایه‌ای است که همهٔ متغیرهای سراسری را در دسترس قرار می‌دهد.
- استفاده از `global` و `$GLOBALS` را به حداقل برسانید و **پاس دادن پارامتر** را ترجیح دهید.
- متغیر `static` مقدار خود را میان فراخوانی‌های تابع حفظ می‌کند، اما همچنان **محلی** است.
- مقدار اولیهٔ متغیر `static` باید ثابت باشد.
- متغیرهای ابرسراسری در همهٔ محدوده‌ها قابل دسترسی‌اند و نیازی به `global` ندارند.

## تست‌های چهارگزینه‌ای

**سؤال ۱.** متغیری که درون یک تابع تعریف می‌شود، چه نوع Scope دارد؟
- الف) سراسری
- ب) محلی
- ج) ایستا
- د) ابرسراسری

**سؤال ۲.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$x = 10;
function test() {
    $x = 20;
}
test();
echo $x;
?>
```
- الف) `10`
- ب) `20`
- ج) `null`
- د) خطا

**سؤال ۳.** کدام کلیدواژه امکان دسترسی به متغیر سراسری درون تابع را فراهم می‌کند؟
- الف) `static`
- ب) `local`
- ج) `global`
- د) `public`

**سؤال ۴.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$y = 5;
function change() {
    global $y;
    $y = 15;
}
change();
echo $y;
?>
```
- الف) `5`
- ب) `15`
- ج) `null`
- د) خطا

**سؤال ۵.** آرایهٔ `$GLOBALS` چه چیزی را نگه می‌دارد؟
- الف) فقط متغیرهای محلی
- ب) همهٔ متغیرهای سراسری
- ج) فقط متغیرهای ایستا
- د) فقط ثابت‌ها

**سؤال ۶.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
function counter() {
    static $n = 0;
    $n++;
    return $n;
}
echo counter();
echo counter();
echo counter();
?>
```
- الف) `111`
- ب) `123`
- ج) `000`
- د) `333`

**سؤال ۷.** کدام گزینه دربارهٔ متغیر `static` صحیح است؟
- الف) از بیرون تابع قابل دسترسی است.
- ب) با هر فراخوانی مقدارش صفر می‌شود.
- ج) مقدارش میان فراخوانی‌ها حفظ می‌شود و محلی است.
- د) نمی‌توان آن را مقداردهی اولیه کرد.

**سؤال ۸.** کدام گزینه دربارهٔ `$GLOBALS` صحیح است؟
- الف) کلید هر عضو، نام متغیر با علامت `$` است.
- ب) کلید هر عضو، نام متغیر بدون علامت `$` است.
- ج) فقط شامل متغیرهای محلی است.
- د) از PHP 8.1 به بعد قابل تغییر کامل است.

**سؤال ۹.** چرا استفاده از کلیدواژهٔ `global` در برنامه‌نویسی اصولی توصیه نمی‌شود؟
- الف) سرعت اجرای برنامه را کاهش می‌دهد.
- ب) باعث وابستگی پنهان تابع به محیط بیرونی می‌شود.
- ج) فقط در PHP 7 کار می‌کند.
- د) با متغیرهای `static` تداخل دارد.

**سؤال ۱۰.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$days = [1 => "Saturday", 2 => "Sunday"];
function getDay($number) {
    if (isset($GLOBALS["days"][$number])) {
        return $GLOBALS["days"][$number];
    }
    return "Invalid";
}
echo getDay(2);
echo getDay(5);
?>
```
- الف) `SundayInvalid`
- ب) `InvalidSunday`
- ج) `SundaySunday`
- د) خطا

## پاسخنامهٔ تشریحی

**۱. پاسخ: ب** — هر متغیری که درون تابع تعریف شود، Scope محلی دارد و بیرون از تابع در دسترس نیست.

**۲. پاسخ: الف** — متغیر `$x` درون تابع، یک متغیر محلی مستقل است و تغییری در متغیر سراسری `$x` نمی‌دهد؛ بنابراین `10` چاپ می‌شود.

**۳. پاسخ: ج** — کلیدواژهٔ `global` متغیر سراسری را درون تابع قابل دسترسی می‌کند.

**۴. پاسخ: ب** — با `global $y;`، تابع به متغیر سراسری `$y` دسترسی پیدا می‌کند و مقدار آن را به `15` تغییر می‌دهد؛ لذا `15` چاپ می‌شود.

**۵. پاسخ: ب** — `$GLOBALS` آرایه‌ای است که همهٔ متغیرهای سراسری را در خود نگه می‌دارد.

**۶. پاسخ: ب** — متغیر `static $n` تنها یک‌بار مقدار `0` می‌گیرد و در هر فراخوانی یک واحد افزایش می‌یابد؛ نتیجه: `123`.

**۷. پاسخ: ج** — متغیر `static` همچنان محلی است، اما مقدارش میان فراخوانی‌های متوالی تابع حفظ می‌شود.

**۸. پاسخ: ب** — در `$GLOBALS`، کلید هر عضو نام متغیر **بدون** علامت `$` است؛ مثلاً برای `$passMark` کلید `"passMark"` است.

**۹. پاسخ: ب** — `global` باعث می‌شود تابع به متغیرهای بیرونی وابسته شود و دیگر خودکفا نباشد؛ این وابستگی پنهان، نگهداری و آزمون کد را دشوار می‌کند.

**۱۰. پاسخ: الف** — `getDay(2)` مقدار `Sunday` و `getDay(5)` مقدار `Invalid` را برمی‌گرداند؛ چون هر دو بدون جداکننده چاپ می‌شوند، خروجی `SundayInvalid` است.
