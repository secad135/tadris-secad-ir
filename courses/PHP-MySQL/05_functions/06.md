## توابع ناشناس و توابع پیکانی

> این مطلب منبع امتحانی نیست

### ۱. توابع ناشناس (Closures)

**تابع ناشناس** یا **Closure**، تابعی است که **نام مشخصی ندارد** و معمولاً به‌عنوان مقدار یک متغیر یا آرگومان یک تابع دیگر (Callback) به کار می‌رود. PHP این عبارات را به‌طور خودکار به نمونه‌ای از کلاس داخلی `Closure` تبدیل می‌کند.

**ساختار:**
```php
$variableName = function ($parameter) {
    // بدنه
    return $result;
};
```

**مثال ساده:**
```php
<?php
$greet = function ($name) {
    return "Hello, " . $name;
};

echo $greet("Ali");    // Hello, Ali
echo "<br>";
echo $greet("Sara");   // Hello, Sara
?>
```

> **نکته:** تابع ناشناس نیز مانند هر متغیر دیگری با `;` پایان می‌یابد و از طریق نام متغیر فراخوانی می‌شود.

---

### ۲. به ارث بردن متغیرها با use

تابع ناشناس به‌طور پیش‌فرض به متغیرهای **بیرون از خود** دسترسی ندارد. برای دسترسی به متغیرهای Scope والد، باید از ساختار `use` استفاده کرد.

```php
<?php
$passMark = 10;

$checkGrade = function ($score) use ($passMark) {
    if ($score >= $passMark) {
        return "Passed";
    }
    return "Failed";
};

echo $checkGrade(12);   // Passed
echo "<br>";
echo $checkGrade(8);    // Failed
?>
```

**نکتهٔ مهم دربارهٔ مقدار متغیر در use:** متغیر به‌صورت **مقداری (By Value)** در لحظهٔ **تعریف** تابع کپی می‌شود، نه در لحظهٔ فراخوانی.

```php
<?php
$message = "hello";

$example = function () use ($message) {
    return $message;
};

$message = "world";
echo $example();   // hello  (مقدار زمان تعریف، نه فراخوانی)
?>
```

برای اینکه تابع ناشناس تغییرات متغیر بیرونی را ببیند، از `use (&$variable)` استفاده کنید (ارجاع).

```php
<?php
$message = "hello";

$example = function () use (&$message) {
    return $message;
};

$message = "world";
echo $example();   // world
?>
```

### ۳. توابع پیکانی (Arrow Functions)

**توابع پیکانی** در PHP 7.4 معرفی شدند و **نحو مختصرتر** توابع ناشناس هستند. ساختار آن‌ها به‌صورت `fn (argument_list) => expr` است.

**ساختار:**
```php
$variableName = fn($parameter) => expression;
```

**مثال:**
```php
<?php
$double = fn($x) => $x * 2;

echo $double(5);    // 10
echo "<br>";
echo $double(12);   // 24
?>
```

**تفاوت کلیدی با توابع ناشناس:** در توابع پیکانی، متغیرهای Scope والد **به‌طور خودکار** و به‌صورت **مقداری** ضبط می‌شوند و نیازی به `use` نیست.

```php
<?php
$multiplier = 3;

// تابع ناشناس: نیاز به use
$fn1 = function ($n) use ($multiplier) {
    return $n * $multiplier;
};

// تابع پیکانی: بدون use، خودکار
$fn2 = fn($n) => $n * $multiplier;

echo $fn1(5);    // 15
echo "<br>";
echo $fn2(5);    // 15
?>
```

> **نکته:** توابع پیکانی فقط می‌توانند شامل **یک عبارت (Expression)** باشند. بنابراین نمی‌توانند دستورات چندخطی، شرط‌های `if` یا `return` صریح داشته باشند. برای منطق پیچیده‌تر از تابع ناشناس استفاده کنید.

### ۴. کاربرد توابع ناشناس و پیکانی در Callbackها

**Callback** تابعی است که به‌عنوان آرگومان به تابع دیگری پاس داده می‌شود تا آن تابع، در زمان مناسب آن را فراخوانی کند. توابع ناشناس و پیکانی رایج‌ترین شکل نوشتن Callback در PHP هستند.

#### ۴-۱. array_map با تابع پیکانی

`array_map` یک تابع را روی همهٔ اعضای آرایه اعمال می‌کند و آرایهٔ جدیدی برمی‌گرداند.

```php
<?php
$scores = [15, 18, 12, 9, 20];

$bonusScores = array_map(fn($s) => $s + 1, $scores);

print_r($bonusScores);
// Array ( [0] => 16 [1] => 19 [2] => 13 [3] => 10 [4] => 21 )
?>
```

#### ۴-۲. array_filter با تابع پیکانی

`array_filter` اعضایی را نگه می‌دارد که Callback برای آن‌ها مقدار `true` برگرداند.

```php
<?php
$scores = [15, 18, 12, 9, 20];

$passed = array_filter($scores, fn($s) => $s >= 10);

print_r($passed);
// Array ( [0] => 15 [1] => 18 [2] => 12 [4] => 20 )
?>
```

#### ۴-۳. usort با تابع پیکانی

`usort` آرایه را بر اساس یک Callback مقایسه‌ای مرتب می‌کند. Callback باید عددی منفی، صفر یا مثبت برگرداند.

```php
<?php
$scores = [15, 18, 12, 9, 20];

usort($scores, fn($a, $b) => $b <=> $a);   // نزولی

print_r($scores);
// Array ( [0] => 20 [1] => 18 [2] => 15 [3] => 12 [4] => 9 )
?>
```

### ۵. مثال ۱: پردازش نمرات با توابع ناشناس و پیکانی

در این مثال، گروهی از دانش‌آموزان در یک آرایهٔ دوبعدی انجمنی ذخیره شده‌اند. با ترکیب `array_map`، `array_filter` و `usort` و توابع پیکانی، نمرات را پردازش می‌کنیم.

```php
<?php
$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12],
    "s104" => ["name" => "Mina", "score" => 7],
    "s105" => ["name" => "Omid", "score" => 15]
];

// استخراج نمرات با array_map و تابع پیکانی
$scores = array_map(fn($student) => $student["score"], $students);
print_r($scores);
// Array ( [s101] => 18 [s102] => 9 [s103] => 12 [s104] => 7 [s105] => 15 )

echo "<br>";

// فیلتر نمرات قبولی (>= 10)
$passedScores = array_filter($scores, fn($score) => $score >= 10);
print_r($passedScores);
// Array ( [s101] => 18 [s103] => 12 [s105] => 15 )

echo "<br>";

// مرتب‌سازی نمرات به‌صورت نزولی
usort($scores, fn($a, $b) => $b <=> $a);
print_r($scores);
// Array ( [0] => 18 [1] => 15 [2] => 12 [3] => 9 [4] => 7 )
?>
```

**تحلیل:**
- `array_map` با تابع پیکانی، نمرهٔ هر دانش‌آموز را از آرایهٔ انجمنی استخراج می‌کند.
- `array_filter` با تابع پیکانی، نمرات کمتر از ۱۰ را حذف می‌کند.
- `usort` با تابع پیکانی و عملگر `<=>`، آرایه را نزولی مرتب می‌کند.
- در تمام موارد، تابع پیکانی به‌دلیل سادگی منطق (یک عبارت) انتخاب شده است.

### ۶. مثال ۲: تشخیص قبولی/مردودی با تابع ناشناس دارای use

در این مثال، حد قبولی به‌عنوان یک متغیر بیرونی تعریف شده و تابع ناشناس با `use` به آن دسترسی پیدا می‌کند. سپس گزارش گروهی تولید می‌شود.

```php
<?php
$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12],
    "s104" => ["name" => "Mina", "score" => 7],
    "s105" => ["name" => "Omid", "score" => 15]
];

$passMark = 10;

$getStatus = function ($score) use ($passMark) {
    if ($score >= $passMark) {
        return "PASSED";
    }
    return "FAILED";
};

foreach ($students as $id => $student) {
    echo $id . " | " . $student["name"] . " | "
         . $student["score"] . " | " . $getStatus($student["score"]) . "<br>";
}
?>
```

**خروجی:**
```
s101 | Ali | 18 | PASSED
s102 | Sara | 9 | FAILED
s103 | Reza | 12 | PASSED
s104 | Mina | 7 | FAILED
s105 | Omid | 15 | PASSED
```

**تحلیل:**
- `$passMark` در Scope والد تعریف شده و تابع ناشناس با `use ($passMark)` به آن دسترسی یافته است.
- از تابع ناشناس (نه پیکانی) استفاده شده زیرا بدنه شامل `if` و دو `return` است و منطق آن فراتر از یک عبارت واحد است.
- تابع ناشناس در متغیر `$getStatus` ذخیره شده و بارها فراخوانی می‌گردد.

### ۷. مثال ۳: روزهای هفته و ماه‌های شمسی با Callback

در این مثال، از `array_map` با تابع پیکانی برای تبدیل شماره‌ها به نام روز یا ماه استفاده می‌کنیم.

**روزهای هفته:**
```php
<?php
$days = [
    1 => "Saturday",
    2 => "Sunday",
    3 => "Monday",
    4 => "Tuesday",
    5 => "Wednesday",
    6 => "Thursday",
    7 => "Friday"
];

$numbers = [1, 3, 5, 7];

$dayNames = array_map(fn($n) => $days[$n] ?? "invalid", $numbers);

print_r($dayNames);
// Array ( [0] => Saturday [1] => Monday [2] => Wednesday [3] => Friday )
?>
```

**ماه‌های شمسی:**
```php
<?php
$months = [
    1 => "Farvardin", 2 => "Ordibehesht", 3 => "Khordad",
    4 => "Tir",       5 => "Mordad",      6 => "Shahrivar",
    7 => "Mehr",      8 => "Aban",        9 => "Azar",
    10 => "Dey",      11 => "Bahman",     12 => "Esfand"
];

$monthNumbers = [1, 4, 7, 10, 12, 15];

$monthNames = array_map(fn($n) => $months[$n] ?? "invalid", $monthNumbers);

print_r($monthNames);
// Array ( [0] => Farvardin [1] => Tir [2] => Mehr [3] => Dey [4] => Esfand [5] => invalid )
?>
```

**تحلیل:**
- عملگر `??` (Null Coalescing) درون تابع پیکانی، مقدار پیش‌فرض `"invalid"` را برای کلیدهای نامعتبر فراهم می‌کند.
- تابع پیکانی برای این تبدیل ساده، بسیار خواناتر از تابع ناشناس معادل است.

---

### ۸. مقایسهٔ تابع ناشناس و تابع پیکانی

| ویژگی | تابع ناشناس (Closure) | تابع پیکانی (Arrow) |
|--------|------------------------|----------------------|
| نحو | `function ($x) { ... }` | `fn($x) => ...` |
| نسخهٔ PHP | همهٔ نسخه‌ها | ۷.۴ به بعد |
| دسترسی به Scope والد | نیازمند `use` | **خودکار** (مقداری) |
| بدنه | چندخطی، شامل `if`، `return` | فقط **یک عبارت** |
| نوع بازگشتی `void` | مجاز | **مجاز نیست** |
| تغییر متغیر بیرونی | با `use (&$var)` | **ممکن نیست** |
| مناسب برای | منطق پیچیده، چند مرحله‌ای | تبدیل‌های کوتاه و ساده |

> **قاعدهٔ کلی:** برای عملیات ساده و یک‌عبارتی از تابع پیکانی استفاده کنید؛ برای منطق دارای شرط، چند دستور یا تغییر متغیر بیرونی، تابع ناشناس انتخاب صحیح است.

---

### ۹. نکات کلیدی این بخش

- تابع ناشناس (Closure) تابعی بدون نام است که در متغیر ذخیره یا به‌عنوان Callback پاس داده می‌شود.
- برای دسترسی به متغیرهای Scope والد در تابع ناشناس، از `use` استفاده کنید.
- `use` مقدار متغیر را در زمان **تعریف** تابع کپی می‌کند، نه در زمان فراخوانی.
- با `use (&$var)` می‌توان متغیر را با ارجاع ضبط کرد.
- تابع پیکانی (`fn`) نحو مختصر توابع ناشناس است و از PHP 7.4 به بعد در دسترس است.
- تابع پیکانی متغیرهای بیرونی را به‌طور خودکار و مقداری ضبط می‌کند و نیازی به `use` ندارد.
- تابع پیکانی فقط یک عبارت می‌پذیرد و نمی‌تواند `void` برگرداند.
- `array_map`، `array_filter` و `usort` از مهم‌ترین توابع دریافت‌کنندهٔ Callback هستند.
- برای منطق ساده از تابع پیکانی و برای منطق پیچیده از تابع ناشناس استفاده کنید.

### تست‌های چهارگزینه‌ای

**سؤال ۱.** تابع ناشناس در PHP با کدام کلاس داخلی پیاده‌سازی می‌شود؟
- الف) `Function`
- ب) `Closure`
- ج) `Anonymous`
- د) `Callable`

**سؤال ۲.** برای دسترسی به متغیر بیرونی در تابع ناشناس از کدام ساختار استفاده می‌شود؟
- الف) `global`
- ب) `static`
- ج) `use`
- د) `$GLOBALS`

**سؤال ۳.** تابع پیکانی از کدام نسخهٔ PHP معرفی شده است؟
- الف) PHP 5.6
- ب) PHP 7.0
- ج) PHP 7.4
- د) PHP 8.0

**سؤال ۴.** نحو صحیح تابع پیکانی برای دو برابر کردن عدد چیست؟
- الف) `fn($x) => $x * 2`
- ب) `function($x) => $x * 2`
- ج) `fn($x) { return $x * 2; }`
- د) `arrow($x) => $x * 2`

**سؤال ۵.** تابع پیکانی چه محدودیتی دارد؟
- الف) نمی‌تواند پارامتر بگیرد.
- ب) فقط یک عبارت می‌پذیرد.
- ج) نمی‌تواند مقدار برگرداند.
- د) فقط با `array_map` کار می‌کند.

**سؤال ۶.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$x = 5;
$fn = fn($n) => $n + $x;
echo $fn(10);
?>
```
- الف) `10`
- ب) `15`
- ج) `5`
- د) خطا

**سؤال ۷.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$message = "hello";
$fn = function () use ($message) {
    return $message;
};
$message = "world";
echo $fn();
?>
```
- الف) `hello`
- ب) `world`
- ج) `null`
- د) خطا

**سؤال ۸.** کدام تابع برای فیلتر کردن اعضای آرایه با یک Callback استفاده می‌شود؟
- الف) `array_map`
- ب) `array_filter`
- ج) `usort`
- د) `array_sum`

**سؤال ۹.** خروجی قطعهٔ کد زیر چیست؟
```php
<?php
$numbers = [1, 2, 3];
$result = array_map(fn($n) => $n * 3, $numbers);
print_r($result);
?>
```
- الف) `[1, 2, 3]`
- ب) `[3, 6, 9]`
- ج) `[3, 3, 3]`
- د) `[1, 4, 9]`

**سؤال ۱۰.** چرا برای منطق دارای `if` و چند `return` نباید از تابع پیکانی استفاده کرد؟
- الف) تابع پیکانی از `if` پشتیبانی نمی‌کند و فقط یک عبارت می‌پذیرد.
- ب) تابع پیکانی کندتر است.
- ج) تابع پیکانی به متغیرهای بیرونی دسترسی ندارد.
- د) تابع پیکانی در PHP 8 حذف شده است.

### پاسخنامهٔ تشریحی

**۱. پاسخ: ب** — توابع ناشناس در PHP با کلاس داخلی `Closure` پیاده‌سازی می‌شوند.

**۲. پاسخ: ج** — ساختار `use` برای به ارث بردن متغیرهای Scope والد در تابع ناشناس به کار می‌رود.

**۳. پاسخ: ج** — توابع پیکانی در PHP 7.4 معرفی شدند.

**۴. پاسخ: الف** — ساختار صحیح `fn($x) => $x * 2` است. گزینهٔ «ج» بدنهٔ بلوکی دارد که در تابع پیکانی مجاز نیست.

**۵. پاسخ: ب** — تابع پیکانی فقط یک عبارت (Expression) می‌پذیرد و نمی‌تواند شامل چند دستور یا ساختارهای کنترلی باشد.

**۶. پاسخ: ب** — تابع پیکانی متغیر `$x` را به‌طور خودکار ضبط می‌کند؛ `10 + 5 = 15`.

**۷. پاسخ: الف** — `use` مقدار متغیر را در زمان **تعریف** تابع کپی می‌کند. در زمان تعریف، `$message` برابر `"hello"` بود؛ تغییر بعدی آن بر تابع اثر ندارد.

**۸. پاسخ: ب** — `array_filter` اعضای آرایه را بر اساس Callback فیلتر می‌کند.

**۹. پاسخ: ب** — `array_map` تابع `fn($n) => $n * 3` را روی هر عضو اعمال می‌کند: `[3, 6, 9]`.

**۱۰. پاسخ: الف** — تابع پیکانی فقط یک عبارت می‌پذیرد و از بلوک دستورات، `if` و `return` صریح پشتیبانی نمی‌کند؛ برای چنین منطقی باید از تابع ناشناس استفاده کرد.
