# توابع بازگشتی و توابع مولد

> این مطلب منبع امتحانی نیست

## ۱. تعریف تابع بازگشتی

**تابع بازگشتی** تابعی است که در بدنهٔ خود، **خودش را فراخوانی می‌کند**. این الگو برای مسائلی مناسب است که می‌توان آن‌ها را به نسخه‌های کوچک‌تر و مشابه همان مسئله تقسیم کرد.

هر تابع بازگشتی **باید** دو بخش داشته باشد:

| بخش | توضیح |
|------|--------|
| **شرط توقف (Base Case)** | حالتی که در آن تابع دیگر خودش را فراخوانی نمی‌کند و مقدار مشخصی برمی‌گرداند. |
| **شرط بازگشتی (Recursive Case)** | حالتی که تابع با ورودی کوچک‌تر، خودش را فراخوانی می‌کند. |

> **هشدار مهم:** اگر شرط توقف وجود نداشته باشد یا هرگز برقرار نشود، تابع بی‌پایان خودش را فراخوانی می‌کند و در نهایت خطای **«حداکثر عمق پشته» (Maximum function nesting level / Stack Overflow)** یا اتمام حافظه رخ می‌دهد.

---

## ۲. مثال ۱: محاسبهٔ فاکتوریل

فاکتوریل عدد `n` برابر است با حاصل‌ضرب اعداد ۱ تا `n`. تعریف بازگشتی آن چنین است: `n! = n × (n-1)!` و `1! = 1`.

```php
<?php
function factorial(int $n): int {
    if ($n <= 1) {
        return 1;
    }
    return $n * factorial($n - 1);
}

echo factorial(5);   // 120
echo "<br>";
echo factorial(3);   // 6
echo "<br>";
echo factorial(1);   // 1
?>
```

**ردیابی اجرا برای `factorial(3)`:**

```
factorial(3) = 3 * factorial(2)
             = 3 * (2 * factorial(1))
             = 3 * (2 * 1)
             = 6
```

**تحلیل:** شرط `$n <= 1` نقش **شرط توقف** را دارد و خط `return $n * factorial($n - 1);` نقش **شرط بازگشتی** را ایفا می‌کند.

## ۳. مثال ۲: مجموع اعداد ۱ تا n

```php
<?php
function sumTo(int $n): int {
    if ($n <= 0) {
        return 0;
    }
    return $n + sumTo($n - 1);
}

echo sumTo(4);    // 10
echo "<br>";
echo sumTo(10);   // 55
?>
```

**تحلیل:** شرط توقف `$n <= 0` است. هر فراخوانی، ورودی را یک واحد کاهش می‌دهد تا در نهایت به شرط توقف برسد.

> **نکته:** برای چنین محاسبات ساده‌ای، راه‌حل غیربازگشتی (حلقه یا فرمول ریاضی) کارآمدتر است. بازگشت زمانی ارزشمند است که ساختار مسئله به‌طور طبیعی بازگشتی باشد (مانند پیمایش ساختارهای تودرتو یا درخت‌ها).

---

## ۴. مثال ۳: پیمایش آرایهٔ تودرتو با آرایهٔ دوبعدی انجمنی

در این مثال، دانش‌آموزان در چند کلاس گروه‌بندی شده‌اند و هر کلاس، خود آرایه‌ای انجمنی از دانش‌آموزان است. با تابع بازگشتی، تعداد قبولی‌ها را در **همهٔ سطوح** می‌شماریم.

```php
<?php
$classes = [
    "classA" => [
        "s101" => ["name" => "Ali",  "score" => 18],
        "s102" => ["name" => "Sara", "score" => 9]
    ],
    "classB" => [
        "s103" => ["name" => "Reza", "score" => 12],
        "s104" => ["name" => "Mina", "score" => 7]
    ],
    "classC" => [
        "s105" => ["name" => "Omid", "score" => 15],
        "s106" => ["name" => "Neda", "score" => 10]
    ]
];

function countPassed(array $list, int $limit = 10): int {
    $count = 0;
    foreach ($list as $item) {
        if (!is_array($item)) {
            continue;
        }
        if (isset($item["score"])) {
            if ($item["score"] >= $limit) {
                $count++;
            }
        } else {
            $count += countPassed($item, $limit);
        }
    }
    return $count;
}

echo countPassed($classes);          // 4
echo "<br>";
echo countPassed($classes, 15);      // 2
?>
```

**خروجی:**
```
4
2
```

**تحلیل:**
- اگر عضو جاری دارای کلید `score` باشد، یک دانش‌آموز است و شرط قبولی بررسی می‌شود.
- اگر عضو جاری آرایه‌ای بدون کلید `score` باشد، یک کلاس است و تابع **خودش را برای آن کلاس** فراخوانی می‌کند.
- شرط توقف، **ضمنی** است: وقتی هیچ آرایهٔ تودرتویی باقی نماند، حلقه پایان می‌یابد و مقدار `$count` برگردانده می‌شود.
- تابع بدون توجه به تعداد سطوح تودرتویی کار می‌کند؛ این مزیت اصلی بازگشت است.

## ۵. مثال ۴: چاپ روزهای هفته به‌صورت بازگشتی

```php
<?php
$days = [
    1 => "Saturday",
    2 => "Sunday",
    3 => "Monday",
    4 => "Tuesday",
    5 => "Wednesday",
    6 => "Thursday",
    7 => "Friday"
];

function printDays(array $days, int $current, int $last): void {
    if ($current > $last) {
        return;
    }
    echo $current . " => " . $days[$current] . "<br>";
    printDays($days, $current + 1, $last);
}

printDays($days, 1, 7);
?>
```

**خروجی:**
```
1 => Saturday
2 => Sunday
3 => Monday
4 => Tuesday
5 => Wednesday
6 => Thursday
7 => Friday
```

**تحلیل:** شرط توقف `$current > $last` است. هر فراخوانی، شمارنده را یک واحد افزایش می‌دهد. نوع بازگشتی `void` است چون تابع فقط چاپ می‌کند و مقداری برنمی‌گرداند.

## ۶. مثال ۵: ساخت فهرست ماه‌های شمسی با بازگشت

```php
<?php
$months = [
    1 => "Farvardin", 2 => "Ordibehesht", 3 => "Khordad",
    4 => "Tir",       5 => "Mordad",      6 => "Shahrivar",
    7 => "Mehr",      8 => "Aban",        9 => "Azar",
    10 => "Dey",      11 => "Bahman",     12 => "Esfand"
];

function monthNames(array $months, int $n): array {
    if ($n < 1) {
        return [];
    }
    return array_merge(monthNames($months, $n - 1), [$months[$n]]);
}

print_r(monthNames($months, 3));
// Array ( [0] => Farvardin [1] => Ordibehesht [2] => Khordad )

echo "<br>";

print_r(monthNames($months, 0));
// Array ( )
?>
```

**تحلیل:** شرط توقف `$n < 1` است و آرایهٔ خالی برمی‌گرداند. هر بازگشت، فهرست ماه‌های قبلی را با ماه جاری ترکیب می‌کند. این الگو نشان می‌دهد تابع بازگشتی می‌تواند **آرایه** برگرداند.

## ۷. تفاوت متغیر ایستا و بازگشت

| مفهوم | کاربرد |
|--------|---------|
| متغیر `static` | نگه‌داشتن وضعیت میان **فراخوانی‌های مستقل** تابع |
| بازگشت (Recursion) | حل مسئله با فراخوانی **تودرتوی** تابع توسط خودش |

این دو با هم نیز به کار می‌روند: متغیر `static` می‌تواند تعداد کل فراخوانی‌های یک تابع بازگشتی را بشمارد.

```php
<?php
function countdown(int $n): void {
    static $calls = 0;
    $calls++;

    if ($n <= 0) {
        echo "Total calls: " . $calls;
        return;
    }

    echo $n . " ";
    countdown($n - 1);
}

countdown(3);   // 3 2 1 Total calls: 4
?>
```

**تحلیل:** تابع چهار بار فراخوانی می‌شود (سه بار برای اعداد ۳، ۲، ۱ و یک بار برای رسیدن به شرط توقف). متغیر `static` مقدار خود را در همهٔ این فراخوانی‌های تودرتو حفظ می‌کند.

---

## ۸. مروری کوتاه بر توابع مولد (Generators)

**تابع مولد** تابعی است که به‌جای بازگرداندن یک‌بارهٔ همهٔ مقادیر، آن‌ها را **یکی‌یکی** تولید می‌کند. برای ساخت مولد از کلیدواژهٔ `yield` استفاده می‌شود.

```php
<?php
function scoreGenerator(array $scores) {
    foreach ($scores as $score) {
        yield $score;
    }
}

$scores = [18, 9, 12, 7, 15];

foreach (scoreGenerator($scores) as $score) {
    if ($score >= 10) {
        echo $score . " Passed<br>";
    }
}
?>
```

**خروجی:**
```
18 Passed
12 Passed
15 Passed
```

**تحلیل:** تابع `scoreGenerator` هیچ آرایه‌ای نمی‌سازد؛ در هر تکرار `foreach`، یک مقدار تولید و تحویل می‌دهد. مزیت اصلی مولدها **کاهش مصرف حافظه** در پردازش مجموعه‌های بزرگ است، زیرا همهٔ مقادیر هم‌زمان در حافظه نگه داشته نمی‌شوند.

> **نکته:** تابع مولد را می‌توان به‌صورت بازگشتی نیز به کار برد (با `yield from`)، اما این موضوع فراتر از سطح این مجموعه است و تنها برای آشنایی ذکر می‌شود.

---

## ۹. نکات کلیدی این بخش

- تابع بازگشتی، تابعی است که خودش را فراخوانی می‌کند.
- هر تابع بازگشتی باید **شرط توقف** داشته باشد؛ در غیر این صورت خطای Stack Overflow رخ می‌دهد.
- در هر فراخوانی بازگشتی، ورودی باید به سمت شرط توقف **نزدیک‌تر** شود.
- بازگشت برای ساختارهای تودرتو و مسائل با تعریف بازگشتی مناسب است.
- برای مسائل ساده، راه‌حل غیربازگشتی معمولاً سریع‌تر و کم‌مصرف‌تر است.
- متغیر `static` می‌تواند تعداد فراخوانی‌های یک تابع بازگشتی را بشمارد.
- تابع مولد با `yield` مقادیر را یکی‌یکی تولید می‌کند و حافظهٔ کمتری مصرف می‌کند.

---

## تست‌های چهارگزینه‌ای

**سؤال ۱.** تابع بازگشتی چه ویژگی دارد؟
- الف) هیچ پارامتری نمی‌پذیرد.
- ب) خودش را فراخوانی می‌کند.
- ج) همیشه آرایه برمی‌گرداند.
- د) فقط با حلقه کار می‌کند.

**سؤال ۲.** اگر تابع بازگشتی شرط توقف نداشته باشد، چه اتفاقی می‌افتد؟
- الف) تابع مقدار `null` برمی‌گرداند.
- ب) PHP خطای نحوی می‌دهد.
- ج) بازگشت بی‌پایان رخ می‌دهد و خطای Stack Overflow صادر می‌شود.
- د) تابع به‌طور خودکار متوقف می‌شود.

**سؤال ۳.** خروجی `factorial(5)` در تابع بازگشتی مثال درس چیست؟
- الف) `25`
- ب) `120`
- ج) `5`
- د) `15`

**سؤال ۴.** خروجی `sumTo(4)` با شرط توقف `$n <= 0` چیست؟
- الف) `4`
- ب) `8`
- ج) `10`
- د) `24`

**سؤال ۵.** در تابع بازگشتی، کدام بخش مانع ادامهٔ بی‌پایان می‌شود؟
- الف) شرط بازگشتی
- ب) شرط توقف (Base Case)
- ج) پارامتر پیش‌فرض
- د) نوع بازگشتی

**سؤال ۶.** خروجی `countPassed($classes)` در مثال آرایهٔ تودرتو (با حد قبولی ۱۰) چیست؟
- الف) `3`
- ب) `4`
- ج) `5`
- د) `6`

**سؤال ۷.** کدام کلیدواژه تابع را به مولد (Generator) تبدیل می‌کند؟
- الف) `return`
- ب) `static`
- ج) `yield`
- د) `global`

**سؤال ۸.** مزیت اصلی تابع مولد چیست؟
- الف) سرعت بالاتر در همهٔ موارد
- ب) مصرف حافظهٔ کمتر در پردازش مجموعه‌های بزرگ
- ج) امکان تعریف تابع بدون نام
- د) جلوگیری از خطاهای نحوی

**سؤال ۹.** خروجی `monthNames($months, 3)` در مثال درس چیست؟
- الف) `[Farvardin]`
- ب) `[Farvardin, Ordibehesht]`
- ج) `[Farvardin, Ordibehesht, Khordad]`
- د) `[]`

**سؤال ۱۰.** در تابع `countdown(3)` با متغیر `static $calls`، مقدار چاپ‌شده برای `Total calls` چند است؟
- الف) `3`
- ب) `4`
- ج) `1`
- د) `0`

## پاسخنامهٔ تشریحی

**۱. پاسخ: ب** — ویژگی تعریف‌کنندهٔ تابع بازگشتی، فراخوانی خودش در بدنهٔ خود است.

**۲. پاسخ: ج** — بدون شرط توقف، فراخوانی‌ها بی‌پایان ادامه می‌یابند تا پشتهٔ فراخوانی سرریز شود و خطای Stack Overflow یا اتمام حافظه رخ دهد.

**۳. پاسخ: ب** — `5 × 4 × 3 × 2 × 1 = 120`.

**۴. پاسخ: ج** — `4 + 3 + 2 + 1 + 0 = 10`.

**۵. پاسخ: ب** — شرط توقف (Base Case) حالتی است که در آن تابع دیگر خودش را فراخوانی نمی‌کند.

**۶. پاسخ: ب** — دانش‌آموزان با نمرهٔ ۱۸، ۱۲، ۱۵ و ۱۰ قبول‌اند؛ مجموعاً ۴ نفر.

**۷. پاسخ: ج** — کلیدواژهٔ `yield` تابع را به مولد تبدیل می‌کند.

**۸. پاسخ: ب** — مولد مقادیر را یکی‌یکی تولید می‌کند و همهٔ آن‌ها را هم‌زمان در حافظه نگه نمی‌دارد.

**۹. پاسخ: ج** — بازگشت تا `$n = 3` ادامه می‌یابد و سه ماه اول را در آرایه جمع می‌کند.

**۱۰. پاسخ: ب** — تابع چهار بار فراخوانی می‌شود: برای ۳، ۲، ۱ و یک بار برای رسیدن به شرط توقف (`$n <= 0`).

# جمع‌بندی و کارگاه عملی

## ۱. مرور کلی مفاهیم

| موضوع | مهم‌ترین نکات |
|--------|----------------|
| تعریف تابع | با `function`؛ بدون فراخوانی اجرا نمی‌شود؛ نام حساس به حروف بزرگ و کوچک نیست |
| پارامتر و آرگومان | پارامتر در تعریف، آرگومان در فراخوانی |
| مقدار پیش‌فرض | باید بعد از پارامترهای اجباری بیاید و مقداری ثابت باشد |
| انواع داده | تعیین نوع پارامتر و مقدار بازگشتی؛ `declare(strict_types=1)` تبدیل خودکار را غیرفعال می‌کند |
| دستور return | مقدار را برمی‌گرداند و اجرا را متوقف می‌کند؛ هر تابع فقط یک مقدار برمی‌گرداند |
| ارسال با ارجاع | با `&`؛ تابع می‌تواند متغیر اصلی را تغییر دهد |
| Variadic | با `...`؛ باید آخرین پارامتر باشد |
| Scope | متغیر محلی، سراسری، `global`، `$GLOBALS`، `static` |
| الحاق فایل | `include` (هشدار) در برابر `require` (خطای کشنده)؛ `_once` برای جلوگیری از تکرار |
| توابع پیش‌ساخته | رشته، ریاضی، آرایه، تاریخ، فایل |
| توابع ناشناس | با `use`؛ مقدار در زمان تعریف کپی می‌شود |
| توابع پیکانی | `fn` از PHP 7.4؛ فقط یک عبارت؛ ضبط خودکار متغیرها |
| بازگشت | نیازمند شرط توقف؛ مناسب ساختارهای تودرتو |
| مولد | `yield`؛ مصرف حافظهٔ کمتر |

---

## ۲. مثال پروژه‌ای کوچک

این پروژه، مفاهیم اصلی مجموعه را در سه فایل ترکیب می‌کند: پیکربندی، داده و توابع، و فایل اصلی گزارش.

**فایل `config.php`:**

```php
<?php
if (!defined('APP_RUNNING')) {
    exit('Direct access not allowed');
}

define('PASS_MARK', 10);
$schoolTitle = "Sample High School";
?>
```

**فایل `students.php`:**

```php
<?php
if (!defined('APP_RUNNING')) {
    exit('Direct access not allowed');
}

$students = [
    "s101" => ["name" => "Ali",  "score" => 18],
    "s102" => ["name" => "Sara", "score" => 9],
    "s103" => ["name" => "Reza", "score" => 12],
    "s104" => ["name" => "Mina", "score" => 7],
    "s105" => ["name" => "Omid", "score" => 15]
];

function getStatus(array $student, int $limit = PASS_MARK): string {
    return ($student["score"] >= $limit) ? "PASSED" : "FAILED";
}

function classAverage(array $list): float {
    if (count($list) === 0) {
        return 0;
    }
    $scores = array_map(fn($student) => $student["score"], $list);
    return round(array_sum($scores) / count($scores), 2);
}

function countPassed(array $list, int $limit = PASS_MARK): int {
    $passed = array_filter($list, fn($student) => $student["score"] >= $limit);
    return count($passed);
}
?>
```

**فایل `report.php`:**

```php
<?php
define('APP_RUNNING', true);

require_once 'config.php';
require_once 'students.php';

$formatName = fn($name) => strtoupper($name);

echo "<h3>" . $schoolTitle . "</h3>";

foreach ($students as $id => $student) {
    echo $id . " | " . $formatName($student["name"]) . " | "
         . $student["score"] . " | " . getStatus($student) . "<br>";
}

echo "<br>";
echo "Total: " . count($students) . "<br>";
echo "Average: " . classAverage($students) . "<br>";
echo "Passed: " . countPassed($students) . "<br>";
echo "Report date: " . date("Y-m-d H:i:s") . "<br>";
?>
```

**خروجی:**
```
Sample High School

s101 | ALI | 18 | PASSED
s102 | SARA | 9 | FAILED
s103 | REZA | 12 | PASSED
s104 | MINA | 7 | FAILED
s105 | OMID | 15 | PASSED

Total: 5
Average: 12.2
Passed: 3
Report date: 2025-03-14 15:07:42
```

**تحلیل پروژه:**
- `require_once` برای الحاق **حیاتی** دو فایل استفاده شده و از الحاق مکرر جلوگیری می‌کند.
- ثابت نگهبان `APP_RUNNING` از دسترسی مستقیم به فایل‌های الحاقی محافظت می‌کند.
- ثابت `PASS_MARK` به‌عنوان مقدار پیش‌فرض پارامتر استفاده شده است.
- تابع پیکانی در `array_map` و `array_filter` و `$formatName` به کار رفته است.
- `count`، `array_sum`، `array_filter`، `array_map`، `round` و `date` از توابع پیش‌ساخته هستند.
- هیچ متغیر سراسری با `global` استفاده نشده؛ همهٔ وابستگی‌ها به‌صورت پارامتر پاس داده شده‌اند.

## ۴. پاسخنامهٔ آزمون جامع

**۱. پاسخ: ب** — کلیدواژهٔ `function` برای تعریف تابع به کار می‌رود.

**۲. پاسخ: ب** — پارامتر اختیاری دارای مقدار پیش‌فرض است و باید بعد از پارامترهای اجباری بیاید.

**۳. پاسخ: ب** — بخش پس از `:` نوع مقدار بازگشتی را مشخص می‌کند.

**۴. پاسخ: ج** — تابع بدون `return` مقدار `null` برمی‌گرداند.

**۵. پاسخ: الف** — متغیر `$x` درون تابع، محلی و مستقل است؛ متغیر سراسری تغییر نمی‌کند و `10` چاپ می‌شود.

**۶. پاسخ: ب** — متغیر `static` مقدار خود را میان فراخوانی‌ها حفظ می‌کند؛ خروجی `123` است.

**۷. پاسخ: ب** — در `$GLOBALS`، کلید هر عضو نام متغیر **بدون** علامت `$` است.

**۸. پاسخ: ب** — `require` در صورت نبود فایل، خطای کشنده صادر می‌کند و اجرا متوقف می‌شود.

**۹. پاسخ: ب** — `require_once` فایل را تنها یک‌بار الحاق می‌کند و از خطای «تعریف مجدد تابع یا کلاس» جلوگیری می‌نماید.

**۱۰. پاسخ: ب** — `"Sara"` چهار کاراکتر دارد.

**۱۱. پاسخ: ب** — از اندیس ۴ تا انتهای رشته برابر `"101"` است.

**۱۲. پاسخ: الف** — گرد کردن به دو رقم اعشار مقدار `3.14` را می‌دهد.

**۱۳. پاسخ: ج** — `10 + 20 + 30 = 60`.

**۱۴. پاسخ: ب** — با `strict=true`، مقایسه با `===` انجام می‌شود و رشتهٔ `"1"` با عدد `1` از نظر نوع برابر نیست.

**۱۵. پاسخ: الف** — `strtotime("+1 day")` timestamp فردا را می‌سازد و `date` آن را قالب‌بندی می‌کند.

**۱۶. پاسخ: ب** — پرچم `FILE_APPEND` محتوا را به انتهای فایل می‌افزاید.

**۱۷. پاسخ: ب** — تابع پیکانی متغیر `$x` را خودکار ضبط می‌کند؛ `10 + 5 = 15`.

**۱۸. پاسخ: الف** — `use` مقدار متغیر را در زمان **تعریف** تابع کپی می‌کند؛ مقدار آن زمان `"hello"` بود.

**۱۹. پاسخ: ب** — `4 × 3 × 2 × 1 = 24`.

**۲۰. پاسخ: ج** — کلیدواژهٔ `yield` تابع را به مولد تبدیل می‌کند.
