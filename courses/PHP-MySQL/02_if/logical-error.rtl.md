این کد یک خطای بسیار رایج در PHP را نشان می‌دهد که برای آموزش برنامه‌نویسی مثال بسیار خوبی است.

### کد

```php
<?php 
$roll = rand(1, 6);

echo 'You rolled a ' . $roll;

if ($roll = 6) {
  echo 'You win!';
}
```

---

## خطا چیست؟

اشتباه در این خط رخ داده است:

```php
if ($roll = 6)
```

در اینجا به جای **مقایسه**، عمل **انتساب (Assignment)** انجام شده است.

---

## تفاوت `=` و `==`

### عملگر انتساب (`=`)

```php
$roll = 6;
```

یعنی:

> مقدار ۶ را داخل متغیر `$roll` قرار بده.

این دستور مقدار قبلی متغیر را از بین می‌برد و آن را برابر ۶ می‌کند.

---

### عملگر مقایسه (`==`)

```php
$roll == 6
```

یعنی:

> بررسی کن آیا مقدار `$roll` برابر ۶ است یا خیر.

نتیجه این عبارت فقط یکی از دو مقدار زیر است:

* `true`
* `false`

---

## چرا این کد همیشه برنده می‌شود؟

فرض کنید:

```php
$roll = 3;
```

اکنون شرط اجرا می‌شود:

```php
if ($roll = 6)
```

در واقع ابتدا این اتفاق می‌افتد:

```php
$roll = 6;
```

پس مقدار متغیر به ۶ تغییر می‌کند.

از آنجا که مقدار ۶ در PHP یک مقدار **True** محسوب می‌شود، شرط نیز برقرار است و بدنه `if` اجرا می‌شود.

بنابراین خروجی همیشه چیزی شبیه این خواهد بود:

```
You rolled a 3
You win!
```

در حالی که تاس واقعاً ۳ آمده است.

---

## کد صحیح

باید از عملگر مقایسه استفاده شود:

```php
<?php
$roll = rand(1, 6);

echo 'You rolled a ' . $roll;

if ($roll == 6) {
    echo 'You win!';
}
```

اکنون تنها زمانی پیام **You win!** نمایش داده می‌شود که مقدار تاس واقعاً ۶ باشد.

---

## روش بهتر در PHP

در PHP معمولاً از عملگر **مقایسهٔ همسان (`===`)** استفاده می‌شود:

```php
if ($roll === 6) {
    echo 'You win!';
}
```

`===` علاوه بر مقدار، **نوع داده** را نیز بررسی می‌کند.

مثلاً:

```php
6 == "6"      // true
6 === "6"     // false
```

زیرا اولی فقط مقدار را مقایسه می‌کند، اما دومی هم مقدار و هم نوع داده را بررسی می‌کند (`integer` در مقابل `string`).

---

## جمع‌بندی

| عملگر | کاربرد                                  |
| ----- | --------------------------------------- |
| `=`   | انتساب مقدار به متغیر                   |
| `==`  | مقایسهٔ مقدار دو عبارت                  |
| `===` | مقایسهٔ مقدار و نوع داده (روش پیشنهادی) |

**نکته آموزشی:** یکی از رایج‌ترین خطاهای برنامه‌نویسان تازه‌کار، استفاده از `=` به جای `==` یا `===` در شرط‌های `if` است. این اشتباه باعث می‌شود مقدار متغیر تغییر کند و شرط رفتاری غیرمنتظره داشته باشد؛ در مثال بالا، برنامه بدون توجه به نتیجهٔ واقعی تاس، همیشه کاربر را برنده اعلام می‌کند.
