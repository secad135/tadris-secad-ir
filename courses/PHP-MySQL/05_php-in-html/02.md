# بخش دوم: ساختارهای کنترلی PHP در کنار HTML

## ۲-۱. مسئله

در PHP ساختارهای کنترلی مثل `if`، `for` و `while` داریم. وقتی می‌خواهیم این ساختارها را با HTML ترکیب کنیم، نمی‌توانیم مستقیم از آکولاد (`{` و `}`) استفاده کنیم؛ چون HTML باید **داخل** ساختار قرار بگیرد و مرزهای بلوک PHP مشخص باشد. راه‌حل، **نحو جایگزین (Alternative Syntax)** است.

---

## ۲-۲. نحو جایگزین چگونه است؟

قاعده ساده است:

1. **آکولاد باز `{`** با **دونقطه `:`** جایگزین می‌شود.
2. **آکولاد بسته `}`** با **`endif`، `endwhile`، `endfor`، `endforeach`** (بسته به نوع ساختار) جایگزین می‌شود.
3. بعد از `endif` و مشابه‌هایش **سمیکالن** می‌آید.

| ساختار | شروع بلوک | پایان بلوک |
| --- | --- | --- |
| `if` | `if (شرط):` | `endif;` |
| `elseif` | `elseif (شرط):` | — |
| `else` | `else:` | — |
| `while` | `while (شرط):` | `endwhile;` |
| `for` | `for (…):` | `endfor;` |
| `foreach` | `foreach (…):` | `endforeach;` |
| `switch` | `switch (…):` | `endswitch;` |

---

## ۲-۳. مقایسهٔ دو سبک

فرض کنید می‌خواهیم بر اساس ساعت روز پیامی نمایش دهیم. **سبک نامناسب** این است که همهٔ HTML را با `echo` بسازیم:

```php
<?php
$hour = 12;

if ($hour < 12) {
    echo "Good morning";
} elseif ($hour < 18) {
    echo "Good afternoon";
} elseif ($hour < 22) {
    echo "Good evening";
} else {
    echo "Good night";
}
?>
```

این کد کار می‌کند، اما همان‌طور که در بخش قبل گفتیم، ترکیب HTML و `echo` ایده‌آل نیست. حالا همان منطق را با **نحو جایگزین** می‌نویسیم تا HTML واقعی داخل شرط‌ها قرار بگیرد:

```php
<?php

$hour = 12;

?>
<!DOCTYPE html>
<html>
<head>
    <title>My website</title>
    <meta charset="utf-8">
</head>
<body>

    <h1>Lorem Ipsum</h1>

    <?php if ($hour < 12): ?>
        Good morning
    <?php elseif ($hour < 18): ?>
        Good afternoon
    <?php elseif ($hour < 22): ?>
        Good evening
    <?php else: ?>
        Good night
    <?php endif; ?>

</body>
</html>
```

در این مثال `$hour` برابر ۱۲ است؛ چون ۱۲ از ۱۲ کوچک‌تر نیست ولی از ۱۸ کوچک‌تر است، خروجی **Good afternoon** خواهد بود.

> **دقت کنید:** بین `Good morning` و `<?php elseif` باید یک فاصله بگذارید، وگرنه کلمات به هم می‌چسبند. همچنین `endif;` سمیکالن دارد.

---

## ۲-۴. الگوی درست: داده‌ها بالا، HTML پایین

در مثال بالا، مقدار `$hour` را به بالای فایل منتقل کردیم، **قبل از شروع HTML**. این کار یک الگوی مهم است:

- کدی که فقط **داده می‌سازد یا می‌خواند** (مثل مقداردهی متغیر، خواندن از پایگاه داده، پردازش ورودی فرم) بهتر است بالای فایل و قبل از HTML باشد.
- بخش PHP که **داخل HTML** می‌آید، تا حد امکان کم و کوتاه باشد.
- در نتیجه کد خواناتر است و هر کسی سریع‌تر می‌فهمد داده از کجا می‌آید و کجا نمایش داده می‌شود.

```
┌──────────────────────────┐
│ ۱. منطق و داده‌ها (PHP)   │  ← بالای فایل
├──────────────────────────┤
│ ۲. ساختار صفحه (HTML)    │  ← بدنهٔ فایل
│    با تکه‌های کوچک PHP     │
└──────────────────────────┘
```

## ۲-۵. ساختارهای دیگر با نحو جایگزین

**حلقهٔ `foreach`:**

```php
<?php
$articles = ["First post", "Another post", "Read this!"];
?>
<ul>
    <?php foreach ($articles as $article): ?>
        <li><?= $article; ?></li>
    <?php endforeach; ?>
</ul>
```

**حلقهٔ `for`:**

```php
<ul>
    <?php for ($i = 1; $i <= 3; $i++): ?>
        <li>شمارهٔ <?= $i; ?></li>
    <?php endfor; ?>
</ul>
```

**حلقهٔ `while`:**

```php
<?php $i = 1; ?>
<?php while ($i <= 3): ?>
    <p>خط <?= $i; ?></p>
    <?php $i++; ?>
<?php endwhile; ?>
```

در همهٔ این مثال‌ها HTML **واقعی** داخل حلقه قرار گرفته و دیگر لازم نیست آن را داخل رشته‌های `echo` بنویسیم.

## ۲-۶. اشتباه‌های رایج

| مشکل | علت | راه‌حل |
| --- | --- | --- |
| `Parse error: syntax error, unexpected end of file` | فراموشی `endif;` یا `endforeach;` | پایان بلوک را با `end...;` ببندید |
| خطای `unexpected ':'` | استفاده از آکولاد به‌جای دونقطه | `{` را به `:` تغییر دهید |
| چسبیدن کلمات در خروجی | نبود فاصله بین متن HTML و `<?php` | یک فاصله قبل از تگ PHP بگذارید |
| خطای `unexpected T_INLINE_HTML` | مخلوط شدن نادرست آکولاد و HTML | همهٔ بلوک‌ها را به نحو جایگزین تبدیل کنید |
| خروجی خالی | تگ بستهٔ `?>` یا `;` جا افتاده است | کد را خط‌به‌خط بررسی کنید |

---

## خلاصه نکات کلیدی

1. برای استفاده از `if` و حلقه‌ها همراه HTML از **نحو جایگزین** استفاده می‌کنیم.
2. در این نحو، آکولاد باز `{` به **دونقطه `:`** تبدیل می‌شود.
3. آکولاد بسته `}` با **`endif`، `endwhile`، `endfor`، `endforeach` یا `endswitch`** جایگزین می‌شود.
4. بعد از `end...` همیشه **سمیکالن** می‌آید.
5. `elseif` و `else` در این نحو هم با دونقطه تمام می‌شوند: `elseif (شرط):` و `else:`.
6. کدهایی که فقط داده می‌سازند یا می‌خوانند را **بالای فایل** و قبل از HTML بنویسید.
7. مقدار PHP داخل HTML را کم نگه دارید تا کد خواناتر و قابل‌نگهداری‌تر باشد.
8. مزیت اصلی این سبک، نوشتن HTML واقعی به‌جای رشته‌های طولانی `echo` است.
9. در خروجی، تگ‌های PHP و حتی بخش‌هایی که خروجی ندارند، حذف می‌شوند و فقط نتیجه به مرورگر می‌رسد.
10. فراموشی `end...;` رایج‌ترین خطای این سبک است.

## ۱۰ سؤال تستی

### سؤال ۱

برای استفاده از `if` همراه با HTML، آکولاد باز `{` با چه چیزی جایگزین می‌شود؟

- الف) `;`
- ب) `:`
- ج) `=>`
- د) `::`

### سؤال ۲

در نحو جایگزین، بلوک `if` با کدام عبارت بسته می‌شود؟

- الف) `end if`
- ب) `endif;`
- ج) `}`
- د) `end;`

### سؤال ۳

در مثال درس، اگر مقدار `$hour` برابر ۱۲ باشد، چه پیامی نمایش داده می‌شود؟

- الف) Good morning
- ب) Good afternoon
- ج) Good evening
- د) Good night

### سؤال ۴

چرا مقداردهی متغیرها را به بالای فایل و قبل از HTML منتقل می‌کنیم؟

- الف) PHP در پایین فایل اجرا نمی‌شود.
- ب) برای اینکه بخش PHP داخل HTML کم شود و کد خواناتر باشد.
- ج) چون متغیرها در HTML قابل استفاده نیستند.
- د) برای افزایش سرعت مرورگر.

### سؤال ۵

در پایان `endif` چه علامتی لازم است؟

- الف) نقطه
- ب) کاما
- ج) سمیکالن
- د) هیچ علامتی

### سؤال ۶

کدام گزینه یک حلقهٔ `foreach` صحیح همراه HTML است؟

- الف) `<?php foreach ($items as $item): ?> ... <?php endforeach; ?>`
- ب) `<?php foreach ($items as $item) { ?> ... <?php endforeach; ?>`
- ج) `<?php foreach ($items as $item): ?> ... <?php } ?>`
- د) `<?php foreach ($items as $item) ?> ... <?php endforeach ?>`

### سؤال ۷

برای بازگشت از HTML به کد PHP در وسط یک بلوک شرطی، چه چیزی لازم است؟

- الف) تگ باز `<?php`
- ب) فقط سمیکالن
- ج) عبارت `endif`
- د) تگ بستهٔ `?>`

### سؤال ۸

فراموش کردن `endif;` در این سبک چه نتیجه‌ای دارد؟

- الف) صفحه بدون خطا نمایش داده می‌شود.
- ب) خطای نحوی (Parse error) رخ می‌دهد.
- ج) شرط همیشه درست در نظر گرفته می‌شود.
- د) HTML اصلاً ارسال نمی‌شود.

### سؤال ۹

مزیت اصلی نحو جایگزین نسبت به نوشتن HTML با `echo` چیست؟

- الف) اجرای سریع‌تر PHP
- ب) امکان استفاده از پایگاه داده
- ج) نوشتن HTML واقعی و کد خواناتر و قابل‌نگهداری‌تر
- د) حذف نیاز به تگ‌های PHP

### سؤال ۱۰

اگر `$hour` برابر ۲۳ باشد، کدام پیام نمایش داده می‌شود؟

- الف) Good morning
- ب) Good afternoon
- ج) Good evening
- د) Good night
