# نکته های ریز کدنویسی

## وب سرور داخلی php

```bash
php -S localhost:8000 -t public
```

این دستور یک **سرور وب موقت و سبک** روی سیستم شما راه‌اندازی می‌کند تا بتوانید سایت را بدون نیاز به نصب Apache یا Nginx (مثل کاری که در هاست انجام می‌شود) تست کنید.

توضیح بخش‌به‌بخش:

*   **`php`**: برنامه مفسر زبان PHP را صدا می‌زند.
*   **`-S`**: مخفف Server است و به PHP می‌گوید «سرور توکار خودت را اجرا کن».
*   **`localhost:8000`**: آدرسی است که سرور روی آن بالا می‌آید. یعنی روی سیستم خودتان (لوکال) و پورت ۸۰۰۰ (می‌توانستید ۸۰۸۰ یا هر عدد دیگری باشد).
*   **`-t public`**: مخفف Target (یا Document Root) است. به سرور می‌گوید: «ریشه سایت من پوشه `public` است». دقیقاً مثل همان تنظیماتی که در cPanel هاست برای ساب‌دامین انجام دادیم.

**خلاصه:** این دستور به PHP می‌گوید: *"فایل‌های پوشه `public` را روی آدرس `http://localhost:8000` به عنوان یک وب‌سایت به من نشان بده."*

*(برای خروج از سرور، در همان ترمینال همزمان کلیدهای `Ctrl + C` را فشار دهید).*
