# دستورات شرطی (if / else / elseif)

## مقدمه: شرطی چیست؟

دستور شرطی به برنامه میگوید: **«اگر فلان چیز درست بود، این کار را بکن؛ وگرنه کار دیگری بکن.»**
در زندگی روزمره هم همینطور است: «اگر باران آمد، چتر بردار؛ وگرنه عینک آفتابی بزن.»

در PHP سه ابزار اصلی برای این کار داریم: `if`، `else` و `elseif`. حالا قدمبهقدم آنها را میسازیم.

---

## قدم ۱: فقط `if` — سادهترین حالت

`if` فقط یک شرط را بررسی میکند. **اگر شرط درست بود**، کد داخل آکولاد اجرا میشود. **اگر غلط بود**، آن کد نادیده گرفته میشود و برنامه ادامه مییابد.

```php
$age = 20;

if ($age >= 18) {
    echo "شما بزرگسال هستید";
}
```

**توضیح خط به خط:**
- `$age >= 18` → یک شرط است که یا `true` (درست) میشود یا `false` (غلط).
- چون ۲۰ بزرگتر یا مساوی ۱۸ است، شرط `true` میشود و پیام چاپ میشود.
- اگر `$age` مثلاً ۱۵ بود، شرط `false` میشد و **هیچ چیزی چاپ نمیشد**.

**نکته:** `if` تنها وقتی کافی است که بخواهیم «فقط در صورت درست بودن» کاری انجام دهیم و برای حالت غلط هیچ کاری لازم نباشد.

---

## قدم ۲: اضافه کردن `else` — دو راهی

حالا میخواهیم برای حالت **غلط** هم کاری انجام دهیم. اینجا `else` وارد میشود.
`else` یعنی: «اگر شرط بالا درست نبود، این کار را بکن.» **`else` هیچ شرطی ندارد**، چون فقط حالت باقیمانده است.

```php
$age = 15;

if ($age >= 18) {
    echo "شما بزرگسال هستید";
} else {
    echo "شما زیر ۱۸ سال هستید";
}
```

**توضیح:**
- اگر `$age >= 18` درست باشد → پیام «بزرگسال».
- اگر غلط باشد → به `else` میرویم و پیام «زیر ۱۸ سال» چاپ میشود.
- **همیشه دقیقاً یکی از این دو بلوک اجرا میشود، نه هر دو.**

---

## قدم ۳: اضافه کردن `elseif` — چند راهی

حالا فرض کنید بیش از دو حالت داریم. مثلاً میخواهیم نمره را به سه دسته تقسیم کنیم: مردود، قبول، ممتاز. اینجا `elseif` به کار میآید.

`elseif` یعنی: «اگر شرط قبلی غلط بود، **این شرط جدید را بررسی کن**.» میتوانیم چند تا `elseif` پشت سر هم بیاوریم. در انتها هم `else` برای حالت باقیمانده میگذاریم.

```php
$score = 15;

if ($score < 10) {
    echo "مردود";
} elseif ($score < 17) {
    echo "قبول";
} else {
    echo "ممتاز";
}
```

**توضیح ترتیب اجرا:**
1. اول شرط `$score < 10` بررسی میشود. چون ۱۵ کمتر از ۱۰ نیست → `false` → رد میشود.
2. بعد شرط `$score < 17` بررسی میشود. چون ۱۵ کمتر از ۱۷ است → `true` → پیام «قبول» چاپ میشود.
3. `else` اجرا **نمیشود**، چون یک شرط قبلی درست شد.

**نکته طلایی:** به محض اینکه **اولین شرط درست** پیدا شود، بقیه شرطها **اصلاً بررسی نمیشوند**. به همین دلیل ترتیب شرطها بسیار مهم است.

---

## نکته مهم: چرا ترتیب شرطها اهمیت دارد؟

در مثال بالا ما نوشتیم `$score < 10` و بعد `$score < 17`. چرا لازم نیست بنویسیم `$score >= 10 && $score < 17`؟

چون وقتی به `elseif` دوم میرسیم، **قطعاً** شرط اول (`$score < 10`) غلط بوده است. یعنی نمره حتماً ۱۰ یا بیشتر است. پس فقط کافی است بررسی کنیم که آیا کمتر از ۱۷ است یا نه.

اما اگر ترتیب را برعکس مینوشتیم، نتیجه اشتباه میشد:

```php
// ❌ مثال اشتباه — ترتیب غلط
if ($score < 17) {
    echo "قبول";
} elseif ($score < 10) {
    echo "مردود";   // این بلوک هرگز اجرا نمیشود!
}
```

چون هر نمرهای که کمتر از ۱۰ باشد، **قطعاً** کمتر از ۱۷ هم هست؛ پس همیشه اولین شرط درست میشود و بلوک «مردود» هیچوقت اجرا نمیشود. **همیشه شرطهای محدودتر (سختگیرانهتر) را اول بنویسید.**

---

## عملگرهای منطقی: ترکیب شرطها

گاهی یک شرط کافی نیست و باید چند شرط را با هم ترکیب کنیم:

| عملگر | معنی | مثال | نتیجه |
|-------|------|------|-------|
| `&&` | **و** — هر دو طرف باید درست باشند | `$x > 0 && $x < 20` | فقط اگر x بین ۰ و ۲۰ باشد |
| `\|\|` | **یا** — حداقل یکی درست باشد | `$x < 0 \|\| $x > 20` | اگر x بیرون بازه ۰ تا ۲۰ باشد |
| `!` | **نقیض** — برعکس میکند | `!($x == 0)` | اگر x صفر نباشد |

**مثال کاربردی — بررسی معتبر بودن نمره:**
```php
if ($score >= 0 && $score <= 20) {
    echo "نمره معتبر است";
} else {
    echo "نمره نامعتبر است";
}
```
اینجا `&&` باعث میشود هر دو شرط (بزرگتر یا مساوی ۰ **و** کوچکتر یا مساوی ۲۰) همزمان برقرار باشند.

---

## مثال ۱: تشخیص عدد زوج و فرد

عملگر `%` (باقیمانده تقسیم) ابزار ماست: اگر عددی بر ۲ تقسیم شود و باقیماندهاش **صفر** باشد، زوج است.

```php
$number = 8;

if ($number % 2 == 0) {
    echo "عدد $number زوج است";
} else {
    echo "عدد $number فرد است";
}
```

**اجرا:** `8 % 2` برابر ۰ میشود → شرط درست → «عدد 8 زوج است».
اگر `$number = 7` بود: `7 % 2` برابر ۱ میشود → شرط غلط → «عدد 7 فرد است».

---

## مثال ۲: تعیین وضعیت نمره دانشآموز (با عملگر منطقی و شرط تو در تو)

قوانین مسئله:
- نمره باید **بین ۰ و ۲۰** باشد (با عملگر `&&`).
- کمتر از ۱۰ → **مردود**
- کمتر از ۱۷ → **قبول**
- بقیه (۱۷ تا ۲۰) → **ممتاز**

### با شرط تو در تو (Nested if)

گاهی خواناتر است که اول **اعتبار نمره** را جدا بررسی کنیم و بعد داخل آن، منطق اصلی را بنویسیم:

```php
$score = 18;

if ($score >= 0 && $score <= 20) {
    // نمره معتبر است → حالا وضعیت را تعیین کن
    if ($score < 10) {
        echo "وضعیت: مردود";
    } elseif ($score < 17) {
        echo "وضعیت: قبول";
    } else {
        echo "وضعیت: ممتاز";
    }
} else {
    // نمره معتبر نیست
    echo "خطا: نمره باید بین ۰ و ۲۰ باشد";
}
```

**چرا این روش خوب است؟** چون دو مسئله جدا از هم را از هم جدا کردهایم:
1. **آیا داده معتبر است؟** (لایه بیرونی)
2. **اگر معتبر بود، وضعیت چیست؟** (لایه درونی)

این جداسازی باعث میشود کد خواناتر باشد و اگر بعداً بخواهیم بررسی اعتبار را تغییر دهیم، به منطق اصلی دست نزنیم.

---

## جمعبندی سریع

| ابزار | کاربرد |
|-------|--------|
| `if` | فقط بررسی «درست بودن» — اگر غلط بود، هیچ کاری نکن |
| `else` | حالت باقیمانده — بدون شرط، وقتی `if` غلط بود |
| `elseif` | بررسی شرط جدید، فقط اگر شرطهای قبلی غلط بودند |
| `&&` | هر دو شرط باید درست باشند (برای بازهها) |
| `\|\|` | حداقل یکی درست باشد (برای خارج از بازه) |
| `%` | باقیمانده تقسیم — برای زوج/فرد |
| شرط تو در تو | جداسازی بررسی اعتبار داده از منطق اصلی |

**سه قانون طلایی:**
1. **ترتیب شرطها** را از محدودترین به کلیترین بنویسید.
2. به محض درست شدن یک شرط، بقیه **بررسی نمیشوند**.
3. برای بازهها از `&&` و برای «خارج از بازه» از `||` استفاده کنید.


## آزمون تستی — دستورات شرطی PHP

**۱)** کدام گزینه فقط زمانی اجرا می‌شود که شرط `if` درست نباشد و خودش هیچ شرطی ندارد؟
- الف) `if`
- ب) `else`
- ج) `elseif`
- د) `switch`

**۲)** خروجی کد زیر چیست؟
```php
$age = 15;
if ($age >= 18) {
    echo "بزرگسال";
} else {
    echo "زیر ۱۸ سال";
}
```
- الف) بزرگسال
- ب) زیر ۱۸ سال
- ج) هیچ خروجی ندارد
- د) خطا می‌دهد

**۳)** خروجی کد زیر چیست؟
```php
$score = 15;
if ($score < 10) {
    echo "مردود";
} elseif ($score < 17) {
    echo "قبول";
} else {
    echo "ممتاز";
}
```
- الف) مردود
- ب) قبول
- ج) ممتاز
- د) هیچ‌کدام

**۴)** در مثال نمره، چرا در `elseif` دوم لازم نیست بنویسیم `$score >= 10 && $score < 17`؟
- الف) چون PHP خودش این شرط را اضافه می‌کند
- ب) چون اگر به `elseif` رسیده باشیم، شرط قبلی (`$score < 10`) غلط بوده است
- ج) چون `elseif` فقط برای اعداد استفاده می‌شود
- د) چون `&&` در `elseif` مجاز نیست

**۵)** کدام شرط بررسی می‌کند که `$x` بین ۰ و ۲۰ باشد؟
- الف) `$x > 0 || $x < 20`
- ب) `$x >= 0 && $x <= 20`
- ج) `$x >= 0 || $x <= 20`
- د) `$x < 0 && $x > 20`

**۶)** کدام شرط بررسی می‌کند که `$score` **بیرون** بازه ۰ تا ۲۰ باشد؟
- الف) `$score < 0 && $score > 20`
- ب) `$score >= 0 && $score <= 20`
- ج) `$score < 0 || $score > 20`
- د) `!($score >= 0 || $score <= 20)`

**۷)** برای تشخیص زوج بودن عدد `$n` کدام شرط درست است؟
- الف) `$n / 2 == 0`
- ب) `$n % 2 == 0`
- ج) `$n % 2 == 1`
- د) `$n == 2`

**۸)** خروجی کد زیر برای `$score = 5` چیست؟
```php
if ($score < 17) {
    echo "قبول";
} elseif ($score < 10) {
    echo "مردود";
}
```
- الف) مردود
- ب) قبول
- ج) هیچ خروجی ندارد
- د) خطا می‌دهد

**۹)** در مثال شرط تو در تو برای تعیین وضعیت نمره، لایه بیرونی (`if` اصلی) چه چیزی را بررسی می‌کند؟
- الف) مردود یا قبول بودن
- ب) ممتاز بودن
- ج) معتبر بودن نمره بین ۰ و ۲۰
- د) زوج یا فرد بودن نمره

**۱۰)** اگر `$score = 18` باشد، در کد زیر چه چیزی چاپ می‌شود؟
```php
if ($score < 10) {
    echo "مردود";
} elseif ($score < 17) {
    echo "قبول";
} else {
    echo "ممتاز";
}
```
- الف) مردود
- ب) قبول
- ج) ممتاز
- د) نمره نامعتبر

## پاسخ‌نامه

1. **ب** — `else`
2. **ب** — زیر ۱۸ سال
3. **ب** — قبول
4. **ب** — چون شرط قبلی غلط بوده و نمره قطعاً ۱۰ یا بیشتر است
5. **ب** — `$x >= 0 && $x <= 20`
6. **ج** — `$score < 0 || $score > 20`
7. **ب** — `$n % 2 == 0`
8. **ب** — قبول (چون شرط اول درست است و `elseif` بررسی نمی‌شود)
9. **ج** — معتبر بودن نمره بین ۰ و ۲۰
10. **ج** — ممتاز
