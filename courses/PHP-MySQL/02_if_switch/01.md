# مقدمه و دستور شرطی ساده `if`

## ۱. شرط چیست؟
در زندگی روزمره نیز شرط داریم. برای مثال:
«اگر هوا بارانی باشد، چتر برمی‌دارم.»

در برنامه‌نویسی نیز شرط به معنی تصمیم‌گیری است. برنامه یک عبارت را بررسی می‌کند. اگر نتیجه درست باشد، دستورهای داخل شرط اجرا می‌شوند. اگر نتیجه نادرست باشد، آن دستورها اجرا نمی‌شوند.

در PHP نتیجه بررسی شرط یکی از دو حالت زیر است:
- `true` یعنی درست
- `false` یعنی نادرست

## ۲. عملگرهای مقایسه
برای ساختن شرط، از عملگرهای مقایسه استفاده می‌کنیم.

| عملگر | معنی | مثال |
|---|---|---|
| `==` | برابر بودن مقدارها | `$a == 10` |
| `!=` | برابر نبودن | `$a != 10` |
| `>` | بزرگ‌تر بودن | `$a > 10` |
| `<` | کوچک‌تر بودن | `$a < 10` |
| `>=` | بزرگ‌تر یا برابر | `$a >= 10` |
| `<=` | کوچک‌تر یا برابر | `$a <= 10` |

### مطالعه تکمیلی
عملگر `===` برای مقایسه مقدار و نوع داده استفاده می‌شود. برای دانش‌آموزان کاردانش دانستن آن الزامی نیست. مثال:
```php
<?php
$a = 10;
if ($a === 10) {
    echo "برابر است";
}
?>
```

## ۳. ساختار دستور `if`
ساختار ساده دستور شرطی به شکل زیر است:

```php
<?php
if (شرط) {
    // دستورهایی که در صورت درست بودن شرط اجرا می‌شوند
}
?>
```

نکته‌ها:
1. شرط داخل پرانتز نوشته می‌شود.
2. دستورها داخل آکولاد `{ }` قرار می‌گیرند.
3. پس از هر دستور، معمولاً نقطه‌ویرگول `;` گذاشته می‌شود.
4. کدها را با فاصله‌گذاری مناسب بنویسید تا خوانایی بهتر شود.

## ۴. مثال ساده
```php
<?php
$age = 18;

if ($age >= 18) {
    echo "شما اجازه ورود دارید.";
}
?>
```

توضیح:
- متغیر `$age` مقدار ۱۸ دارد.
- شرط `$age >= 18` بررسی می‌شود.
- چون ۱۸ بزرگ‌تر یا برابر ۱۸ است، نتیجه شرط `true` می‌شود.
- بنابراین پیام «شما اجازه ورود دارید.» نمایش داده می‌شود.

## ۵. مثال با مقدار نادرست
```php
<?php
$age = 15;

if ($age >= 18) {
    echo "شما اجازه ورود دارید.";
}
?>
```

توضیح:
- شرط `$age >= 18` بررسی می‌شود.
- چون ۱۵ کوچک‌تر از ۱۸ است، نتیجه `false` می‌شود.
- بنابراین دستور `echo` اجرا نمی‌شود و هیچ پیامی نمایش داده نمی‌شود.

## ۶. خطاهای رایج
1. گذاشتن `=` به جای `==` در شرط  
   نادرست: `if ($age = 18)`  
   درست: `if ($age == 18)`

2. فراموش کردن آکولاد  
   برای شروع، همیشه از آکولاد استفاده کنید.

3. فراموش کردن نقطه‌ویرگول  
   پس از دستورهای داخل بلوک شرط، نقطه‌ویرگول لازم است.

4. نوشتن کد بیرون از تگ PHP  
   کد PHP باید داخل `<?php ... ?>` باشد.

5. اشتباه در حروف بزرگ و کوچک نام متغیرها  
   در PHP نام متغیرها به حروف بزرگ و کوچک حساس است. `$Age` با `$age` متفاوت است.

## ۷. تمرین کلاسی
1. برنامه‌ای بنویسید که متغیر `$score` را با مقدار ۲۰ تعریف کند. اگر نمره بزرگ‌تر یا برابر ۱۰ باشد، پیام «قبول» نمایش داده شود.
2. برنامه‌ای بنویسید که اگر مقدار متغیر `$number` بزرگ‌تر از ۱۰۰ باشد، پیام «عدد بزرگ است» نمایش دهد.
3. خطای کد زیر را پیدا کنید:
```php
<?php
$age = 20;
if ($age = 18) {
    echo "برابر است";
}
?>
```

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

نتیجهٔ بررسی یک شرط منطقی کدام است؟

- الف) همیشه عدد ۱۰
- ب) نام فایل
- ج) فقط متن
- د) درست یا نادرست

### سؤال ۲

بدنهٔ `if` چه زمانی اجرا می‌شود؟

- الف) فقط وقتی شرط نادرست باشد
- ب) فقط در پایان فایل
- ج) همیشه دو بار
- د) وقتی شرط درست باشد

### سؤال ۳

کدام عملگر برای مقایسهٔ برابری مقدارهاست؟

- الف) `.`
- ب) `==`
- ج) `+=`
- د) `=`

### سؤال ۴

خروجی `$age = 20; if ($age >= 18) { echo "A"; }` چیست؟

- الف) `A`
- ب) هیچ خروجی ندارد
- ج) `18`
- د) `20`

### سؤال ۵

خروجی `$n = 3; if ($n > 5) { echo "B"; }` چیست؟

- الف) هیچ خروجی ندارد
- ب) `B`
- ج) `3`
- د) `5`

### سؤال ۶

کدام شرط عدد ۱۰ را نیز جزو نمرات قبولی حساب می‌کند؟

- الف) `$score != 10`
- ب) `$score >= 10`
- ج) `$score < 10`
- د) `$score > 10`

### سؤال ۷

علامت `!=` چه مفهومی دارد؟

- الف) اتصال متن
- ب) بزرگ‌تر بودن
- ج) نابرابر بودن
- د) انتساب مقدار

### سؤال ۸

شرط دستور if در ساختار معمول داخل چه چیزی نوشته می‌شود؟

- الف) توضیح چندخطی
- ب) پرانتز
- ج) کوتیشن
- د) براکت HTML

### سؤال ۹

برای قرار دادن چند دستور در بدنهٔ if از چه چیزی استفاده می‌شود؟

- الف) کوتیشن
- ب) درصد
- ج) آکولاد
- د) علامت دلار

### سؤال ۱۰

در `if ($x = 5)` کدام عمل انجام می‌شود؟

- الف) کم کردن ۵ از x
- ب) مقایسهٔ نوع x
- ج) مقایسهٔ برابری x با ۵
- د) انتساب ۵ به x

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | د | شرط منطقی با true یا false بیان می‌شود. |
| ۲ | د | اجرای بدنه وابسته به درست بودن شرط است. |
| ۳ | ب | دو علامت مساوی برای مقایسهٔ مقدارها استفاده می‌شود. |
| ۴ | الف | سن ۲۰ شرط بزرگ‌تر یا مساوی ۱۸ را برقرار می‌کند. |
| ۵ | الف | شرط نادرست است و دستور دیگری برای چاپ وجود ندارد. |
| ۶ | ب | عملگر بزرگ‌تر یا مساوی مرز ۱۰ را شامل می‌شود. |
| ۷ | ج | این عملگر تفاوت مقدارها را می‌سنجد. |
| ۸ | ب | شرط بعد از if در پرانتز قرار می‌گیرد. |
| ۹ | ج | آکولادها یک بلوک از دستورها می‌سازند. |
| ۱۰ | د | یک علامت مساوی عملگر انتساب است. |
