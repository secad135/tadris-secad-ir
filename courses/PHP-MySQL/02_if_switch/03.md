# جزوه آموزشی `switch`، `if` و شرط کوتاه `? :` در PHP

## ۱) دستور `switch`

دستور `switch` زمانی استفاده می‌شود که بخواهیم مقدار یک متغیر را با چند مقدار مختلف مقایسه کنیم و برای هر مقدار یک کار مشخص انجام دهیم.  
به‌جای نوشتن چندین `if` پشت‌سرهم، از `switch` استفاده می‌کنیم تا کد خواناتر و مرتب‌تر باشد.

### ساختار کلی

```php
<?php
switch ($متغیر) {
    case مقدار۱:
        // کد
        break;
    case مقدار۲:
        // کد
        break;
    default:
        // اگر هیچ case ای مطابقت نکرد
}
?>
```

- `case`: مقدارهایی که می‌خواهیم بررسی شوند.
- `break`: از اجرای caseهای بعدی جلوگیری می‌کند.
- `default`: اگر هیچ‌کدام از caseها مطابقت نکردند، اجرا می‌شود. این بخش اختیاری است.

> نکته: اگر `break` را فراموش کنیم، PHP بعد از اجرای case موردنظر، caseهای بعدی را هم اجرا می‌کند. به این رفتار fall-through می‌گویند.

---

## ۲) مثال `switch` برای روزهای هفته

در این مثال:

- `0` = شنبه
- `1` = یکشنبه
- `2` = دوشنبه
- `3` = سه‌شنبه
- `4` = چهارشنبه
- `5` = پنجشنبه
- `6` = جمعه

```php
<?php
$day = 3;

switch ($day) {
    case 0:
        echo "شنبه";
        break;
    case 1:
        echo "یکشنبه";
        break;
    case 2:
        echo "دوشنبه";
        break;
    case 3:
        echo "سه‌شنبه";
        break;
    case 4:
        echo "چهارشنبه";
        break;
    case 5:
        echo "پنجشنبه";
        break;
    case 6:
        echo "جمعه";
        break;
    default:
        echo "روز نامعتبر";
}
?>
```

خروجی این مثال:

```text
سه‌شنبه
```

اگر مقدار `$day` را به `6` تغییر دهیم، خروجی «جمعه» می‌شود.  
اگر مقدار آن مثلاً `9` باشد، چون هیچ caseای مطابقت نمی‌کند، `default` اجرا می‌شود و «روز نامعتبر» چاپ می‌شود.

## ۳) مقایسه سریع `switch` و `if` در مثال روزهای هفته

همان مثال روزهای هفته را می‌توان با `if` و `elseif` هم نوشت. خروجی هر دو نسخه یکسان است، اما ساختار کد متفاوت است.

### نسخه `if` برای روزهای هفته

```php
<?php
$day = 3;

if ($day == 0) {
    echo "شنبه";
} elseif ($day == 1) {
    echo "یکشنبه";
} elseif ($day == 2) {
    echo "دوشنبه";
} elseif ($day == 3) {
    echo "سه‌شنبه";
} elseif ($day == 4) {
    echo "چهارشنبه";
} elseif ($day == 5) {
    echo "پنجشنبه";
} elseif ($day == 6) {
    echo "جمعه";
} else {
    echo "روز نامعتبر";
}
?>
```

خروجی:

```text
سه‌شنبه
```

### مقایسه سریع

| ویژگی | `switch` | `if / elseif / else` |
|---|---|---|
| کاربرد اصلی | مقایسه یک متغیر با چند مقدار ثابت | بررسی شرط‌های مختلف و متنوع |
| خوانایی در حالت‌های زیاد | معمولاً خواناتر | ممکن است طولانی و تکراری شود |
| نیاز به `break` | دارد | ندارد |
| بخش پیش‌فرض | `default` | `else` |
| بررسی بازه‌ها یا شرط‌های پیچیده | مناسب نیست | مناسب است |
| مثال روزهای هفته | هر روز یک `case` | هر روز یک `if / elseif` |

**نتیجه:** برای مقایسه یک مقدار با چند مقدار ثابت مثل روزهای هفته، `switch` معمولاً خواناتر است. اما برای شرط‌های پیچیده‌تر یا بررسی بازه‌ها، `if` انعطاف بیشتری دارد.

## ۴) شرط کوتاه `? :`

شرط کوتاه یا عملگر سه‌گانه `? :` یک روش کوتاه برای نوشتن `if` و `else` ساده است.

### ساختار

```php
$متغیر = (شرط) ? مقدار_در_صورت_درست : مقدار_در_صورت_نادرست;
```

### کدام قسمت در متغیر ذخیره می‌شود؟

- اگر شرط **`true`** باشد: مقداری که **بعد از `?` و قبل از `:`** نوشته شده است، در متغیر ذخیره می‌شود.
- اگر شرط **`false`** باشد: مقداری که **بعد از `:`** نوشته شده است، در متغیر ذخیره می‌شود.

| نتیجه شرط | چه چیزی در متغیر ذخیره می‌شود؟ |
|---|---|
| `true` | مقدار قبل از `:` و بعد از `?` |
| `false` | مقدار بعد از `:` |

### مثال ساده

```php
<?php
$age = 20;

$result = ($age >= 18) ? "بزرگسال" : "نوجوان";

echo $result;
?>
```

توضیح:

- شرط `$age >= 18` بررسی می‌شود.
- چون `$age = 20` است، شرط **`true`** است.
- بنابراین مقدار `"بزرگسال"` که بعد از `?` آمده است، در متغیر `$result` ذخیره می‌شود.
- خروجی: `بزرگسال`

حالا اگر مقدار متغیر را تغییر دهیم:

```php
<?php
$age = 16;

$result = ($age >= 18) ? "بزرگسال" : "نوجوان";

echo $result;
?>
```

توضیح:

- شرط `$age >= 18` بررسی می‌شود.
- چون `$age = 16` است، شرط **`false`** است.
- بنابراین مقدار `"نوجوان"` که بعد از `:` آمده است، در متغیر `$result` ذخیره می‌شود.
- خروجی: `نوجوان`

### مثال ساده دیگر

```php
<?php
$number = 5;

$result = ($number % 2 == 0) ? "زوج" : "فرد";
echo $result;
?>
```

خروجی:

```text
فرد
```

معادل همان کد با `if` و `else`:

```php
<?php
$age = 20;

if ($age >= 18) {
    echo "بزرگسال";
} else {
    echo "نوجوان";
}
?>
```

## ۵) دستور `match` در PHP — برای مطالعه بیشتر

از PHP 8 به بعد دستور `match` معرفی شده است. `match` شبیه `switch` است، اما کوتاه‌تر و امن‌تر نوشته می‌شود. در `match` به‌جای `case` و `break`، از پیکان `=>` استفاده می‌کنیم و نتیجه مستقیماً برگردانده می‌شود.

> توجه: در سوالات تستی این جزوه هیچ سوالی از دستور `match` طراحی نشده است و این بخش فقط برای مطالعه بیشتر است.

### ساختار کلی `match`

```php
<?php
$نتیجه = match ($متغیر) {
    مقدار۱ => نتیجه۱,
    مقدار۲ => نتیجه۲,
    default => نتیجه_پیش‌فرض
};
?>
```

### مثال `match` برای روزهای هفته

همان نگاشت قبلی: `0` شنبه، `1` یکشنبه، ...، `6` جمعه.

```php
<?php
$day = 3;

$name = match ($day) {
    0 => "شنبه",
    1 => "یکشنبه",
    2 => "دوشنبه",
    3 => "سه‌شنبه",
    4 => "چهارشنبه",
    5 => "پنجشنبه",
    6 => "جمعه",
    default => "روز نامعتبر"
};

echo $name;
?>
```

خروجی:

```text
سه‌شنبه
```

اگر `$day = 6` باشد، خروجی `جمعه` می‌شود.  
اگر `$day = 9` باشد، چون هیچ مقداری مطابقت نمی‌کند، مقدار `default` یعنی `روز نامعتبر` برگردانده می‌شود.

### تفاوت‌های مهم `match` با `switch`

1. در `match` نیازی به `break` نیست.
2. `match` یک مقدار برمی‌گرداند و می‌توان نتیجه را مستقیماً در متغیر ذخیره کرد.
3. مقایسه در `match` به‌صورت سخت‌گیرانه (`===`) انجام می‌شود؛ یعنی هم مقدار و هم نوع داده بررسی می‌شود.
4. اگر هیچ مقداری مطابقت نکند و `default` هم نوشته نشده باشد، PHP خطای `UnhandledMatchError` می‌دهد.
5. نوشتن `match` معمولاً خواناتر و کوتاه‌تر از `switch` است.

### مثال ساده دیگر از `match`

```php
<?php
$status = 2;

$message = match ($status) {
    1 => "فعال",
    2 => "غیرفعال",
    3 => "مسدود",
    default => "وضعیت نامشخص"
};

echo $message;
?>
```

خروجی:

```text
غیرفعال
```

# سوالات تستی

۱) در دستور `switch` کدام گزینه از اجرای ادامه caseها جلوگیری می‌کند؟  
الف) `continue`  
ب) `break`  
ج) `exit`  
د) `return`

۲) اگر `$day = 6` باشد و switch روزهای هفته را با 0 برای شنبه تا 6 برای جمعه نوشته باشیم، چه چیزی چاپ می‌شود؟  
الف) شنبه  
ب) پنجشنبه  
ج) جمعه  
د) روز نامعتبر

۳) بخش `default` در `switch` چه زمانی اجرا می‌شود؟  
الف) همیشه  
ب) فقط وقتی متغیر صفر باشد  
ج) فقط وقتی `break` وجود نداشته باشد  
د) وقتی هیچ caseای با مقدار متغیر مطابقت نکند

۴) کدام گزینه یک شرط کوتاه درست در PHP است؟  
الف) `$x = ($a > 0) ? "مثبت" : "منفی";`  
ب) `$x = ($a > 0) : "مثبت" ? "منفی";`  
ج) `$x = if ($a > 0) ? "مثبت" : "منفی";`  
د) `$x = ($a > 0) ? "مثبت" ; "منفی";`

۵) خروجی کد زیر چیست؟

```php
<?php
$n = 5;
echo ($n % 2 == 0) ? "زوج" : "فرد";
?>
```

الف) زوج  
ب) فرد  
ج) 5  
د) خطا

۶) در switch روزهای هفته، اگر `$day = 1` باشد، چه روزی چاپ می‌شود؟  
الف) شنبه  
ب) یکشنبه  
ج) دوشنبه  
د) جمعه

۷) اگر در case مربوط به `0` دستور `break` را حذف کنیم و `$day = 0` باشد، چه اتفاقی می‌افتد؟  
الف) فقط «شنبه» چاپ می‌شود  
ب) هیچ چیزی چاپ نمی‌شود  
ج) بعد از «شنبه»، caseهای بعدی هم تا رسیدن به `break` اجرا می‌شوند  
د) برنامه خطا می‌دهد

۸) شرط کوتاه `? :` معادل کدام ساختار است؟  
الف) `for`  
ب) `while`  
ج) `if / else` ساده  
د) `switch`

۹) خروجی کد زیر چیست؟

```php
<?php
$age = 17;
echo ($age >= 18) ? "بزرگسال" : "نوجوان";
?>
```

الف) بزرگسال  
ب) نوجوان  
ج) 17  
د) خطا

۱۰) در نگاشت روزهای هفته (0 شنبه تا 6 جمعه)، عدد `5` مربوط به کدام روز است؟  
الف) چهارشنبه  
ب) پنجشنبه  
ج) جمعه  
د) سه‌شنبه
