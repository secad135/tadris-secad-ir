### تمرین

**هدف:** آشنایی با حلقه `for` و افزایش تدریجی مقدار یک متغیر.

**صورت سؤال:**

برنامه‌ای به زبان PHP بنویسید که جدول عدد **۹** را از `9 × 1` تا `9 × 12` چاپ کند.

**شرایط:**

1. از عملگر ضرب (`*`) استفاده نکنید.
2. از دستور `if` استفاده نکنید.
3. برای تولید اعداد از حلقه `for` استفاده کنید.
4. هر عدد در یک خط جداگانه نمایش داده شود.

**خروجی مورد انتظار:**

```text
9
18
27
36
45
54
63
72
81
90
99
108
```

---

### پاسخ نمونه

```php
<?php

$value = 9;

for ($count = 1; $count <= 12; $count++) {
    echo $value . "<br>";
    $value += 9;
}
```

---

### توضیح پاسخ

* ابتدا متغیر `$value` برابر **۹** قرار داده می‌شود.
* حلقه `for` دوازده بار اجرا می‌شود.
* در هر تکرار:

  * مقدار فعلی `$value` چاپ می‌شود.
  * سپس با دستور `$value += 9`، عدد ۹ به مقدار قبلی اضافه می‌شود تا عدد بعدی جدول تولید شود.
* به این ترتیب، بدون استفاده از عملگر ضرب (`*`) و بدون استفاده از دستور `if`، جدول عدد ۹ تا `12 × 9` تولید می‌شود.

**نکته آموزشی:** این تمرین نشان می‌دهد که بسیاری از مسائل را می‌توان با استفاده از افزایش تدریجی یک متغیر حل کرد و همیشه نیازی به استفاده از عملگر ضرب نیست.
