# متد GET: ارسال داده از طریق نشانی صفحه

## خلاصه مطالب

### ۱. متد GET چیست؟

`GET` یکی از دو روش اصلی ارسال داده از فرم به سرور است. در این روش، داده‌های فرم به انتهای نشانی صفحه اضافه می‌شوند و در نوار آدرس مرورگر دیده می‌شوند. به زبان ساده: **داده‌ها روی نشانی صفحه سوار می‌شوند و به سرور می‌روند.**

وقتی نشانی یک صفحه را در مرورگر باز می‌کنیم، یک درخواست `GET` می‌فرستیم. وقتی فرمی با `method="get"` ارسال شود، مرورگر داده‌های آن را به همین شکل به نشانی مقصد می‌چسباند.

### ۲. شکل داده‌ها در نشانی

بخشی از نشانی که داده‌ها در آن قرار می‌گیرد، **Query String** نام دارد. این بخش با علامت `?` از نشانی اصلی جدا می‌شود. داده‌ها به شکل «نام=مقدار» نوشته می‌شوند و اگر چند داده باشند، میان آن‌ها `&` می‌آید.

```
page.php?name1=value1&name2=value2
```

- `?` آغاز بخش داده‌ها را نشان می‌دهد (در نشانی فقط یک بار می‌آید).
- `&` میان جفت‌های نام و مقدار جداکننده است.
- `نام` همان مقدار ویژگی `name` در ورودی فرم است.
- `مقدار` داده‌ای است که کاربر وارد یا انتخاب کرده است.

مثال ساده: اگر نشانی `search.php?q=php` را در مرورگر باز کنیم، یعنی یک داده با نام `q` و مقدار `php` به صفحه `search.php` فرستاده شده است.

### ۳. دیدن آرایه `$_GET` با `var_dump` (گام اول یادگیری)

پیش از هر کاری، خوب است ببینیم PHP داده‌های GET را چگونه نگه می‌دارد. PHP همه داده‌های GET را در آرایه‌ای به نام `$_GET` می‌ریزد. کلیدهای این آرایه، همان مقدار `name` ورودی‌ها هستند.

برای دیدن محتوای این آرایه، از `var_dump()` استفاده می‌کنیم. این تابع نوع و مقدار هر عضو آرایه را نشان می‌دهد.

**گام ۱ — یک فایل ساده می‌سازیم به نام `show.php`:**

```php
<?php
var_dump($_GET);
?>
```

**گام ۲ — در مرورگر این نشانی را باز می‌کنیم:**

```
show.php?name=Ali&age=15
```

**گام ۳ — خروجی چنین چیزی است:**

```
array(2) {
  ["name"]=>
  string(3) "Ali"
  ["age"]=>
  string(2) "15"
}
```

**این خروجی چه می‌گوید؟**

- `array(2)` یعنی آرایه دو عضو دارد.
- `["name"]` و `["age"]` کلیدهای آرایه‌اند (همان `name` ورودی‌ها).
- `string(3) "Ali"` یعنی مقدار `Ali` یک رشته است و ۳ نویسه دارد.
- `string(2) "15"` یعنی مقدار `15` هم **رشته** است، نه عدد. این نکته بسیار مهم است: هر چیزی که با GET بیاید، در PHP رشته است، حتی اگر عدد باشد.

اگر نشانی را عوض کنیم و `show.php?x=1` را باز کنیم، خروجی آرایه‌ای با یک عضو به نام `x` و مقدار رشته‌ای `"1"` خواهد بود.

اگر هیچ داده‌ای در نشانی نباشد (فقط `show.php`)، خروجی چنین است:

```
array(0) {
}
```

یعنی آرایه خالی است.

**نکته کاربردی:** قبل از استفاده از `$_GET` در فرم واقعی، همیشه با `var_dump` ببینید چه داده‌ای رسیده است. این کار مثل «چراغ‌قوه» است که نشان می‌دهد چه چیزی در آرایه هست.

### ۴. خواندن داده‌ها از `$_GET`

حالا که دیدیم آرایه چه شکلی است، خواندن داده ساده است. کافی است بنویسیم `$_GET['نام']` و مقدار را برداریم.

```php
<?php
$name = $_GET['name'];
echo "Hello " . $name;
?>
```

اگر نشانی `show.php?name=Ali` باشد، خروجی `Hello Ali` است.

**دو نکته ساده:**

- مقدار رسیده همیشه **رشته (string)** است.
- اگر آن کلید در نشانی وجود نداشته باشد، دسترسی مستقیم به آن ممکن است هشدار (Warning) ایجاد کند. برای پیشگیری، با `isset()` بررسی می‌کنیم:

```php
<?php
if (isset($_GET['name'])) {
    $name = $_GET['name'];
    echo "Hello " . $name;
} else {
    echo "No name provided.";
}
?>
```

`isset()` بررسی می‌کند که آیا این کلید در آرایه وجود دارد یا نه. اگر وجود داشت، مقدارش را برمی‌داریم؛ اگر نه، پیام مناسب نشان می‌دهیم.

### ۵. ویژگی‌های متد GET

**الف) داده‌ها در نوار آدرس دیده می‌شوند.** هر کسی به صفحه نگاه کند، داده‌ها را می‌بیند.

**ب) محدودیت طول نشانی.** نشانی نمی‌تواند بی‌نهایت بلند باشد. مرورگرها و سرورها محدودیتی در حدود ۲۰۰۰ نویسه دارند.

**پ) قابل نشانک‌گذاری است.** می‌توان نتیجه یک جستجو را در نشانک‌ها ذخیره کرد یا نشانی را برای دیگری فرستاد.

**ت) در تاریخچه مرورگر می‌ماند.** نشانی‌های GET در تاریخچه ذخیره می‌شوند.

**ث) وضعیت سرور را تغییر نمی‌دهد.** GET فقط برای **خواندن** اطلاعات است. نباید با آن داده‌ای در پایگاه داده ذخیره، حذف یا ویرایش کرد. اگر با GET چیزی ذخیره کنیم، هر بار بازخوانی صفحه همان عمل تکرار می‌شود.

### ۶. موارد کاربرد متد GET

GET جایی مناسب است که داده حساس نباشد و عملیات فقط خواندن باشد:

- **جستجو:** مثلاً `search.php?q=math`
- **فیلتر و مرتب‌سازی فهرست:** مثلاً `books.php?category=science&sort=price`
- **صفحه‌بندی:** مثلاً `articles.php?page=3`
- **پیوندهای اشتراک‌پذیر:** نشانی‌ای که می‌خواهیم برای دیگری بفرستیم.

### ۷. مثال کامل و ساده

فرض کنید صفحه‌ای برای جستجوی کتاب در کتابخانه مدرسه داریم.

**فایل `books-search.html`:**

```html
<form action="books-result.php" method="get">
    <label for="title">Title:</label>
    <input type="text" id="title" name="title">

    <label for="page">Page:</label>
    <input type="number" id="page" name="page" min="1" value="1">

    <button type="submit">Search</button>
</form>
```

اگر کاربر عنوان `math` و صفحه `2` را وارد کند، مرورگر به این نشانی درخواست می‌فرستد:

```
books-result.php?title=math&page=2
```

**فایل `books-result.php` — گام اول: ببینیم چه رسیده است**

```php
<?php
var_dump($_GET);
?>
```

خروجی:

```
array(2) {
  ["title"]=>
  string(4) "math"
  ["page"]=>
  string(1) "2"
}
```

**فایل `books-result.php` — گام دوم: از داده‌ها استفاده کنیم**

```php
<?php
if (isset($_GET['title'])) {
    $title = $_GET['title'];
    echo "Title: " . $title . "<br>";
} else {
    echo "No title provided.<br>";
}

if (isset($_GET['page'])) {
    $page = (int) $_GET['page'];
    if ($page < 1) {
        $page = 1;
    }
    echo "Page: " . $page . "<br>";
} else {
    echo "Page: 1<br>";
}
?>
```

**توضیح گام‌به‌گام:**

- با `isset()` بررسی کردیم که کلید وجود دارد.
- مقدار `page` را با `(int)` به عدد تبدیل کردیم. چون از GET همه چیز به‌صورت رشته می‌آید، برای استفاده عددی باید تبدیل کنیم.
- اگر مقدار `page` کوچک‌تر از ۱ بود، به ۱ برمی‌گردانیم تا صفحه‌بندی منطقی بماند.

### ۸. نکات امنیتی ساده درباره GET

- **داده محرمانه (رمز عبور، شماره کارت، کد ملی) را با GET نفرستید.** این داده‌ها در نوار آدرس و تاریخچه مرورگر دیده می‌شوند.
- **به داده‌های `$_GET` اعتماد نکنید.** کاربر می‌تواند نشانی را دستکاری کند، پس داده‌ها باید بررسی شوند.
- **برای تغییر داده از GET استفاده نکنید.** حذف، ویرایش و درج اطلاعات باید با روش دیگری انجام شود.

**نکته درباره امنیت نمایش داده:** پیش از نمایش هر داده‌ای که از کاربر آمده، باید آن را ایمن کنیم. تابع مناسب این کار در بخش «توابع پیش‌ساخته» به‌طور کامل معرفی و تمرین خواهد شد. در این درس فقط به همین اشاره بسنده می‌کنیم.

## ده پرسش چهارگزینه‌ای

**۱.** در متد GET، داده‌های فرم کجا قرار می‌گیرند؟
- الف) در بدنه درخواست
- ب) در انتهای نشانی صفحه
- پ) در کوکی
- ت) در یک فایل جداگانه

**۲.** کدام علامت، بخش داده‌ها (Query String) را از نشانی اصلی جدا می‌کند؟
- الف) `&`
- ب) `?`
- پ) `=`
- ت) `#`

**۳.** کدام علامت، میان جفت‌های نام و مقدار در Query String جداکننده است؟
- الف) `?`
- ب) `&`
- پ) `=`
- ت) `;`

**۴.** برای دیدن محتوای آرایه `$_GET` از کدام تابع استفاده می‌کنیم؟
- الف) `echo`
- ب) `print`
- پ) `var_dump`
- ت) `isset`

**۵.** اگر نشانی `show.php?name=Ali&age=15` باشد، خروجی `var_dump($_GET)` چند عضو دارد؟
- الف) ۱
- ب) ۲
- پ) ۳
- ت) ۴

**۶.** در همان نشانی، نوع مقدار `"15"` در آرایه `$_GET` چیست؟
- الف) عدد صحیح (int)
- ب) عدد اعشاری (float)
- پ) رشته (string)
- ت) بولین (bool)

**۷.** کدام تابع بررسی می‌کند که آیا یک کلید در آرایه `$_GET` وجود دارد یا نه؟
- الف) `var_dump`
- ب) `isset`
- پ) `echo`
- ت) `count`

**۸.** کدام کاربرد برای متد GET مناسب است؟
- الف) ارسال رمز عبور
- ب) جستجو در فهرست کتاب‌ها
- پ) حذف یک رکورد از پایگاه داده
- ت) ثبت‌نام کاربر جدید

**۹.** کدام مورد، از محدودیت‌های متد GET است؟
- الف) امکان نشانک‌گذاری وجود ندارد
- ب) محدودیت طول نشانی
- پ) عدم امکان استفاده در فرم جستجو
- ت) داده‌ها در تاریخچه مرورگر ذخیره نمی‌شوند

**۱۰.** کدام گزاره درباره امنیت GET درست است؟
- الف) برای اطلاعات محرمانه مناسب است
- ب) داده‌ها در نشانی رمزنگاری می‌شوند
- پ) برای اطلاعات محرمانه مناسب نیست، چون در نشانی دیده می‌شوند
- ت) استفاده از GET برای ثبت اطلاعات جدید کاربر بی‌اشکال است
