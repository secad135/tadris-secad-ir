# مقایسه متدهای GET و POST

## خلاصه مطالب

### ۱. چرا مقایسه؟

تا اینجا هر دو متد را جداگانه شناختیم. حالا وقت آن است که کنار هم بگذاریم و ببینیم کدام یک برای چه کاری مناسب‌تر است. این مقایسه به ما کمک می‌کند در ساخت فرم‌ها تصمیم درستی بگیریم.

### ۲. جدول مقایسه

| موضوع مقایسه | GET | POST |
|---|---|---|
| محل داده‌ها | در انتهای نشانی صفحه (Query String) | در بدنه درخواست |
| دیده شدن در نوار آدرس | بله، همه داده‌ها دیده می‌شوند | خیر، فقط نام صفحه دیده می‌شود |
| نگه‌داری در تاریخچه مرورگر | بله | خیر |
| امکان نشانک‌گذاری | بله | خیر |
| محدودیت طول داده | دارد (حدود ۲۰۰۰ نویسه) | عملاً ندارد |
| مناسب برای داده محرمانه | خیر | بله (به‌همراه HTTPS) |
| تأثیر بر وضعیت سرور | نباید تغییر دهد | برای تغییر ساخته شده است |
| هدف اصلی | خواندن اطلاعات | فرستادن و تغییر اطلاعات |
| بازخوانی صفحه | بی‌خطر | مرورگر هشدار تکرار می‌دهد |
| آرایه PHP مربوطه | `$_GET` | `$_POST` |

### ۳. توضیح ساده چند مورد کلیدی

**الف) محل داده‌ها**

این مهم‌ترین تفاوت است. در GET داده‌ها روی نشانی هستند و دیده می‌شوند؛ در POST داده‌ها در بدنه درخواست هستند و از دید کاربر پنهان‌اند.

**ب) امنیت**

POST داده را از نوار آدرس پنهان می‌کند، ولی این به‌تنهایی امنیت کامل نیست. برای امنیت واقعی در هر دو متد باید از HTTPS استفاده شود و داده‌ها بررسی شوند. با این حال، برای داده محرمانه (رمز عبور، شماره کارت) هرگز GET مناسب نیست.

**پ) هدف اصلی**

- GET برای **خواندن** است: جستجو، فیلتر، صفحه‌بندی.
- POST برای **تغییر** است: ثبت‌نام، ورود، ذخیره، حذف، ویرایش.

**ت) بازخوانی صفحه**

اگر با GET چیزی را در سرور تغییر دهیم (که کار نادرستی است)، هر بار بازخوانی صفحه همان عمل تکرار می‌شود. POST این مشکل را ندارد؛ مرورگر هنگام بازخوانی هشدار می‌دهد.

### ۴. راهنمای ساده انتخاب

برای انتخاب بین GET و POST، سه پرسش ساده از خود بپرسید:

**پرسش اول: آیا داده محرمانه است؟**
- بله → POST
- خیر → می‌توان GET را هم در نظر گرفت

**پرسش دوم: آیا این عملیات اطلاعات را در سرور تغییر می‌دهد؟**
- بله (ثبت، حذف، ویرایش) → POST
- خیر (فقط خواندن) → GET

**پرسش سوم: آیا می‌خواهیم نشانی نتیجه قابل ذخیره یا اشتراک باشد؟**
- بله → GET
- خیر → POST

اگر هر سه پرسش به GET اشاره کرد، از GET استفاده کنید. در غیر این صورت، POST انتخاب مطمئن‌تری است.

**قاعده ساده و کاربردی:** اگر شک کردید، POST را انتخاب کنید. POST برای اکثر فرم‌های واقعی (ورود، ثبت‌نام، تماس، ذخیره) انتخاب درست است.

### ۵. مثال کنار هم

فرض کنید دو صفحه داریم: یکی برای جستجوی کتاب و یکی برای ثبت‌نام در کلاس.

**جستجوی کتاب — GET مناسب است:**

```html
<form action="search.php" method="get">
    <label for="q">Search:</label>
    <input type="text" id="q" name="q">
    <button type="submit">Search</button>
</form>
```

نتیجه: نشانی `search.php?q=math` قابل ذخیره و اشتراک است. داده محرمانه‌ای هم وجود ندارد. اگر صفحه بازخوانی شود، فقط همان جستجو تکرار می‌شود و تغییری در سرور رخ نمی‌دهد.

**ثبت‌نام در کلاس — POST مناسب است:**

```html
<form action="register.php" method="post">
    <label for="fullname">Full Name:</label>
    <input type="text" id="fullname" name="fullname">

    <label for="password">Password:</label>
    <input type="password" id="password" name="password">

    <button type="submit" name="submit">Register</button>
</form>
```

نتیجه: نشانی فقط `register.php` را نشان می‌دهد؛ رمز عبور در نوار آدرس دیده نمی‌شود. اگر صفحه بازخوانی شود، مرورگر هشدار می‌دهد تا ثبت تکراری رخ ندهد.

### ۶. نکته پایانی

GET و POST ابزارهای متفاوتی برای کارهای متفاوت‌اند؛ هیچ‌کدام «بهتر» نیستند. انتخاب درست به این بستگی دارد که چه کاری می‌خواهیم انجام دهیم و داده چه نوعی دارد. با سه پرسش بالا، انتخاب همیشه روشن خواهد بود.

## ده پرسش چهارگزینه‌ای

**۱.** تفاوت اصلی GET و POST در چیست؟
- الف) GET فقط در PHP کار می‌کند
- ب) محل قرارگیری داده‌ها (نشانی در برابر بدنه درخواست)
- پ) POST فقط برای فایل است
- ت) GET امن‌تر از POST است

**۲.** کدام متد داده‌ها را در نوار آدرس نمایش می‌دهد؟
- الف) POST
- ب) GET
- پ) هر دو
- ت) هیچ‌کدام

**۳.** کدام متد نتیجه‌اش قابل نشانک‌گذاری است؟
- الف) POST
- ب) GET
- پ) هر دو
- ت) هیچ‌کدام

**۴.** برای ارسال رمز عبور، کدام متد مناسب است؟
- الف) GET
- ب) POST
- پ) هر دو
- ت) هیچ‌کدام

**۵.** برای جستجو در فهرست کتاب‌ها، کدام متد مناسب‌تر است؟
- الف) GET
- ب) POST
- پ) هر دو یکسان‌اند
- ت) هیچ‌کدام

**۶.** کدام متد محدودیت طول داده دارد؟
- الف) GET
- ب) POST
- پ) هر دو
- ت) هیچ‌کدام

**۷.** اگر بخواهیم اطلاعاتی را در پایگاه داده ذخیره کنیم، کدام متد درست است؟
- الف) GET
- ب) POST
- پ) هر دو
- ت) بستگی به رنگ صفحه دارد

**۸.** کدام آرایه PHP مربوط به GET است؟
- الف) `$_POST`
- ب) `$_GET`
- پ) `$_FILES`
- ت) `$_SESSION`

**۹.** اگر شک کنیم کدام متد را انتخاب کنیم، انتخاب مطمئن‌تر کدام است؟
- الف) GET
- ب) POST
- پ) هر دو یکسان‌اند
- ت) هیچ‌کدام

**۱۰.** کدام گزاره درباره امنیت درست است؟
- الف) POST داده را کاملاً امن می‌کند و نیازی به HTTPS نیست
- ب) GET برای داده محرمانه مناسب است
- پ) POST داده را از URL پنهان می‌کند، ولی برای امنیت کامل HTTPS لازم است
- ت) GET داده‌ها را رمزنگاری می‌کند
