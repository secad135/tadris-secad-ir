# ساخت فرم و انواع ورودی‌ها در HTML

## خلاصه مطالب

### ۱. فرم چیست؟

فرم، بخشی از یک صفحه وب است که به کاربر امکان می‌دهد اطلاعات وارد کند و برای پردازش به سرور بفرستد. همه جاهایی که کاربر باید چیزی بنویسد یا گزینه‌ای انتخاب کند (فرم عضویت، ورود، تماس با ما، جستجو) از فرم استفاده می‌شود. ساخت فرم در HTML انجام می‌شود و پردازش داده‌های آن در PHP.

### ۲. ساختار پایه فرم و صفت‌های اصلی تگ `<form>`

فرم با تگ `<form>` ساخته می‌شود. سه صفت مهم آن عبارت‌اند از:

- **`action`** — نشانی صفحه‌ای که داده‌ها به آن فرستاده می‌شوند (مثلاً `process.php`). اگر خالی بماند، داده‌ها به همان صفحه فرستاده می‌شوند.
- **`method`** — روش ارسال داده؛ مقدار `GET` یا `POST`. اگر نوشته نشود، پیش‌فرض `GET` است.
- **`enctype`** — شکل کدگذاری داده‌ها. برای فرم‌های معمولی نیازی به نوشتن ندارد، اما **اگر فرم فایل بفرستد، باید `multipart/form-data` باشد**.

نمونه پایه:

```html
<form action="process.php" method="post">
    ...
</form>
```

ساخت فرم چند گام ساده دارد: نوشتن تگ `<form>`، گذاشتن برچسب `<label>` و ورودی `<input>` برای هر داده، و در پایان گذاشتن دکمه ثبت `<button type="submit">`.

### ۳. انواع ورودی‌ها همراه با کد نمونه

همه ورودی‌های متنی و انتخابی با تگ `<input>` ساخته می‌شوند و صفت `type` شکل آن‌ها را تعیین می‌کند. در ادامه، هر نوع پرکاربرد با یک نمونه کوتاه آمده است.

**الف) ورودی متنی ساده**

```html
<label for="fullname">نام و نام خانوادگی:</label>
<input type="text" id="fullname" name="fullname" placeholder="مثلاً علی رضایی" required>
```

**ب) رمز عبور**

```html
<label for="pass">رمز عبور:</label>
<input type="password" id="pass" name="pass">
```

**پ) ایمیل**

```html
<label for="email">ایمیل:</label>
<input type="email" id="email" name="email" required>
```

**ت) عدد**

```html
<label for="age">سن:</label>
<input type="number" id="age" name="age" min="10" max="100">
```

**ث) دکمه رادیویی (Radio) — انتخاب فقط یک گزینه**

نکته کلیدی: همه دکمه‌های رادیویی یک گروه باید **`name` یکسان** داشته باشند تا کاربر فقط یکی را بتواند انتخاب کند.

```html
<p>جنسیت:</p>
<input type="radio" id="male" name="gender" value="male">
<label for="male">مرد</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">زن</label>
```

**ج) جعبه انتخابی (Checkbox) — انتخاب چندگانه**

هر گزینه معمولاً `name` جداگانه دارد و کاربر می‌تواند چند مورد را هم‌زمان انتخاب کند.

```html
<p>علاقه‌مندی‌ها:</p>
<input type="checkbox" id="sport" name="hobby_sport" value="1">
<label for="sport">ورزش</label>

<input type="checkbox" id="music" name="hobby_music" value="1">
<label for="music">موسیقی</label>

<input type="checkbox" id="book" name="hobby_book" value="1">
<label for="book">کتاب</label>
```

**چ) تاریخ**

```html
<label for="birthday">تاریخ تولد:</label>
<input type="date" id="birthday" name="birthday">
```

**ح) رنگ**

```html
<label for="color">رنگ مورد علاقه:</label>
<input type="color" id="color" name="color" value="#3366ff">
```

**خ) انتخاب فایل**

```html
<label for="photo">عکس پروفایل:</label>
<input type="file" id="photo" name="photo" accept="image/*">
```

(برای کار کردن این ورودی، تگ `<form>` باید `enctype="multipart/form-data"` داشته باشد.)

**د) ورودی پنهان (Hidden)**

```html
<input type="hidden" name="form_version" value="1">
```

برای انتقال داده‌های کمکی همراه فرم (مانند شناسه یا نسخه فرم) به کار می‌رود. کاربر آن را نمی‌بیند، ولی چون در صفحه قابل ویرایش است، نباید داده حساس یا قابل اعتماد در آن گذاشت.

**ذ) کادر متن چندخطی (`<textarea>`)**

```html
<label for="bio">درباره من:</label>
<textarea id="bio" name="bio" rows="4" cols="40"></textarea>
```

**ر) فهرست کشویی (`<select>` و `<option>`)**

```html
<label for="city">شهر:</label>
<select id="city" name="city">
    <option value="tehran">تهران</option>
    <option value="shiraz">شیراز</option>
    <option value="mashhad">مشهد</option>
</select>
```

**ز) صفت‌های پرکاربرد مشترک ورودی‌ها**

- **`name`** — نام داده هنگام ارسال به سرور؛ **بدون آن، مقدار ورودی ارسال نمی‌شود**.
- **`id`** — شناسه یکتا؛ برای اتصال `<label>` به ورودی.
- **`value`** — مقدار اولیه یا مقدار ارسالی.
- **`placeholder`** — متن راهنمای کم‌رنگ داخل کادر.
- **`required`** — پر کردن این ورودی الزامی است.
- **`readonly`** — قابل مشاهده ولی تغییرناپذیر؛ مقدار ارسال می‌شود.
- **`disabled`** — غیرفعال؛ مقدار ارسال نمی‌شود.
- **`maxlength`** — بیشترین تعداد نویسه مجاز.

### ۴. دکمه ثبت (Submit Button)

بدون دکمه ثبت، کاربر نمی‌تواند داده‌ها را بفرستد. دو راه رایج:

**الف) `<input type="submit">`**

```html
<input type="submit" value="ثبت">
```

متن دکمه از `value` گرفته می‌شود.

**ب) `<button type="submit">`**

```html
<button type="submit">ثبت</button>
```

انعطاف بیشتری دارد و می‌تواند محتوای پیچیده‌تری مانند آیکون داشته باشد. امروزه رایج‌تر است. بهتر است همیشه `type` را صریح بنویسیم.

**دو دکمه دیگر که خوب است بشناسیم:**

- **`reset`** — همه ورودی‌های فرم را به مقدار اولیه برمی‌گرداند و داده‌ای نمی‌فرستد:

```html
<button type="reset">پاک‌کردن فرم</button>
```

- **`button`** — هیچ رفتار پیش‌فرضی ندارد و فقط با جاوااسکریپت کار می‌کند. اگر دکمه‌ای داخل فرم باشد ولی نمی‌خواهیم فرم را ارسال کند، `type="button"` ضروری است:

```html
<button type="button">دکمه ساده</button>
```

**نکته مفید:** اگر روی دکمه ثبت، `name` و `value` بگذاریم، هنگام کلیک، آن جفت نام و مقدار هم به سرور می‌رسد. این کار برای فرم‌هایی که چند دکمه ثبت دارند (مثلاً «ذخیره» و «حذف») بسیار کارآمد است:

```html
<button type="submit" name="action" value="save">ذخیره</button>
<button type="submit" name="action" value="delete">حذف</button>
```

### ۵. یک مثال کامل و جالب: فرم عضویت در باشگاه بازی‌سازی مدرسه

فرض کنید می‌خواهیم فرمی بسازیم که دانش‌آموزان برای عضویت در باشگاه بازی‌سازی مدرسه پر کنند. در این فرم از انواع مختلف ورودی استفاده می‌شود:

```html
<form action="join-club.php" method="post" enctype="multipart/form-data">

    <h2>فرم عضویت در باشگاه بازی‌سازی مدرسه</h2>

    <p>
        <label for="nickname">نام مستعار (Nickname):</label>
        <input type="text" id="nickname" name="nickname"
               placeholder="مثلاً ShadowMaster" maxlength="20" required>
    </p>

    <p>
        <label for="email">ایمیل:</label>
        <input type="email" id="email" name="email" required>
    </p>

    <p>
        <label for="birthday">تاریخ تولد:</label>
        <input type="date" id="birthday" name="birthday">
    </p>

    <p>سطح تجربه:</p>
    <input type="radio" id="beginner" name="level" value="beginner" checked>
    <label for="beginner">مبتدی</label>

    <input type="radio" id="intermediate" name="level" value="intermediate">
    <label for="intermediate">متوسط</label>

    <input type="radio" id="advanced" name="level" value="advanced">
    <label for="advanced">پیشرفته</label>

    <p>زمینه‌های مورد علاقه (چند مورد را می‌توانید انتخاب کنید):</p>
    <input type="checkbox" id="design" name="interest_design" value="1">
    <label for="design">طراحی بازی</label>

    <input type="checkbox" id="code" name="interest_code" value="1">
    <label for="code">برنامه‌نویسی</label>

    <input type="checkbox" id="graphic" name="interest_graphic" value="1">
    <label for="graphic">گرافیک</label>

    <input type="checkbox" id="sound" name="interest_sound" value="1">
    <label for="sound">صداگذاری</label>

    <p>
        <label for="genre">ژانر مورد علاقه:</label>
        <select id="genre" name="genre">
            <option value="puzzle">معمایی</option>
            <option value="action">اکشن</option>
            <option value="strategy">استراتژی</option>
            <option value="sports">ورزشی</option>
        </select>
    </p>

    <p>
        <label for="team_color">رنگ تیم:</label>
        <input type="color" id="team_color" name="team_color" value="#ff6600">
    </p>

    <p>
        <label for="avatar">تصویر آواتار:</label>
        <input type="file" id="avatar" name="avatar" accept="image/*">
    </p>

    <p>
        <label for="bio">درباره من:</label>
        <textarea id="bio" name="bio" rows="3" cols="40"
                  placeholder="چند جمله درباره خودت بنویس..."></textarea>
    </p>

    <input type="hidden" name="form_version" value="1">

    <p>
        <button type="submit" name="action" value="register">ثبت‌نام</button>
        <button type="reset">پاک‌کردن فرم</button>
    </p>

</form>
```

این مثال همه چیزهایی را که در این درس دیدیم یک‌جا جمع کرده است: متن، ایمیل، تاریخ، رادیو، چک‌باکس، منوی کشویی، رنگ، فایل، کادر چندخطی، ورودی پنهان و دو دکمه ثبت و بازنشانی.

## ده پرسش چهارگزینه‌ای

**۱.** کدام صفت تگ `<form>` نشانی صفحه پردازش‌کننده داده‌ها را مشخص می‌کند؟
- الف) `method`
- ب) `action`
- پ) `enctype`
- ت) `name`

**۲.** برای ارسال فایل از طریق فرم، مقدار درست `enctype` کدام است؟
- الف) `text/plain`
- ب) `application/x-www-form-urlencoded`
- پ) `multipart/form-data`
- ت) `application/json`

**۳.** در دکمه‌های رادیویی، برای اینکه کاربر فقط یکی را بتواند انتخاب کند، چه شرطی لازم است؟
- الف) همه `id` یکسان داشته باشند
- ب) همه `name` یکسان داشته باشند
- پ) همه `value` یکسان داشته باشند
- ت) همه `type="checkbox"` باشند

**۴.** برای اینکه کاربر بتواند چند گزینه را هم‌زمان انتخاب کند، از کدام ورودی استفاده می‌شود؟
- الف) `radio`
- ب) `checkbox`
- پ) `text`
- ت) `password`

**۵.** اگر ورودی‌ای `name` نداشته باشد، چه اتفاقی می‌افتد؟
- الف) مرورگر خطا نشان می‌دهد
- ب) مقدار آن ورودی به سرور نمی‌رسد
- پ) مقدار آن به‌طور خودکار ارسال می‌شود
- ت) فرم بسته می‌شود

**۶.** کدام گزاره درباره `readonly` و `disabled` درست است؟
- الف) هر دو مقدار را ارسال می‌کنند
- ب) هیچ‌کدام مقدار را ارسال نمی‌کنند
- پ) `readonly` مقدار را ارسال می‌کند ولی `disabled` ارسال نمی‌کند
- ت) `disabled` مقدار را ارسال می‌کند ولی `readonly` ارسال نمی‌کند

**۷.** کدام مورد، ورودی‌ای است که کاربر آن را نمی‌بیند ولی مقدارش ارسال می‌شود؟
- الف) `password`
- ب) `hidden`
- پ) `readonly`
- ت) `disabled`

**۸.** برای ساخت کادر متن چندخطی از کدام تگ استفاده می‌شود؟
- الف) `<input type="text">`
- ب) `<textarea>`
- پ) `<select>`
- ت) `<label>`

**۹.** برای ساخت فهرست کشویی از کدام تگ‌ها استفاده می‌شود؟
- الف) `<select>` و `<option>`
- ب) `<input>` و `<label>`
- پ) `<textarea>` و `<label>`
- ت) `<button>` و `<option>`

**۱۰.** کدام گزاره درباره دکمه‌های داخل فرم درست است؟
- الف) `<button>` بدون نوشتن `type` فرم را ارسال نمی‌کند
- ب) `<button>` بدون نوشتن `type` به‌طور پیش‌فرض `submit` است و فرم را ارسال می‌کند
- پ) دکمه `reset` داده‌ها را به سرور می‌فرستد
- ت) دکمه `button` همیشه فرم را ارسال می‌کند

| ۱ | ب | `action` نشانی مقصد را تعیین می‌کند. |
| ۲ | پ | ارسال فایل فقط با `multipart/form-data` انجام می‌شود. |
| ۳ | ب | `name` یکسان، دکمه‌های رادیویی را در یک گروه قرار می‌دهد. |
| ۴ | ب | `checkbox` انتخاب چندگانه را ممکن می‌کند. |
| ۵ | ب | بدون `name`، داده ارسال نمی‌شود. |
| ۶ | پ | `readonly` ارسال می‌شود؛ `disabled` نمی‌شود. |
| ۷ | ب | `hidden` دیده نمی‌شود ولی ارسال می‌شود. |
| ۸ | ب | متن چندخطی با `<textarea>` ساخته می‌شود. |
| ۹ | الف | فهرست کشویی از `<select>` و `<option>` ساخته می‌شود. |
| ۱۰ | ب | `type` پیش‌فرض `<button>` برابر `submit` است. |
