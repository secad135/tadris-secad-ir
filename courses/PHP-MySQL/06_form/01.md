# جزوه آموزشی: ساخت فرم و انواع ورودی‌ها در HTML

## ۱. فرم چیست و چه کاربردی دارد؟

حتماً هنگام استفاده از سایت‌های مختلف، فرم‌هایی را دیده‌اید که از شما اطلاعاتی مانند نام، شماره تلفن، ایمیل یا رمز عبور می‌خواهند.

**فرم (Form)** بخشی از یک صفحه وب است که به کاربر اجازه می‌دهد اطلاعاتی را وارد کند یا از بین چند گزینه، مواردی را انتخاب کند و سپس آن اطلاعات را برای پردازش ارسال کند.

برای مثال، در موقعیت‌های زیر از فرم استفاده می‌شود:

- ثبت‌نام در یک سایت
- ورود به حساب کاربری
- ارسال پیام در بخش تماس با ما
- جستجوی مطالب
- ثبت سفارش خرید

در HTML ساختار ظاهری فرم و ورودی‌های آن را ایجاد می‌کنیم. سپس با زبان‌هایی مانند PHP می‌توانیم اطلاعات دریافت‌شده را پردازش کنیم و در پایگاه داده ذخیره کنیم.

---

## ۲. ساختار اصلی فرم در HTML

برای ساخت فرم از تگ `<form>` استفاده می‌کنیم.

این تگ مانند یک ظرف است که تمام ورودی‌ها و دکمه‌های مربوط به یک فرم را درون خود قرار می‌دهد.

### نمونه ساختار یک فرم

```html
<form action="process.php" method="post">

    <!-- ورودی‌های فرم در این قسمت قرار می‌گیرند -->

    <button type="submit">ارسال اطلاعات</button>

</form>
```

در تگ `<form>` چند صفت مهم وجود دارد:

**۱. صفت `action`**

مشخص می‌کند اطلاعات فرم به کدام صفحه ارسال شوند.

مثلاً:

```html
action="process.php"
```

یعنی اطلاعات فرم برای پردازش به فایل `process.php` ارسال می‌شوند.

**۲. صفت `method`**

روش ارسال اطلاعات را مشخص می‌کند.

دو مقدار پرکاربرد دارد:

- `GET` : اطلاعات از طریق آدرس صفحه ارسال می‌شوند.
- `POST` : اطلاعات در بدنه درخواست ارسال می‌شوند و معمولاً برای فرم‌های ثبت‌نام و ورود مناسب‌تر است.

نکته: اگر صفت `method` را ننویسیم، روش پیش‌فرض `GET` خواهد بود.

**۳. صفت `enctype`**

نوع کدگذاری اطلاعات هنگام ارسال را مشخص می‌کند.

در فرم‌های معمولی نیازی به نوشتن آن نیست؛ اما اگر بخواهیم فایلی مانند عکس را ارسال کنیم، باید از مقدار زیر استفاده کنیم:

```html
enctype="multipart/form-data"
```

## ۳. ساخت اولین ورودی فرم

فرض کنید می‌خواهیم از کاربر نام و نام خانوادگی او را دریافت کنیم.

برای ساخت یک کادر متنی از تگ `<input>` استفاده می‌کنیم.

اما بهتر است کنار هر ورودی، یک توضیح قرار دهیم تا کاربر بداند چه اطلاعاتی باید وارد کند.

برای این کار از تگ `<label>` استفاده می‌کنیم.

### نمونه ساخت ورودی نام و نام خانوادگی

```html
<label for="fn">نام و نام خانوادگی:</label>

<input
    type="text"
    id="fn"
    name="fullname"
>
```

در این مثال، سه بخش مهم وجود دارد:

**۱. تگ `label`**

متنی را نمایش می‌دهد که مشخص می‌کند کاربر باید چه اطلاعاتی وارد کند.

**۲. صفت `id`**

برای مشخص کردن شناسه ورودی استفاده می‌شود.

**۳. صفت `name`**

نامی است که اطلاعات ورودی هنگام ارسال به سرور با آن شناخته می‌شود.

### ارتباط `label` و `input`

در مثال بالا دو صفت `for` و `id` با یکدیگر ارتباط دارند.

مقدار `for` در تگ `label` باید با مقدار `id` در تگ `input` یکسان باشد.

مثلاً:

```html
<label for="fullname">نام:</label>

<input type="text" id="fullname" name="fullname">
```

با این ارتباط، وقتی کاربر روی متن «نام» کلیک کند، کادر مربوط به آن فعال می‌شود.

### تفاوت `id` و `name`

این دو صفت بسیار مهم هستند و نباید آن‌ها را با یکدیگر اشتباه بگیرید.

| صفت | کاربرد |
|---|---|
| `id` | شناسه ورودی در صفحه HTML است. |
| `name` | نام اطلاعات هنگام ارسال به سرور است. |

**نکته مهم:** اگر ورودی `name` نداشته باشد، مقدار آن هنگام ارسال فرم به سرور فرستاده نمی‌شود.

## ۴. انواع ورودی‌ها در HTML

در HTML می‌توانیم ورودی‌های مختلفی برای دریافت اطلاعات از کاربر ایجاد کنیم.

بیشتر این ورودی‌ها با تگ `<input>` ساخته می‌شوند و نوع آن‌ها با صفت `type` مشخص می‌شود.

در ادامه با انواع پرکاربرد ورودی‌ها آشنا می‌شویم.

### ۱. ورودی متنی (Text)

برای دریافت اطلاعات متنی مانند نام، نام خانوادگی و نام کاربری استفاده می‌شود.

```html
<label for="fullname">نام و نام خانوادگی:</label>

<input
    type="text"
    id="fullname"
    name="fullname"
    placeholder="مثلاً علی رضایی"
    required
>
```

دو صفت جدید در این مثال داریم:

- `placeholder` : یک متن راهنما داخل کادر نمایش می‌دهد که با تایپ کاربر محو می‌شود.
- `required` : مشخص می‌کند که وارد کردن اطلاعات این کادر الزامی است.

### ۲. ورودی رمز عبور (Password)

برای دریافت رمز عبور استفاده می‌شود. حروف و اعداد واردشده به شکل مخفی نمایش داده می‌شوند.

```html
<label for="pass">رمز عبور:</label>

<input
    type="password"
    id="pass"
    name="pass"
>
```

نکته: این ورودی فقط نوشته‌ها را روی صفحه مخفی می‌کند و به‌تنهایی باعث رمزگذاری اطلاعات نمی‌شود.

### ۳. ورودی ایمیل (Email)

برای دریافت نشانی ایمیل استفاده می‌شود.

```html
<label for="email">ایمیل:</label>

<input
    type="email"
    id="email"
    name="email"
    required
>
```

مرورگر هنگام ارسال فرم، شکل کلی ایمیل را بررسی می‌کند؛ مثلاً اگر نشانی ایمیل به شکل صحیح نوشته نشده باشد، ممکن است اجازه ارسال فرم را ندهد.

### ۴. ورودی شماره تلفن (Tel)

برای دریافت شماره تلفن استفاده می‌شود.

```html
<label for="phone">شماره تماس:</label>

<input
    type="tel"
    id="phone"
    name="phone"
    placeholder="09121234567"
>
```

این نوع ورودی در تلفن‌های همراه معمولاً صفحه‌کلید مناسب‌تری برای وارد کردن شماره تلفن نمایش می‌دهد.

### ۵. ورودی عددی (Number)

برای دریافت اطلاعات عددی مانند سن، تعداد یا قیمت استفاده می‌شود.

```html
<label for="age">سن:</label>

<input
    type="number"
    id="age"
    name="age"
    min="10"
    max="100"
>
```

دو صفت مهم در این مثال:

- `min` : کمترین مقدار مجاز را مشخص می‌کند.
- `max` : بیشترین مقدار مجاز را مشخص می‌کند.

در این مثال کاربر می‌تواند عددی بین ۱۰ تا ۱۰۰ وارد کند.

### ۶. دکمه رادیویی (Radio)

گاهی می‌خواهیم کاربر فقط یکی از چند گزینه را انتخاب کند.

برای این کار از `type="radio"` استفاده می‌کنیم.

مثلاً فرض کنید می‌خواهیم کاربر جنسیت خود را انتخاب کند:

```html
<p>جنسیت:</p>

<input type="radio" id="male" name="gender" value="male">
<label for="male">مرد</label>

<input type="radio" id="female" name="gender" value="female">
<label for="female">زن</label>
```

**نکته بسیار مهم:** برای اینکه چند دکمه رادیویی به یک گروه تعلق داشته باشند و کاربر فقط بتواند یکی از آن‌ها را انتخاب کند، باید صفت `name` آن‌ها یکسان باشد.

در این مثال هر دو ورودی دارای `name="gender"` هستند.

همچنین صفت `value` مقداری را مشخص می‌کند که در صورت انتخاب گزینه به سرور ارسال می‌شود.

### ۷. جعبه انتخابی (Checkbox)

اگر بخواهیم کاربر بتواند چند گزینه را هم‌زمان انتخاب کند، از `type="checkbox"` استفاده می‌کنیم.

مثلاً برای انتخاب علاقه‌مندی‌ها:

```html
<p>علاقه‌مندی‌ها:</p>
<input 
    type="checkbox" 
    id="sport" 
    name="hobby[]" 
    value="sport"
>
<label for="sport">ورزش</label>

<input 
    type="checkbox" 
    id="music" 
    name="hobby[]" 
    value="music"
>
<label for="music">موسیقی</label>

<input 
    type="checkbox" 
    id="book" 
    name="hobby[]" 
    value="book"
>
<label for="book">کتاب</label>
```

در این مثال کاربر می‌تواند یک یا چند گزینه را انتخاب کند.

**تفاوت Radio و Checkbox:**

- Radio : انتخاب فقط یک گزینه از بین چند گزینه.
- Checkbox : امکان انتخاب چند گزینه به‌صورت هم‌زمان.

### ۸. ورودی تاریخ (Date)

برای دریافت تاریخ از کاربر استفاده می‌شود.

```html
<label for="birthday">تاریخ تولد:</label>

<input
    type="date"
    id="birthday"
    name="birthday"
>
```

مرورگر معمولاً یک ابزار انتخاب تاریخ در اختیار کاربر قرار می‌دهد.

### ۹. ورودی انتخاب رنگ (Color)

برای انتخاب رنگ استفاده می‌شود.

```html
<label for="color">رنگ مورد علاقه:</label>

<input
    type="color"
    id="color"
    name="color"
    value="#3366ff"
>
```

با کلیک روی این ورودی، ابزار انتخاب رنگ باز می‌شود.

صفت `value` رنگ اولیه را مشخص می‌کند.

### ۱۰. ورودی انتخاب فایل (File)

برای انتخاب و ارسال فایل‌هایی مانند عکس و سند استفاده می‌شود.

```html
<label for="photo">عکس پروفایل:</label>

<input
    type="file"
    id="photo"
    name="photo"
    accept="image/*"
>
```

در این مثال کاربر می‌تواند یک تصویر انتخاب کند.

صفت `accept` مشخص می‌کند چه نوع فایل‌هایی برای انتخاب پیشنهاد شوند.

**نکته مهم:** برای ارسال فایل، تگ `form` باید دارای صفت زیر باشد:

```html
enctype="multipart/form-data"
```

### ۱۱. ورودی پنهان (Hidden)

گاهی لازم است اطلاعاتی همراه فرم ارسال شوند، اما کاربر آن‌ها را در صفحه مشاهده نکند.

برای این کار از `type="hidden"` استفاده می‌کنیم.

```html
<input
    type="hidden"
    name="form_version"
    value="1"
>
```

این ورودی در صفحه نمایش داده نمی‌شود، اما مقدار آن همراه فرم ارسال می‌شود.

نکته: اطلاعات پنهان به معنی اطلاعات محرمانه یا امن نیستند؛ بنابراین نباید اطلاعات حساس را در آن قرار دهیم.

### ۱۲. کادر متن چندخطی (Textarea)

برای دریافت متن‌های طولانی مانند توضیحات، پیام‌ها و نظرات از تگ `<textarea>` استفاده می‌کنیم.

```html
<label for="bio">درباره من:</label>

<textarea
    id="bio"
    name="bio"
    rows="4"
    cols="40"
></textarea>
```

تفاوت این تگ با `input type="text"` در این است که `textarea` امکان نوشتن متن در چند خط را فراهم می‌کند.

- `rows` : تعداد تقریبی سطرهای قابل مشاهده را مشخص می‌کند.
- `cols` : عرض تقریبی کادر را مشخص می‌کند.

### ۱۳. فهرست کشویی (Select)

گاهی به‌جای نمایش چندین گزینه، بهتر است آن‌ها را در یک فهرست کشویی قرار دهیم.

برای ساخت فهرست کشویی از دو تگ `<select>` و `<option>` استفاده می‌کنیم.

```html
<label for="city">شهر:</label>

<select id="city" name="city">

    <option value="tehran">تهران</option>
    <option value="shiraz">شیراز</option>
    <option value="mashhad">مشهد</option>

</select>
```

در این مثال:

- `select` فهرست کشویی را ایجاد می‌کند.
- `option` گزینه‌های موجود در فهرست را مشخص می‌کند.

کاربر می‌تواند یکی از شهرها را انتخاب کند.

## ۵. صفت‌های پرکاربرد در ورودی‌های فرم

تا اینجا با انواع ورودی‌ها آشنا شدیم. حالا بهتر است مهم‌ترین صفت‌هایی را که در ساخت فرم استفاده می‌شوند، مرور کنیم.

| صفت | کاربرد |
|---|---|
| `name` | نام اطلاعات هنگام ارسال به سرور |
| `id` | شناسه ورودی در صفحه |
| `value` | مقدار اولیه یا مقدار ارسالی |
| `placeholder` | نمایش متن راهنما داخل کادر |
| `required` | اجباری کردن ورود اطلاعات |
| `readonly` | نمایش اطلاعات بدون امکان تغییر توسط کاربر |
| `disabled` | غیرفعال کردن ورودی |
| `maxlength` | تعیین حداکثر تعداد نویسه‌ها |
| `checked` | انتخاب پیش‌فرض Radio یا Checkbox |
| `min` | تعیین حداقل مقدار مجاز |
| `max` | تعیین حداکثر مقدار مجاز |

### تفاوت readonly و disabled

این دو صفت ممکن است در نگاه اول شبیه به هم باشند، اما تفاوت مهمی دارند.

**readonly:** کاربر می‌تواند مقدار را مشاهده کند، اما نمی‌تواند آن را تغییر دهد. مقدار این ورودی هنگام ارسال فرم فرستاده می‌شود.

**disabled:** ورودی غیرفعال می‌شود و کاربر نمی‌تواند با آن کار کند. مقدار آن نیز هنگام ارسال فرم فرستاده نمی‌شود.

## ۶. دکمه‌های فرم

پس از اینکه کاربر اطلاعات موردنیاز را وارد کرد، باید بتواند فرم را ارسال کند.

برای ایجاد دکمه ارسال فرم دو روش رایج وجود دارد.

### روش اول: input با نوع submit

```html
<input type="submit" value="ثبت اطلاعات">
```

در این روش، متن دکمه با صفت `value` مشخص می‌شود.

### روش دوم: button با نوع submit

```html
<button type="submit">ثبت اطلاعات</button>
```

این روش انعطاف‌پذیری بیشتری دارد و امروزه بسیار رایج است.

### آشنایی با انواع دکمه‌ها

تگ `button` سه نوع پرکاربرد دارد:

**۱. submit**

برای ارسال فرم استفاده می‌شود.

```html
<button type="submit">ارسال</button>
```

**۲. reset**

مقادیر ورودی‌های فرم را به حالت اولیه برمی‌گرداند.

```html
<button type="reset">پاک کردن فرم</button>
```

**۳. button**

به‌تنهایی عملیات خاصی انجام نمی‌دهد و معمولاً برای اجرای دستورات جاوااسکریپت استفاده می‌شود.

```html
<button type="button">دکمه ساده</button>
```

**نکته مهم:** اگر برای تگ `button` نوع مشخص نکنیم، به‌طور پیش‌فرض مانند دکمه `submit` عمل می‌کند. بنابراین بهتر است همیشه نوع دکمه را مشخص کنیم.

## ۷. مثال عملی: ساخت فرم عضویت در باشگاه بدن‌سازی

حالا که با تگ‌ها و صفت‌های مختلف آشنا شدیم، می‌خواهیم یک فرم نسبتاً کامل طراحی کنیم.

فرض کنید یک باشگاه بدن‌سازی قصد دارد اطلاعات افراد متقاضی عضویت را از طریق سایت دریافت کند.

در این فرم از ورودی‌های مختلفی استفاده می‌کنیم که در این درس یاد گرفتیم.

```html
<!DOCTYPE html>
<html lang="fa" dir="rtl">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>فرم ثبت نام</title>
    <link rel="stylesheet" href="https://code.secad.ir/temp.css">
</head>
<body>
    
<form
    action=""
    method=""
    enctype="multipart/form-data"
>

    <h2>فرم عضویت در باشگاه بدن‌سازی</h2>

    <p>
        <label for="fullname">نام و نام خانوادگی:</label>

        <input
            type="text"
            id="fullname"
            name="fullname"
            placeholder="مثلاً علی رضایی"
            maxlength="50"
            required
        >
    </p>

    <p>
        <label for="email">ایمیل:</label>

        <input
            type="email"
            id="email"
            name="email"
            required
        >
    </p>

    <p>
        <label for="phone">شماره تماس:</label>

        <input
            type="tel"
            id="phone"
            name="phone"
            placeholder="09121234567"
            required
        >
    </p>

    <p>
        <label for="age">سن:</label>

        <input
            type="number"
            id="age"
            name="age"
            min="12"
            max="99"
        >
    </p>

    <p>جنسیت:</p>

    <input type="radio" id="male" name="gender" value="male" checked>
    <label for="male">مرد</label>
```

در این مثال با استفاده از تگ `form` یک فرم عضویت ساخته‌ایم.

کاربر می‌تواند اطلاعات شخصی خود را وارد کند، نوع عضویت را انتخاب کند، اهداف تمرینی خود را مشخص کند و تصویر پروفایل خود را ارسال کند.

در پایان با کلیک روی دکمه ثبت‌نام، اطلاعات فرم برای پردازش به فایل `join-gym.php` فرستاده می‌شوند.

**توجه:** این مثال فقط ساختار فرم در HTML را نشان می‌دهد. برای دریافت و ذخیره اطلاعات باید فایل پردازش‌کننده را با PHP برنامه‌نویسی کنیم.

## ۸. جمع‌بندی درس

در این درس یاد گرفتیم:

۱. فرم چیست و چه کاربردی در صفحات وب دارد.

۲. چگونه با تگ `form` یک فرم ایجاد کنیم.

۳. کاربرد صفت‌های `action`، `method` و `enctype` چیست.

۴. چگونه با تگ‌های `label` و `input` ورودی ایجاد کنیم.

۵. تفاوت انواع ورودی‌ها مانند `text`، `password`، `email`، `radio` و `checkbox` چیست.

۶. چگونه با `textarea` و `select` اطلاعات متنی و انتخابی دریافت کنیم.

۷. چگونه با دکمه `submit` اطلاعات فرم را ارسال کنیم.

# ۹. پرسش‌های چهارگزینه‌ای

**سؤال ۱.** کدام صفت در تگ `form` نشانی صفحه پردازش‌کننده اطلاعات را مشخص می‌کند؟

الف) `method`

ب) `action`

ج) `enctype`

د) `name`

**سؤال ۲.** برای ارسال فایل از طریق فرم، مقدار درست `enctype` کدام است؟

الف) `text/plain`

ب) `application/x-www-form-urlencoded`

ج) `multipart/form-data`

د) `application/json`

**سؤال ۳.** برای اینکه کاربر در بین چند دکمه رادیویی فقط بتواند یک گزینه را انتخاب کند، چه شرطی لازم است؟

الف) همه `id` یکسان داشته باشند.

ب) همه `name` یکسان داشته باشند.

ج) همه `value` یکسان داشته باشند.

د) همه `type="checkbox"` باشند.

**سؤال ۴.** برای اینکه کاربر بتواند چند گزینه را هم‌زمان انتخاب کند، از کدام ورودی استفاده می‌کنیم؟

الف) `radio`

ب) `checkbox`

ج) `text`

د) `password`

**سؤال ۵.** اگر یک ورودی `name` نداشته باشد، چه اتفاقی می‌افتد؟

الف) مرورگر خطا نشان می‌دهد.

ب) مقدار آن ورودی به سرور ارسال نمی‌شود.

ج) مقدار آن به‌طور خودکار ارسال می‌شود.

د) فرم بسته می‌شود.

**سؤال ۶.** کدام عبارت درباره `readonly` و `disabled` صحیح است؟

الف) هر دو مقدار را ارسال می‌کنند.

ب) هیچ‌کدام مقدار را ارسال نمی‌کنند.

ج) `readonly` مقدار را ارسال می‌کند، اما `disabled` ارسال نمی‌کند.

د) `disabled` مقدار را ارسال می‌کند، اما `readonly` ارسال نمی‌کند.

**سؤال ۷.** کدام ورودی در صفحه دیده نمی‌شود، اما مقدار آن همراه فرم ارسال می‌شود؟

الف) `password`

ب) `hidden`

ج) `readonly`

د) `disabled`

**سؤال ۸.** برای ساخت کادر متن چندخطی از کدام تگ استفاده می‌شود؟

الف) `<input type="text">`

ب) `<textarea>`

ج) `<select>`

د) `<label>`

**سؤال ۹.** برای ساخت فهرست کشویی از کدام تگ‌ها استفاده می‌کنیم؟

الف) `<select>` و `<option>`

ب) `<input>` و `<label>`

ج) `<textarea>` و `<label>`

د) `<button>` و `<option>`

**سؤال ۱۰.** کدام عبارت درباره دکمه‌های داخل فرم صحیح است؟

الف) `<button>` بدون نوشتن `type` فرم را ارسال نمی‌کند.

ب) `<button>` بدون نوشتن `type` به‌طور پیش‌فرض فرم را ارسال می‌کند.

ج) دکمه `reset` اطلاعات را به سرور ارسال می‌کند.

د) دکمه `button` همیشه فرم را ارسال می‌کند.
