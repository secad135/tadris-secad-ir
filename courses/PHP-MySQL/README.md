# مقدمه درس PHP و MySQL

این درس به آموزش ساخت صفحات وب پویا با استفاده از PHP و MySQL اختصاص دارد. در پایان دوره، دانش‌آموز توانایی طراحی برنامه‌های کوچک وب را کسب می‌کند؛ برنامه‌هایی که می‌توانند اطلاعات کاربر را دریافت کنند، در پایگاه داده ذخیره نمایند و آن را نمایش، ویرایش یا حذف کنند.

## PHP

PHP یک زبان برنامه‌نویسی سمت سرور است. کدهای PHP روی سرور اجرا می‌شوند و خروجی آن‌ها به مرورگر کاربر ارسال می‌شود. با این زبان می‌توان فرم ساخت، اطلاعات کاربر را دریافت کرد، شرایط منطقی نوشت، از حلقه‌ها استفاده کرد و به پایگاه داده متصل شد.

## MySQL

MySQL یک سیستم مدیریت پایگاه داده است که اطلاعات را در قالب جدول‌ها ذخیره و مدیریت می‌کند. جدول‌هایی مانند دانش‌آموزان، نمرات یا محصولات نمونه‌هایی از کاربرد آن هستند. با دستورهای SQL می‌توان اطلاعات را ثبت، بازیابی، ویرایش یا حذف کرد.

## ارتباط PHP و MySQL

فرایند کلی کار به این صورت است:

1. کاربر اطلاعات را در فرم وارد می‌کند.
2. اطلاعات به سرور ارسال می‌شود.
3. PHP اطلاعات را دریافت و بررسی می‌کند.
4. PHP به MySQL متصل شده و اطلاعات را ذخیره یا بازیابی می‌کند.
5. نتیجه به مرورگر بازگردانده می‌شود.

## اهداف درس

در این دوره دانش‌آموز می‌آموزد:

- صفحه PHP ساده ایجاد کند.
- از متغیر، شرط، حلقه، آرایه و تابع استفاده کند.
- فرم بسازد و اطلاعات کاربر را دریافت کند.
- به پایگاه داده MySQL متصل شود.
- دستورهای اصلی SQL را اجرا کند.
- اطلاعات را ثبت، نمایش، ویرایش و حذف کند.
- جستجوی ساده انجام دهد.
- نکات پایه امنیتی را رعایت کند.
- یک پروژه کوچک تکمیل و ارائه کند.

## روش اجرای درس

هر هفته یک جلسه به تدریس مبحث جدید و یک جلسه به تمرین و کارگاه اختصاص دارد. آموزش به‌صورت مرحله‌به‌مرحله و با تمرکز بر مهارت‌های کاربردی انجام می‌شود. هر جلسه یک خروجی عملی دارد تا دانش‌آموز نتیجه کار خود را مشاهده کند. تأکید اصلی بر خواندن کد، تغییر دادن آن و اجرای تمرین‌های کوتاه است، نه حفظ کردن مطالب.

## انتظارات

- حضور منظم در کلاس و انجام تمرین‌ها
- پرسیدن سؤال در صورت عدم درک مطلب
- اجرای کدها و تغییر آن‌ها برای درک بهتر
- مطالعه جزوه و تکمیل تمرین‌های کلاسی
- انجام جدی پروژه پایانی

## حداقل مهارت قابل قبول

در پایان درس، دانش‌آموز باید بتواند یک برنامه ساده شامل فرم ثبت اطلاعات، اتصال به پایگاه داده، ذخیره اطلاعات، نمایش لیست، ویرایش و حذف رکورد و رعایت نکات پایه امنیتی را پیاده‌سازی کند.

## ابزارهای مورد استفاده

- XAMPP یا Laragon برای اجرای PHP و MySQL
- ویرایشگر کد مانند VS Code
- مرورگر وب
- phpMyAdmin برای مدیریت پایگاه داده
- mysqli برای اتصال PHP به MySQL

در این درس برای سادگی از mysqli استفاده می‌شود. PDO در جزوه به‌صورت اختیاری معرفی شده است و مطالعه آن برای امتحان الزامی نیست.

## توصیه‌های پایانی

کدها را شخصاً بنویسید، تمرین‌ها را کامل انجام دهید و در صورت بروز اشکال، همان هفته آن را پیگیری کنید. خطا بخشی طبیعی از برنامه‌نویسی است و با تمرین و تکرار برطرف می‌شود. هدف این درس کسب یک مهارت کاربردی است: ساخت برنامه‌های کوچک وب با PHP و MySQL.
