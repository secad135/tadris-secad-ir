# بخش پنجم: پیمایش آرایه‌ها با foreach

> در این درس برای پیمایش آرایه‌ها فقط از حلقهٔ `foreach` استفاده می‌کنیم. این حلقه منبع امتحانی بخش آرایه‌هاست.

## ۵-۱. مفهوم پیمایش

پیمایش به معنای مرور کردن همه عناصر آرایه و انجام یک عملیات روی آن‌هاست. `foreach` ساده‌ترین و مناسب‌ترین حلقه برای این کار است؛ زیرا به‌طور خودکار همه عناصر آرایه را مرور می‌کند و نیازی به شمارش دستی ندارد.

## ۵-۲. حلقه foreach

### حالت اول: فقط مقدارها

```php
<?php
$colors = ["Red", "Green", "Blue"];

foreach ($colors as $color) {
    echo $color . "<br>";
}
?>
```

خروجی:

```
Red
Green
Blue
```

در این ساختار، متغیر `$color` در هر تکرار مقدار یکی از عناصر آرایه را می‌گیرد.

### حالت دوم: کلید و مقدار

```php
<?php
$student = [
    "name"  => "Ali",
    "age"   => 17,
    "field" => "Computer"
];

foreach ($student as $key => $value) {
    echo $key . " : " . $value . "<br>";
}
?>
```

خروجی:

```
name : Ali
age : 17
field : Computer
```

در این ساختار، `$key` کلید و `$value` مقدار هر عنصر را می‌گیرد.

## ۵-۳. پیمایش آرایه دوبعدی با foreach

برای آرایه‌های دوبعدی از دو `foreach` تودرتو استفاده می‌کنیم: حلقهٔ بیرونی سطرها و حلقهٔ داخلی عناصر هر سطر را مرور می‌کند.

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18],
    ["Maryam", 16]
];

foreach ($students as $row) {
    foreach ($row as $value) {
        echo $value . " | ";
    }
    echo "<br>";
}
?>
```

خروجی:

```
Ali | 17 |
Reza | 18 |
Maryam | 16 |
```

اگر آرایهٔ دوبعدی کلید انجمنی داشته باشد، می‌توانیم کلید هر ستون را هم نمایش دهیم:

```php
<?php
$students = [
    ["name" => "Ali", "age" => 17],
    ["name" => "Reza", "age" => 18]
];

foreach ($students as $index => $student) {
    echo "Student " . ($index + 1) . ":<br>";
    foreach ($student as $key => $value) {
        echo $key . " : " . $value . "<br>";
    }
    echo "<hr>";
}
?>
```

## ۵-۴. تغییر مقدار عناصر با foreach

در حالت عادی، `foreach` یک کپی از مقدار هر عنصر را در اختیار برنامه قرار می‌دهد؛ بنابراین تغییر متغیر داخل حلقه، آرایه اصلی را تغییر نمی‌دهد.

```php
<?php
$numbers = [1, 2, 3];

foreach ($numbers as $number) {
    $number = $number * 2;
}

print_r($numbers);
?>
```

خروجی:

```
Array
(
    [0] => 1
    [1] => 2
    [2] => 3
)
```

برای تغییر مقدار عناصر آرایه در حلقه `foreach`، باید از علامت `&` (ارجاع) استفاده کنیم.

```php
<?php
$numbers = [1, 2, 3, 4];

foreach ($numbers as &$number) {
    $number = $number * 2;
}

unset($number);

print_r($numbers);
?>
```

خروجی:

```
Array
(
    [0] => 2
    [1] => 4
    [2] => 6
    [3] => 8
)
```

**نکته مهم:** پس از پایان حلقه، متغیر ارجاعی (`$number` در مثال بالا) هنوز به آخرین عنصر آرایه اشاره می‌کند. برای جلوگیری از خطاهای بعدی، باید با `unset` آن را آزاد کرد.

> **مطالعه تکمیلی:** استفاده از ارجاع در `foreach` نیاز به دقت دارد. اگر متغیر ارجاعی آزاد نشود، ممکن است در ادامه برنامه مقدار آخرین عنصر به‌طور ناخواسته تغییر کند. به همین دلیل همیشه پس از حلقه، `unset` را فراخوانی کنید.

## ۵-۵. شکستن و ادامه حلقه

### استفاده از break

با `break` می‌توان حلقه را پیش از پایان طبیعی متوقف کرد.

```php
<?php
$numbers = [10, 20, 30, 40, 50];

foreach ($numbers as $number) {
    if ($number == 30) {
        break;
    }
    echo $number . "<br>";
}
?>
```

خروجی:

```
10
20
```

### استفاده از continue

با `continue` می‌توان از تکرار جاری صرف‌نظر کرد و به تکرار بعدی رفت.

```php
<?php
$numbers = [10, 20, 30, 40, 50];

foreach ($numbers as $number) {
    if ($number == 30) {
        continue;
    }
    echo $number . "<br>";
}
?>
```

خروجی:

```
10
20
40
50
```

### شکستن حلقه‌های تودرتو

با `break` و یک عدد، می‌توان چند حلقه تودرتو را همزمان شکست.

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18],
    ["Maryam", 16]
];

foreach ($students as $row) {
    foreach ($row as $value) {
        if ($value == 18) {
            break 2;
        }
        echo $value . " ";
    }
}
?>
```

خروجی:

```
Ali 17
```

> **مطالعه تکمیلی:** استفاده از `break` با عدد (مثل `break 2`) کد را کوتاه می‌کند، اما خوانایی را کاهش می‌دهد. در برنامه‌های بزرگ بهتر است منطق برنامه به‌گونه‌ای طراحی شود که نیازی به شکستن چند سطحی نباشد.

## ۵-۶. مثال کامل

```php
<?php
$products = [
    ["name" => "Keyboard", "price" => 450000],
    ["name" => "Mouse", "price" => 250000],
    ["name" => "Monitor", "price" => 3500000]
];

$total = 0;

echo "<h3>Product list:</h3>";

foreach ($products as $index => $product) {
    echo ($index + 1) . ". " . $product["name"] . " - " . $product["price"] . " Toman<br>";
    $total += $product["price"];
}

echo "<hr>";
echo "Total: " . $total . " Toman";
?>
```

## ۵-۷. نکات مهم

1. `foreach` ساده‌ترین و مناسب‌ترین حلقه برای پیمایش آرایه است.
2. برای دسترسی به کلید و مقدار با هم، از `$key => $value` استفاده می‌کنیم.
3. برای تغییر مقدار عناصر در `foreach`، از ارجاع (`&`) استفاده می‌کنیم و پس از حلقه `unset` را فراخوانی می‌کنیم.
4. با `break` می‌توان حلقه را متوقف کرد و با `continue` از یک تکرار صرف‌نظر کرد.
5. برای پیمایش آرایه‌های چندبعدی از `foreach`های تودرتو استفاده می‌کنیم.
6. آرایهٔ خالی هیچ عنصری ندارد و بدنهٔ حلقه حتی یک‌بار هم اجرا نمی‌شود.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

منظور از پیمایش آرایه چیست؟

- الف) تغییر نام فایل
- ب) حذف تمام عناصر
- ج) دسترسی نوبتی به عناصر
- د) تعریف ثابت

### سؤال ۲

کدام حلقه برای پیمایش آرایهٔ انجمنی ساده‌تر است؟

- الف) `foreach`
- ب) `if`
- ج) `switch`
- د) بدون حلقه

### سؤال ۳

در `foreach ($arr as $key => $value)` کدام متغیر کلید را می‌گیرد؟

- الف) هیچ‌کدام
- ب) `$arr`
- ج) `$value`
- د) `$key`

### سؤال ۴

خروجی `foreach ([1, 2, 3] as $n) { echo $n; }` چیست؟

- الف) `1`
- ب) `123`
- ج) `13`
- د) `23`

### سؤال ۵

برای پیمایش تک‌تک خانه‌های آرایهٔ دوبعدی کدام روش مناسب است؟

- الف) یک `define`
- ب) یک `echo` روی نام آرایه
- ج) یک شرط بدون حلقه
- د) دو `foreach` تودرتو

### سؤال ۶

دستور break در یک حلقهٔ ساده چه می‌کند؟

- الف) آرایه را پاک می‌کند
- ب) از حلقه خارج می‌شود
- ج) حلقه را از ابتدا راه می‌اندازد
- د) فقط این دور را رد می‌کند

### سؤال ۷

دستور continue در یک حلقهٔ ساده چه می‌کند؟

- الف) شمارنده را همیشه صفر می‌کند
- ب) آرایه را حذف می‌کند
- ج) کل حلقه را پایان می‌دهد
- د) باقیِ دور جاری را رد می‌کند و به دور بعد می‌رود

### سؤال ۸

خروجی `foreach ([1, 2, 3] as $n) { if ($n == 2) { continue; } echo $n; }` چیست؟

- الف) `1`
- ب) `123`
- ج) `23`
- د) `13`

### سؤال ۹

خروجی `foreach ([1, 2, 3] as $n) { if ($n == 2) { break; } echo $n; }` چیست؟

- الف) `123`
- ب) `1`
- ج) `13`
- د) `23`

### سؤال ۱۰

برای میانگین آرایهٔ غیرخالی از نمرات، پس از محاسبه مجموع چه باید کرد؟

- الف) ضرب مجموع در تعداد
- ب) کم کردن تعداد از مجموع
- ج) تقسیم تعداد بر مجموع
- د) تقسیم مجموع بر تعداد نمرات

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ج | در پیمایش روی اعضای آرایه حرکت می‌کنیم. |
| ۲ | الف | foreach کلید و مقدار را مستقیماً در اختیار می‌گذارد. |
| ۳ | د | در این ساختار، متغیر سمت چپ پیکان کلید را می‌گیرد. |
| ۴ | ب | مقادیر آرایه به‌ترتیب چاپ می‌شوند. |
| ۵ | د | حلقهٔ بیرونی سطرها و حلقهٔ داخلی عناصر سطر را مرور می‌کند. |
| ۶ | ب | break ادامهٔ حلقه را متوقف می‌کند. |
| ۷ | د | continue اجرای همان دور را کوتاه می‌کند. |
| ۸ | د | دور مربوط به ۲ پیش از چاپ رد می‌شود. |
| ۹ | ب | در مقدار ۲ حلقه پیش از چاپ متوقف می‌شود. |
| ۱۰ | د | میانگین برابر مجموع داده‌ها تقسیم بر تعداد آن‌هاست. |
