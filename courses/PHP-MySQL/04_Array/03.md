# بخش سوم: آرایه‌های انجمنی (کلید رشته‌ای)

## ۳-۱. تعریف آرایه انجمنی

در آرایه انجمنی، کلید هر عنصر یک نام یا رشته است، نه یک عدد ترتیبی. به همین دلیل به آن آرایه با کلید رشته‌ای یا آرایه انجمنی می‌گویند.

مثال:

```php
<?php
$student = [
    "name"  => "Ali",
    "age"   => 17,
    "field" => "Computer"
];
?>
```

در این آرایه:

| کلید | مقدار |
|------|--------|
| name | علی |
| age | 17 |
| field | کامپیوتر |

## ۳-۲. کاربرد آرایه انجمنی

آرایه انجمنی وقتی مناسب است که بخواهیم برای هر مقدار، یک نام معنادار داشته باشیم. برای مثال، اطلاعات یک دانش‌آموز شامل نام، سن و رشته است. استفاده از کلیدهای `name`، `age` و `field` خوانایی کد را بسیار بیشتر می‌کند.

## ۳-۳. ساخت آرایه انجمنی

روش ساخت آرایه انجمنی مانند سایر آرایه‌هاست و در بخش اول توضیح داده شد. کافی است هر کلید رشته‌ای را با `=>` به مقدارش نسبت دهیم:

```php
<?php
$book = [
    "title"  => "PHP Programming",
    "author" => "Ahmadi",
    "price"  => 250000
];
?>
```

## ۳-۴. خواندن مقدار یک عنصر

برای خواندن مقدار، کلید رشته‌ای را داخل کروشه می‌نویسیم.

```php
<?php
$student = [
    "name" => "Ali",
    "age"  => 17
];

echo $student["name"]; // Ali
echo $student["age"];  // 17
?>
```

**نکته:** کلید رشته‌ای باید داخل علامت نقل قول نوشته شود. در PHP 8 نوشتن کلید رشته‌ای بدون نقل قول باعث خطا می‌شود.

```php
<?php
echo $student["name"]; // correct
// echo $student[name]; // wrong and causes an error
?>
```

## ۳-۵. تغییر مقدار یک عنصر

با مشخص کردن کلید، مقدار آن تغییر می‌کند.

```php
<?php
$student = [
    "name" => "Ali",
    "age"  => 17
];

$student["age"] = 18;

print_r($student);
?>
```

خروجی:

```
Array
(
    [name] => Ali
    [age] => 18
)
```

## ۳-۶. افزودن عنصر جدید

برای افزودن عنصر جدید، یک کلید جدید انتخاب می‌کنیم و مقدار را به آن نسبت می‌دهیم.

```php
<?php
$student = [
    "name" => "Ali",
    "age"  => 17
];

$student["field"] = "Computer";
$student["grade"] = 19;

print_r($student);
?>
```

خروجی:

```
Array
(
    [name] => Ali
    [age] => 17
    [field] => Computer
    [grade] => 19
)
```

## ۳-۷. حذف عنصر

برای حذف یک عنصر از آرایه انجمنی، از `unset` استفاده می‌کنیم.

```php
<?php
$student = [
    "name"  => "Ali",
    "age"   => 17,
    "field" => "Computer"
];

unset($student["age"]);

print_r($student);
?>
```

خروجی:

```
Array
(
    [name] => Ali
    [field] => Computer
)
```

## ۳-۸. مثال کامل

```php
<?php
$product = [
    "name"  => "Keyboard",
    "model" => "K-200",
    "price" => 450000
];

$product["price"] = 500000;
$product["count"] = 10;
unset($product["model"]);

print_r($product);
?>
```

خروجی:

```
Array
(
    [name] => Keyboard
    [price] => 500000
    [count] => 10
)
```

## ۳-۹. نکات مهم

1. در آرایه انجمنی، کلیدها معمولاً رشته هستند.
2. کلید رشته‌ای باید داخل علامت نقل قول نوشته شود.
3. برای افزودن عنصر جدید، یک کلید جدید تعریف می‌کنیم.
4. برای حذف عنصر از `unset` استفاده می‌کنیم.
5. اگر کلید تکراری تعریف شود، مقدار قبلی بازنویسی می‌شود.

> **مطالعه تکمیلی:** در PHP همه آرایه‌ها در واقع مجموعه‌ای از جفت‌های کلید و مقدار هستند. بنابراین مرز دقیقی بین آرایه اندیس‌دار و انجمنی وجود ندارد. آرایه‌ای که کلیدهای آن رشته باشند، انجمنی نامیده می‌شود. توابع `array_keys` و `array_values` در بخش ششم معرفی شده‌اند.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

ویژگی آرایهٔ انجمنی در مثال‌های این درس چیست؟

- الف) استفاده از کلیدهای معنادار متنی
- ب) نداشتن مقدار
- ج) الزام به کلیدهای صفر تا ۹
- د) ذخیرهٔ فقط عدد صحیح

### سؤال ۲

در `$s = ["name" => "Ali", "age" => 17];` مقدار `$s["name"]` چیست؟

- الف) `0`
- ب) `Ali`
- ج) `17`
- د) `name`

### سؤال ۳

کدام دستور سن آرایهٔ s را ۱۸ می‌کند؟

- الف) `$s = 18;`
- ب) `$s[18] = "age";`
- ج) `$s[] = 18;`
- د) `$s["age"] = 18;`

### سؤال ۴

اگر کلید field وجود نداشته باشد، `$s["field"] = "Computer";` چه می‌کند؟

- الف) عنصر جدید اضافه می‌کند
- ب) کل آرایه را پاک می‌کند
- ج) فقط متن چاپ می‌کند
- د) همهٔ کلیدها را عددی می‌کند

### سؤال ۵

برای حذف فقط کلید age کدام دستور درست است؟

- الف) `unset($s);`
- ب) `$s["age"] = 0;`
- ج) `unset($s["age"]);`
- د) `$s = [];`

### سؤال ۶

کدام گزینه یک آرایهٔ خالی می‌سازد؟

- الف) `$s = [];`
- ب) `$s = "";`
- ج) `$s = 0;`
- د) `$s = array(1, 2);`

### سؤال ۷

برای تغییر مقدار کلید name کدام دستور درست است؟

- الف) `$s["name"] = "Sara";`
- ب) `$s[] = "Sara";`
- ج) `$s = "Sara";`
- د) `$s[0] = "Sara";`

### سؤال ۸

کلید رشته‌ای در دسترسی باید چگونه نوشته شود؟

- الف) بدون نقل قول
- ب) داخل نقل قول
- ج) فقط با عدد
- د) بعد از `=>`

### سؤال ۹

کدام گزینه یک جفت کلید و مقدار در آرایهٔ انجمنی است؟

- الف) `"title"`
- ب) `"PHP"`
- ج) `"title" => "PHP"`
- د) `["title"]`

### سؤال ۱۰

در `$s = ["name" => "Ali", "name" => "Sara"];` مقدار نهایی name چیست؟

- الف) `Ali`
- ب) `AliSara`
- ج) `Sara`
- د) آرایه‌ای شامل هر دو نام

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | الف | کلیدهایی مانند name و age معنای داده را مشخص می‌کنند. |
| ۲ | ب | کلید name به مقدار Ali اشاره دارد. |
| ۳ | د | مقدار کلید age باید تغییر کند. |
| ۴ | الف | انتساب به کلید جدید عنصر تازه می‌سازد. |
| ۵ | ج | unset روی همان عنصر، فقط آن را حذف می‌کند. |
| ۶ | الف | کروشهٔ خالی یک آرایهٔ خالی می‌سازد. |
| ۷ | الف | برای تغییر مقدار، همان کلید را مقدار جدید می‌دهیم. |
| ۸ | ب | کلید رشته‌ای باید داخل نقل قول باشد. |
| ۹ | ج | هر جفت کلید و مقدار با `=>` نوشته می‌شود. |
| ۱۰ | ج | مقدار آخر برای کلید تکراری جای مقدار قبلی را می‌گیرد. |
