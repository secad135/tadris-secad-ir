## تمرین

لیست دانش‌آموزان زیر در یک فایل Excel نگهداری می‌شود. آرایه‌ای در PHP بسازید که اطلاعات هر دانش‌آموز شامل `id`، `name` و `family` را نگه دارد. سپس لیست دانش‌آموزان را به‌صورت یک جدول در خروجی نمایش دهید. همچنین تعداد کل دانش‌آموزان در بالای جدول چاپ شود.

| id | name | family |
|:---|:-----|:-------|
| 1405_304_01 | نعیم | آرخ |
| 1405_304_02 | حسین | آزادی قهرمانلو |
| 1405_304_03 | جواد | احمدی خشتی |
| 1405_304_04 | عبدلله | جان محمدی |
| 1405_304_05 | محمد | جعفری کاهو |
| 1405_304_06 | محمدصدرا | حسن پور ایمانی |
| 1405_304_07 | جواد | رشید کاهویی |
| 1405_304_08 | امیرعلی | روان شاد |
| 1405_304_09 | امیرمحمد | سلیمانی نژاد |
| 1405_304_10 | علیرضا | عبدی |
| 1405_304_11 | حسین | کیان زاده |
| 1405_304_12 | طاها | گلکار |
| 1405_304_13 | امیرعلی | مهرپرور |
| 1405_304_14 | محمدطاها | میری مقدم |
| 1405_304_15 | سامان | نادرپناه |
| 1405_304_16 | معین | ناظمی |

```php
<?php
$students = [
    ["id" => "1405_304_01", "name" => "نعیم", "family" => "آرخ"],
    ["id" => "1405_304_02", "name" => "حسین", "family" => "آزادی قهرمانلو"],
    ["id" => "1405_304_03", "name" => "جواد", "family" => "احمدی خشتی"],
    ["id" => "1405_304_04", "name" => "عبدلله", "family" => "جان محمدی"],
    ["id" => "1405_304_05", "name" => "محمد", "family" => "جعفری کاهو"],
    ["id" => "1405_304_06", "name" => "محمدصدرا", "family" => "حسن پور ایمانی"],
    ["id" => "1405_304_07", "name" => "جواد", "family" => "رشید کاهویی"],
    ["id" => "1405_304_08", "name" => "امیرعلی", "family" => "روان شاد"],
    ["id" => "1405_304_09", "name" => "امیرمحمد", "family" => "سلیمانی نژاد"],
    ["id" => "1405_304_10", "name" => "علیرضا", "family" => "عبدی"],
    ["id" => "1405_304_11", "name" => "حسین", "family" => "کیان زاده"],
    ["id" => "1405_304_12", "name" => "طاها", "family" => "گلکار"],
    ["id" => "1405_304_13", "name" => "امیرعلی", "family" => "مهرپرور"],
    ["id" => "1405_304_14", "name" => "محمدطاها", "family" => "میری مقدم"],
    ["id" => "1405_304_15", "name" => "سامان", "family" => "نادرپناه"],
    ["id" => "1405_304_16", "name" => "معین", "family" => "ناظمی"],
    ["id" => "1405_304_17", "name" => "محمدطاها", "family" => "یزدان پور"]
];

echo "تعداد دانش‌آموزان: " . count($students) . "<br><br>";

echo "<table border='1' cellpadding='8' cellspacing='0'>";
echo "<tr>
        <th>ردیف</th>
        <th>شناسه</th>
        <th>نام</th>
        <th>نام خانوادگی</th>
      </tr>";

$rowNumber = 1;

foreach ($students as $student) {
    echo "<tr>";
    echo "<td>" . $rowNumber . "</td>";
    echo "<td>" . $student["id"] . "</td>";
    echo "<td>" . $student["name"] . "</td>";
    echo "<td>" . $student["family"] . "</td>";
    echo "</tr>";

    $rowNumber++;
}

echo "</table>";
?>
```

## خروجی مورد انتظار

```
تعداد دانش‌آموزان: 17
```

سپس جدولی شامل ستون‌های «ردیف»، «شناسه»، «نام» و «نام خانوادگی» نمایش داده می‌شود که هر سطر آن اطلاعات یکی از دانش‌آموزان است.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

در تمرین جدول دانش‌آموزان، هر دانش‌آموز با چه ساختاری نگهداری می‌شود؟

- الف) آرایهٔ انجمنی با کلیدهای id و name و family
- ب) فایل CSS جداگانه
- ج) فقط یک عدد
- د) فقط یک متغیر بولی

### سؤال ۲

تعداد دانش‌آموزان نمونه چند نفر است؟

- الف) `3`
- ب) `18`
- ج) `17`
- د) `16`

### سؤال ۳

کدام عبارت تعداد دانش‌آموزان را محاسبه می‌کند؟

- الف) `count($student)`
- ب) `count($students)`
- ج) `$students[0]["id"]`
- د) `$rowNumber++`

### سؤال ۴

متغیر rowNumber در ابتدای نمایش جدول چه مقداری دارد؟

- الف) `1`
- ب) `17`
- ج) `0`
- د) `3`

### سؤال ۵

در `foreach ($students as $student)` متغیر student چیست؟

- الف) تعداد همهٔ دانش‌آموزان
- ب) فقط نام خانوادگی
- ج) شمارهٔ ستون
- د) اطلاعات یک دانش‌آموز در تکرار جاری

### سؤال ۶

برای چاپ نام خانوادگی عضو جاری از کدام عبارت استفاده می‌شود؟

- الف) `$student["id"]`
- ب) `$student["name"]`
- ج) `$student["family"]`
- د) `$students["family"]`

### سؤال ۷

کدام تگ HTML یک سطر جدول را مشخص می‌کند؟

- الف) `<tr>`
- ب) `<td>`
- ج) `<br>`
- د) `<th>`

### سؤال ۸

کدام تگ برای سلول عنوان ستون‌ها در نمونه به کار رفته است؟

- الف) `<tr>`
- ب) `<th>`
- ج) `<br>`
- د) `<td>`

### سؤال ۹

چرا شناسه‌ای مانند `1405_304_01` در نمونه داخل کوتیشن قرار گرفته است؟

- الف) برای حذف آندرلاین‌ها
- ب) برای جمع عددی بخش‌های شناسه
- ج) برای نگهداری شناسه به‌صورت رشته با قالب نوشتاری آن
- د) برای تبدیل شناسه به شرط

### سؤال ۱۰

پس از نمایش ۱۷ ردیف و افزایش rowNumber در پایان هر دور، مقدار این متغیر چیست؟

- الف) `16`
- ب) `17`
- ج) `1`
- د) `18`

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | الف | هر رکورد سه ویژگی نام‌گذاری‌شده دارد. |
| ۲ | ج | آرایهٔ نمونه شامل ۱۷ رکورد دانش‌آموز است. |
| ۳ | ب | تعداد اعضای آرایهٔ بیرونی برابر تعداد دانش‌آموزان است. |
| ۴ | الف | شمارهٔ نمایشی ردیف‌ها از یک آغاز شده است. |
| ۵ | د | هر عضو آرایهٔ بیرونی یک رکورد کامل است. |
| ۶ | ج | کلید family نام خانوادگی را نگه می‌دارد. |
| ۷ | الف | tr یک ردیف جدول ایجاد می‌کند. |
| ۸ | ب | th سلول عنوان جدول است. |
| ۹ | ج | شناسهٔ رشته‌ای قالب شامل آندرلاین و صفر را حفظ می‌کند. |
| ۱۰ | د | شمارنده از ۱ شروع می‌شود و ۱۷ بار افزایش می‌یابد. |
