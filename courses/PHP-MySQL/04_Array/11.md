## کد حل

```php
<?php
$students = [
    ["id" => "1405_304_01", "name" => "Naeim", "family" => "Arakh"],
    ["id" => "1405_304_02", "name" => "Hossein", "family" => "Azadi Ghahremanloo"],
    ["id" => "1405_304_03", "name" => "Javad", "family" => "Ahmadi Khashti"],
    ["id" => "1405_304_04", "name" => "Abdullah", "family" => "Jan Mohammadi"],
    ["id" => "1405_304_05", "name" => "Mohammad", "family" => "Jafari Kahoo"],
    ["id" => "1405_304_06", "name" => "Mohammadsadra", "family" => "Hasanpour Imani"],
    ["id" => "1405_304_07", "name" => "Javad", "family" => "Rashid Kahouei"],
    ["id" => "1405_304_08", "name" => "Amirali", "family" => "Ravan Shad"],
    ["id" => "1405_304_09", "name" => "Amirmohammad", "family" => "Soleimani Nejad"],
    ["id" => "1405_304_10", "name" => "Alireza", "family" => "Abdi"],
    ["id" => "1405_304_11", "name" => "Hossein", "family" => "Kian Zadeh"],
    ["id" => "1405_304_12", "name" => "Taha", "family" => "Golkar"],
    ["id" => "1405_304_13", "name" => "Amirali", "family" => "Mehrparvar"],
    ["id" => "1405_304_14", "name" => "MohammadTaha", "family" => "Miri Moghaddam"],
    ["id" => "1405_304_15", "name" => "Saman", "family" => "Naderpanah"],
    ["id" => "1405_304_16", "name" => "Moein", "family" => "Nazemi"],
    ["id" => "1405_304_17", "name" => "MohammadTaha", "family" => "Yazdanpour"]
];

echo "Number of students: " . count($students) . "<br><br>";

echo "<table border='1' cellpadding='8' cellspacing='0'>";
echo "<tr>
        <th>Row</th>
        <th>ID</th>
        <th>Name</th>
        <th>Family</th>
      </tr>";

$rowNumber = 1;

foreach ($students as $student) {
    echo "<tr>";
    echo "<td>" . $rowNumber . "</td>";
    echo "<td>" . $student["id"] . "</td>";
    echo "<td>" . $student["name"] . "</td>";
    echo "<td>" . $student["family"] . "</td>";
    echo "</tr>";

    $rowNumber++;
}

echo "</table>";
?>
```

## خروجی مورد انتظار

```
Number of students: 17
```

سپس جدولی شامل ستون‌های «Row»، «ID»، «Name» و «Family» نمایش داده می‌شود که هر سطر آن اطلاعات یکی از دانش‌آموزان است.
