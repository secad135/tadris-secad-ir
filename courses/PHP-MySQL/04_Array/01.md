# بخش اول: آشنایی با آرایه

## ۱-۱. محدودیت متغیرهای معمولی

فرض کنید می‌خواهیم نام پنج دانش‌آموز را ذخیره کنیم. با متغیرهای معمولی این‌گونه می‌نویسیم:

```php
<?php
$name1 = "Ali";
$name2 = "Reza";
$name3 = "Maryam";
$name4 = "Sara";
$name5 = "Hossein";
?>
```

این روش برای تعداد کم کار می‌کند. اما اگر تعداد دانش‌آموزان ۵۰ نفر باشد، نوشتن ۵۰ متغیر عملی نیست. همچنین پیمایش (مرور) این متغیرها دشوار است.

## ۱-۲. آرایه چیست؟

آرایه مجموعه‌ای از چند مقدار است که **همه با یک نام** نگهداری می‌شوند.

هر مقدار داخل آرایه یک **عنصر** نام دارد. هر عنصر از دو بخش تشکیل می‌شود:

- **کلید** (اندیس): موقعیت یا شناسه عنصر
- **مقدار**: خود داده

مثال:

```php
<?php
$names = ["Ali", "Reza", "Maryam", "Sara", "Hossein"];
?>
```

در این مثال، یک آرایه با نام `$names` داریم که پنج عنصر دارد. کلید عنصر اول `0`، عنصر دوم `1` و به همین ترتیب است.

## ۱-۳. مزایای استفاده از آرایه

1. **مدیریت آسان:** همه داده‌های مرتبط زیر یک نام قرار می‌گیرند.
2. **کد کوتاه‌تر:** نیازی به نوشتن متغیرهای متعدد نیست.
3. **پیمایش ساده:** با یک حلقه می‌توان همه عناصر را مرور کرد.
4. **انتقال آسان:** کل آرایه با یک نام به تابع فرستاده می‌شود.
5. **انعطاف:** تعداد عناصر می‌تواند در طول اجرای برنامه کم یا زیاد شود.

## ۱-۴. ساخت آرایه در PHP

دو روش برای ساخت آرایه وجود دارد:

**روش اول (قدیمی‌تر):**

```php
<?php
$fruits = array("Apple", "Orange", "Grape");
?>
```

**روش دوم (کوتاه‌تر و رایج‌تر):**

```php
<?php
$fruits = ["Apple", "Orange", "Grape"];
?>
```

هر دو روش نتیجه یکسانی دارند. در این جزوه از روش دوم استفاده می‌شود.

برای ساخت آرایهٔ خالی هم می‌توان نوشت:

```php
<?php
$items = [];
?>
```

## ۱-۵. نمایش محتوای آرایه

برای دیدن محتوای آرایه، از `print_r` یا `var_dump` استفاده می‌کنیم:

```php
<?php
$fruits = ["Apple", "Orange", "Grape"];
print_r($fruits);
?>
```

خروجی:

```
Array
(
    [0] => Apple
    [1] => Orange
    [2] => Grape
)
```

همچنین:

```php
<?php
var_dump($fruits);
?>
```

خروجی `var_dump` اطلاعات بیشتری مثل نوع داده و تعداد کاراکترها را نشان می‌دهد.

> **نکته:** دستور `echo` برای نمایش کل آرایه مناسب نیست و PHP هشدار `Array to string conversion` می‌دهد. برای نمایش کل آرایه از `print_r` استفاده کنید.

برای خوانایی بهتر خروجی، آرایه را داخل تگ `pre` نمایش می‌دهیم:

```php
<?php
$fruits = ["Apple", "Orange", "Grape"];

echo "<pre>";
print_r($fruits);
echo "</pre>";
?>
```

> **مطالعه تکمیلی:** تفاوت `print_r` و `var_dump` در این است که `print_r` نمایش خوانا و ساده می‌دهد، اما `var_dump` نوع و طول داده را نیز نمایش می‌دهد. در مرحلهٔ اشکال‌زدایی، `var_dump` دقیق‌تر است.

## ۱-۶. انواع آرایه در PHP

PHP سه نوع اصلی آرایه دارد. در این بخش فقط با شکل کلی آن‌ها آشنا می‌شویم و جزئیات هر نوع در بخش جداگانهٔ خودش توضیح داده می‌شود:

| نوع آرایه | شکل کلید | مثال کوتاه | بخش مربوطه |
|---|---|---|---|
| اندیس‌دار (عددی) | عدد | `[10, 20, 30]` | بخش دوم |
| انجمنی (کلید رشته‌ای) | نام یا رشته | `["name" => "Ali", "age" => 17]` | بخش سوم |
| چندبعدی | ترکیبی | `[["Ali", 17], ["Sara", 18]]` | بخش چهارم |

> **مطالعه تکمیلی:** در PHP می‌توان آرایه‌ای ساخت که هم کلید عددی و هم کلید رشته‌ای داشته باشد. به این نوع، آرایه ترکیبی می‌گویند. این حالت در عمل کمتر استفاده می‌شود و برای دانش‌آموزان الزامی نیست.

## ۱-۷. جمع‌بندی بخش اول

- آرایه مجموعه‌ای از چند مقدار با یک نام است.
- هر عنصر آرایه یک کلید و یک مقدار دارد.
- آرایه‌ها کد را کوتاه‌تر و مدیریت داده‌ها را آسان‌تر می‌کنند.
- در PHP سه نوع آرایه داریم: اندیس‌دار، انجمنی و چندبعدی.
- برای نمایش محتوای آرایه از `print_r` یا `var_dump` استفاده می‌کنیم.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

آرایه برای چه کاری مناسب است؟

- الف) فقط نگهداری یک عدد ثابت
- ب) تغییر پسوند فایل
- ج) نگهداری چند مقدار زیر یک نام
- د) اجرای وب‌سرور

### سؤال ۲

کدام گزینه آرایهٔ سه‌عضوی می‌سازد؟

- الف) `$a = "10, 20, 30";`
- ب) `$a = [10, 20, 30];`
- ج) `$a = 10 + 20 + 30;`
- د) `$a = 10;`

### سؤال ۳

کدام نوشتار معادل `["A", "B"]` است؟

- الف) `"A B"`
- ب) `array("AB")`
- ج) `array("A", "B")`
- د) `"A" . "B"`

### سؤال ۴

برای دیدن ساختار و عناصر آرایه کدام ابزار مناسب است؟

- الف) `print_r()`
- ب) `break`
- ج) `echo "Array"`
- د) `define()`

### سؤال ۵

کدام ابزار علاوه بر مقدارها، نوع داده را هم نشان می‌دهد؟

- الف) `var_dump()`
- ب) `continue`
- ج) `echo "type"`
- د) `case`

### سؤال ۶

کدام گزینه آرایهٔ انجمنی است؟

- الف) `"name: Ali"`
- ب) `["name" => "Ali"]`
- ج) `[10, 20]`
- د) `17`

### سؤال ۷

کدام گزینه آرایهٔ چندبعدی است؟

- الف) `["Ali", "Sara"]`
- ب) `[["Ali", 17], ["Sara", 18]]`
- ج) `[17, 18]`
- د) `"Ali,17"`

### سؤال ۸

در آرایهٔ `[10, 20, 30]` اندیس خودکار نخستین عنصر چیست؟

- الف) `10`
- ب) `3`
- ج) `1`
- د) `0`

### سؤال ۹

برای نگهداری نام صد دانش‌آموز کدام طراحی مناسب‌تر است؟

- الف) یک آرایه از نام‌ها
- ب) تغییر نام یک متغیر در هر خط
- ج) صد دستور echo بدون ذخیره داده
- د) یک ثابت برای همهٔ نام‌ها با یک مقدار

### سؤال ۱۰

در `["age" => 17]` کدام بخش مقدار عنصر است؟

- الف) `age`
- ب) `=>`
- ج) نام نوع آرایه
- د) `17`

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ج | آرایه مجموعه‌ای از عناصر را در یک متغیر نگه می‌دارد. |
| ۲ | ب | کروشه‌ها سه مقدار جداگانه را در آرایه قرار می‌دهند. |
| ۳ | ج | array و کروشه دو روش ساخت آرایه‌اند. |
| ۴ | الف | print_r کلیدها و مقدارهای آرایه را نمایش می‌دهد. |
| ۵ | الف | var_dump اطلاعات نوع و مقدار را ارائه می‌کند. |
| ۶ | ب | این آرایه از کلید متنی name استفاده می‌کند. |
| ۷ | ب | در آرایهٔ چندبعدی، برخی عناصر خودشان آرایه هستند. |
| ۸ | د | اندیس‌های خودکار این آرایه از صفر آغاز می‌شوند. |
| ۹ | الف | آرایه مدیریت مجموعهٔ نام‌ها را آسان می‌کند. |
| ۱۰ | د | سمت راست پیکان مقدار عنصر قرار دارد. |
