# بخش اول: آشنایی با آرایه

## ۱-۱. محدودیت متغیرهای معمولی

فرض کنید می‌خواهیم نام پنج دانش‌آموز را ذخیره کنیم. با متغیرهای معمولی این‌گونه می‌نویسیم:

```php
<?php
$name1 = "علی";
$name2 = "رضا";
$name3 = "مریم";
$name4 = "سارا";
$name5 = "حسین";
?>
```

این روش برای تعداد کم کار می‌کند. اما اگر تعداد دانش‌آموزان ۵۰ نفر باشد، نوشتن ۵۰ متغیر عملی نیست. همچنین پیمایش (مرور) این متغیرها با حلقه دشوار است.

## ۱-۲. آرایه چیست؟

آرایه مجموعه‌ای از چند مقدار است که **همه با یک نام** نگهداری می‌شوند.

هر مقدار داخل آرایه یک **عنصر** نام دارد. هر عنصر از دو بخش تشکیل می‌شود:

- **کلید** (اندیس): موقعیت یا شناسه عنصر
- **مقدار**: خود داده

مثال:

```php
<?php
$names = ["علی", "رضا", "مریم", "سارا", "حسین"];
?>
```

در این مثال، یک آرایه با نام `$names` داریم که پنج عنصر دارد. کلید عنصر اول `0`، عنصر دوم `1` و به همین ترتیب است.

## ۱-۳. مزایای استفاده از آرایه

1. **مدیریت آسان:** همه داده‌های مرتبط زیر یک نام قرار می‌گیرند.
2. **کد کوتاه‌تر:** نیازی به نوشتن متغیرهای متعدد نیست.
3. **پیمایش ساده:** با یک حلقه می‌توان همه عناصر را مرور کرد.
4. **انتقال آسان:** کل آرایه با یک نام به تابع فرستاده می‌شود.
5. **انعطاف:** تعداد عناصر می‌تواند در طول اجرای برنامه کم یا زیاد شود.

## ۱-۴. دو روش ساخت آرایه در PHP

**روش اول (قدیمی‌تر):**

```php
<?php
$fruits = array("سیب", "پرتقال", "انگور");
?>
```

**روش دوم (کوتاه‌تر، رایج‌تر):**

```php
<?php
$fruits = ["سیب", "پرتقال", "انگور"];
?>
```

هر دو روش نتیجه یکسانی دارند. در این جزوه بیشتر از روش دوم استفاده می‌شود.

## ۱-۵. نمایش محتوای آرایه

برای دیدن محتوای آرایه، از `print_r` یا `var_dump` استفاده می‌کنیم:

```php
<?php
$fruits = ["سیب", "پرتقال", "انگور"];
print_r($fruits);
?>
```

خروجی:

```
Array
(
    [0] => سیب
    [1] => پرتقال
    [2] => انگور
)
```

همچنین:

```php
<?php
var_dump($fruits);
?>
```

خروجی `var_dump` اطلاعات بیشتری مثل نوع داده و تعداد کاراکترها را نشان می‌دهد.

> **نکته:** دستور `echo` برای نمایش کل آرایه مناسب نیست و خطا می‌دهد. برای نمایش کل آرایه از `print_r` استفاده کنید.

> **مطالعه تکمیلی:** تفاوت `print_r` و `var_dump` در این است که `print_r` نمایش خوانا و ساده می‌دهد، اما `var_dump` نوع و طول داده را نیز نمایش می‌دهد. در مرحله اشکال‌زدایی، `var_dump` دقیق‌تر است.

## ۱-۶. انواع آرایه در PHP

PHP سه نوع اصلی آرایه دارد:

### الف) آرایه اندیس‌دار (عددی)

کلید عناصر، عدد است و از صفر شروع می‌شود.

```php
<?php
$numbers = [10, 20, 30, 40];
?>
```

### ب) آرایه انجمنی (کلید رشته‌ای)

کلید هر عنصر، یک نام یا رشته است.

```php
<?php
$student = [
    "name"  => "علی",
    "age"   => 17,
    "field" => "کامپیوتر"
];
?>
```

### ج) آرایه چندبعدی

آرایه‌ای که عناصر آن خودشان آرایه هستند.

```php
<?php
$students = [
    ["علی", 17],
    ["رضا", 18],
    ["مریم", 16]
];
?>
```

> **مطالعه تکمیلی:** در PHP می‌توان آرایه‌ای ساخت که هم کلید عددی و هم کلید رشته‌ای داشته باشد. به این نوع، آرایه ترکیبی می‌گویند. مثال:
> ```php
> <?php
> $data = ["نام" => "علی", 0 => "مقدار اول"];
> ?>
> ```
> این حالت در عمل کمتر استفاده می‌شود و برای دانش‌آموزان الزامی نیست.

## ۱-۷. جمع‌بندی بخش اول

- آرایه مجموعه‌ای از چند مقدار با یک نام است.
- هر عنصر آرایه یک کلید و یک مقدار دارد.
- آرایه‌ها کد را کوتاه‌تر و مدیریت داده‌ها را آسان‌تر می‌کنند.
- در PHP سه نوع آرایه داریم: اندیس‌دار، انجمنی و چندبعدی.
- برای نمایش محتوای آرایه از `print_r` یا `var_dump` استفاده می‌کنیم.
