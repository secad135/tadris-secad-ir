# بخش ششم: توابع پرکاربرد آرایه‌ها (بخش اول)

## ۶-۱. مقدمه

در این درس با چند تابع ساده برای کار با آرایه‌ها آشنا می‌شویم؛ مثلاً شمارش مقدارها، جمع عددها و اضافه یا حذف کردن یک مقدار. هر مثال را جداگانه اجرا کنید و نتیجه را ببینید.

در مثال‌ها، `echo` یک مقدار و `print_r` محتویات آرایه را نمایش می‌دهد.

## ۶-۲. تابع count

تعداد عناصر آرایه را برمی‌گرداند.

```php
<?php
$colors = ["Red", "Green", "Blue"];
echo count($colors); // 3
?>
```

## ۶-۳. تابع array_sum

مجموع عناصر عددی آرایه را برمی‌گرداند.

```php
<?php
$numbers = [10, 20, 30, 40];
echo array_sum($numbers); // 100
?>
```

## ۶-۴. تابع array_keys

همه کلیدهای آرایه را به‌صورت یک آرایه جدید برمی‌گرداند.

```php
<?php
$student = [
    "name"  => "Ali",
    "age"   => 17,
    "field" => "Computer"
];

print_r(array_keys($student));
?>
```

خروجی:

```
Array
(
    [0] => name
    [1] => age
    [2] => field
)
```

## ۶-۵. تابع array_values

مقدارهای آرایه را در یک آرایه جدید قرار می‌دهد. شماره‌گذاری آرایه جدید از صفر شروع می‌شود.

```php
<?php
$student = [
    "name"  => "Ali",
    "age"   => 17,
    "field" => "Computer"
];

print_r(array_values($student));
?>
```

خروجی:

```
Array
(
    [0] => Ali
    [1] => 17
    [2] => Computer
)
```

## ۶-۶. تابع array_merge

مقدارهای دو آرایه را کنار هم قرار می‌دهد و یک آرایه جدید می‌سازد.

```php
<?php
$array1 = ["Red", "Green"];
$array2 = ["Blue", "Yellow"];

$result = array_merge($array1, $array2);

print_r($result);
?>
```

خروجی:

```
Array
(
    [0] => Red
    [1] => Green
    [2] => Blue
    [3] => Yellow
)
```

## ۶-۷. تابع array_push

یک مقدار به انتهای آرایه اضافه می‌کند. در این مثال، رنگ آبی به فهرست اضافه می‌شود.

```php
<?php
$colors = ["Red", "Green"];
array_push($colors, "Blue");

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => Red
    [1] => Green
    [2] => Blue
)
```

## ۶-۸. تابع array_pop

آخرین عنصر آرایه را حذف می‌کند و مقدار آن را برمی‌گرداند.

```php
<?php
$colors = ["Red", "Green", "Blue"];
$last = array_pop($colors);

echo $last; // Blue
echo "<br>";
print_r($colors);
?>
```

خروجی:

```
Blue
Array
(
    [0] => Red
    [1] => Green
)
```

## ۶-۹. تابع array_shift

اولین مقدار آرایه را حذف می‌کند و آن را برمی‌گرداند. در این مثال، رنگ قرمز حذف می‌شود و شماره‌گذاری مقدارهای باقی‌مانده از صفر شروع می‌شود.

```php
<?php
$colors = ["Red", "Green", "Blue"];
$first = array_shift($colors);

echo $first;
echo "<br>";
print_r($colors);
?>
```

خروجی:

```
Red
Array
(
    [0] => Green
    [1] => Blue
)
```

## ۶-۱۰. تابع array_unshift

یک مقدار به ابتدای آرایه اضافه می‌کند. در این مثال، رنگ قرمز در ابتدای فهرست قرار می‌گیرد.

```php
<?php
$colors = ["Green", "Blue"];
array_unshift($colors, "Red");

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => Red
    [1] => Green
    [2] => Blue
)
```

## ۶-۱۱. تابع in_array

بررسی می‌کند که یک مقدار در آرایه وجود دارد یا نه.

```php
<?php
$colors = ["Red", "Green", "Blue"];

if (in_array("Green", $colors)) {
    echo "Green is in the array.";
} else {
    echo "Green is not in the array.";
}
?>
```

## ۶-۱۲. تابع array_key_exists

بررسی می‌کند که یک کلید در آرایه وجود دارد یا نه.

```php
<?php
$student = ["name" => "Ali", "age" => 17];

if (array_key_exists("name", $student)) {
    echo "The name key exists.";
}
?>
```

## ۶-۱۳. تابع array_reverse

ترتیب عناصر آرایه را برعکس می‌کند.

```php
<?php
$colors = ["Red", "Green", "Blue"];
print_r(array_reverse($colors));
?>
```

خروجی:

```
Array
(
    [0] => Blue
    [1] => Green
    [2] => Red
)
```

## ۶-۱۴. تابع array_flip

جای کلیدها و مقدارها را در یک آرایه جدید عوض می‌کند. در این مثال، `Red` که مقدار بود، به کلید تبدیل می‌شود و `red` مقدار آن می‌شود.

```php
<?php
$colors = ["red" => "Red", "blue" => "Blue"];
$flipped = array_flip($colors);

print_r($flipped);
?>
```

خروجی:

```
Array
(
    [Red] => red
    [Blue] => blue
)
```

**نکته:** مقدارهای آرایه باید رشته یا عدد صحیح باشند. برای شروع، مانند مثال بالا از مقدارهای غیرتکراری استفاده کنید.

## ۶-۱۵. خلاصه توابع

| تابع | کار |
|------|------|
| `count` | شمارش مقدارهای آرایه |
| `array_sum` | جمع عددهای آرایه |
| `array_keys` | گرفتن کلیدها |
| `array_values` | گرفتن مقدارها |
| `array_merge` | کنار هم گذاشتن مقدارهای دو آرایه |
| `array_push` | اضافه کردن به انتهای آرایه |
| `array_pop` | حذف آخرین مقدار و برگرداندن آن |
| `array_shift` | حذف اولین مقدار و برگرداندن آن |
| `array_unshift` | اضافه کردن به ابتدای آرایه |
| `in_array` | بررسی وجود یک مقدار |
| `array_key_exists` | بررسی وجود یک کلید |
| `array_reverse` | برعکس کردن ترتیب مقدارها |
| `array_flip` | جابه‌جا کردن کلیدها و مقدارها |

## ۶-۱۶. نکات مهم

1. برای شمارش مقدارها از `count` و برای جمع عددها از `array_sum` استفاده کنید.
2. `array_push` و `array_pop` با انتهای آرایه و `array_unshift` و `array_shift` با ابتدای آن کار می‌کنند. هر چهار تابع خود آرایه را تغییر می‌دهند.
3. `in_array` دنبال یک مقدار می‌گردد، اما `array_key_exists` وجود یک کلید را بررسی می‌کند.
4. `array_merge`، `array_reverse` و `array_flip` نتیجه را در یک آرایه جدید برمی‌گردانند. برای استفاده بعدی، نتیجه را در یک متغیر ذخیره کنید.
