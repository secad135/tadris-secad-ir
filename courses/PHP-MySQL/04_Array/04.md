# بخش چهارم: آرایه‌های چندبعدی


## ۴-۱. تعریف آرایه چندبعدی

آرایه‌ای که عناصر آن خودشان آرایه باشند، **آرایه چندبعدی** نامیده می‌شود. ساده‌ترین حالت آن، **آرایه دوبعدی** است؛ یعنی آرایه‌ای که هر عنصر آن یک آرایه است.

مثال:

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18],
    ["Maryam", 16]
];
?>
```

در این آرایه، هر عنصر یک آرایه کوچک‌تر است. آرایه چندبعدی برای نگهداری داده‌های جدولی مناسب است.

---

## ۴-۲. ساختار آرایه دوبعدی

آرایه دوبعدی را می‌توان مانند یک جدول تصور کرد. سطرها با کلید اول و ستون‌ها با کلید دوم مشخص می‌شوند.

```php
<?php
$students = [
    ["Ali", 17, "Computer"],
    ["Reza", 18, "Accounting"],
    ["Maryam", 16, "Computer"]
];
?>
```

در این مثال:

| سطر | ستون 0 | ستون 1 | ستون 2 |
|------|---------|---------|---------|
| 0 | Ali | 17 | Computer |
| 1 | Reza | 18 | Accounting |
| 2 | Maryam | 16 | Computer |

---

## ۴-۳. دسترسی به عناصر آرایه دوبعدی

برای دسترسی به یک عنصر، ابتدا کلید سطر و سپس کلید ستون را می‌نویسیم.

```php
<?php
$students = [
    ["Ali", 17, "Computer"],
    ["Reza", 18, "Accounting"],
    ["Maryam", 16, "Computer"]
];

echo $students[0][0]; // Ali
echo $students[1][1]; // 18
echo $students[2][2]; // Computer
?>
```

---

## ۴-۴. تغییر مقدار یک عنصر

```php
<?php
$students = [
    ["Ali", 17, "Computer"],
    ["Reza", 18, "Accounting"]
];

$students[1][1] = 19;

print_r($students);
?>
```

خروجی:

```
Array
(
    [0] => Array
        (
            [0] => Ali
            [1] => 17
            [2] => Computer
        )

    [1] => Array
        (
            [0] => Reza
            [1] => 19
            [2] => Accounting
        )
)
```

---

## ۴-۵. افزودن سطر جدید

برای افزودن یک سطر جدید، یک آرایه جدید به انتهای آرایه اصلی اضافه می‌کنیم.

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18]
];

$students[] = ["Maryam", 16];

print_r($students);
?>
```

---

## ۴-۶. افزودن ستون جدید به یک سطر

برای افزودن مقدار جدید به یک سطر، از کلید بعدی آن سطر استفاده می‌کنیم.

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18]
];

$students[0][] = "Computer";
$students[1][] = "Accounting";

print_r($students);
?>
```

---

## ۴-۷. حذف یک سطر

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18],
    ["Maryam", 16]
];

unset($students[1]);

print_r($students);
?>
```

**نکته:** پس از حذف، کلیدهای آرایه اصلی به‌طور خودکار مرتب نمی‌شوند.

---

## ۴-۸. حذف یک عنصر از یک سطر

```php
<?php
$students = [
    ["Ali", 17, "Computer"],
    ["Reza", 18, "Accounting"]
];

unset($students[0][2]);

print_r($students);
?>
```

---

## ۴-۹. پیمایش آرایه دوبعدی

برای مرور همه عناصر آرایه دوبعدی، معمولاً از دو حلقه تودرتو استفاده می‌کنیم.

### استفاده از foreach تودرتو

```php
<?php
$students = [
    ["Ali", 17, "Computer"],
    ["Reza", 18, "Accounting"],
    ["Maryam", 16, "Computer"]
];

foreach ($students as $row) {
    foreach ($row as $value) {
        echo $value . " | ";
    }
    echo "<br>";
}
?>
```

خروجی:

```
Ali | 17 | Computer |
Reza | 18 | Accounting |
Maryam | 16 | Computer |
```

### استفاده از foreach با کلید سطر

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18]
];

foreach ($students as $rowIndex => $row) {
    echo "Row " . $rowIndex . ": ";
    foreach ($row as $value) {
        echo $value . " ";
    }
    echo "<br>";
}
?>
```

خروجی:

```
Row 0: Ali 17
Row 1: Reza 18
```

### استفاده از حلقه for

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18]
];

for ($i = 0; $i < count($students); $i++) {
    for ($j = 0; $j < count($students[$i]); $j++) {
        echo $students[$i][$j] . " ";
    }
    echo "<br>";
}
?>
```

## ۴-۱۰. آرایه دوبعدی با کلید انجمنی

می‌توان در آرایه دوبعدی از کلیدهای رشته‌ای نیز استفاده کرد.

```php
<?php
$students = [
    [
        "name"  => "Ali",
        "age"   => 17,
        "field" => "Computer"
    ],
    [
        "name"  => "Reza",
        "age"   => 18,
        "field" => "Accounting"
    ]
];

echo $students[0]["name"]; // Ali
echo $students[1]["field"]; // Accounting
?>
```

پیمایش این آرایه:

```php
<?php
foreach ($students as $student) {
    foreach ($student as $key => $value) {
        echo $key . " : " . $value . " | ";
    }
    echo "<br>";
}
?>
```

> **نکته:** آرایه دوبعدی با کلید انجمنی برای نگهداری رکوردهای پایگاه داده بسیار رایج است. هر سطر یک رکورد و هر کلید یک نام ستون است.

---

## ۴-۱۱. شمارش عناصر در آرایه چندبعدی

تابع `count` به‌طور پیش‌فرض فقط عناصر سطح اول را می‌شمارد.

```php
<?php
$students = [
    ["Ali", 17],
    ["Reza", 18],
    ["Maryam", 16]
];

echo count($students); // 3
?>
```

برای شمارش همه عناصر به‌صورت بازگشتی، از حالت `COUNT_RECURSIVE` استفاده می‌کنیم.

```php
<?php
echo count($students, COUNT_RECURSIVE); // 9
?>
```

در مثال بالا، 3 سطر و هر سطر 2 مقدار دارد؛ بنابراین مجموع عناصر 9 است.

> **نکته:** شمارش بازگشتی شامل خود آرایه‌های داخلی نیز می‌شود. برای درک دقیق ساختار آرایه، می‌توانید از `print_r` استفاده کنید.

---

## ۴-۱۲. مثال کامل

```php
<?php
$products = [
    [
        "name"  => "Keyboard",
        "price" => 450000,
        "count" => 10
    ],
    [
        "name"  => "Mouse",
        "price" => 250000,
        "count" => 20
    ]
];

$products[] = [
    "name"  => "Monitor",
    "price" => 3500000,
    "count" => 5
];

$products[1]["price"] = 270000;

echo "Product list:<br>";

foreach ($products as $index => $product) {
    echo "Product " . ($index + 1) . ":<br>";
    foreach ($product as $key => $value) {
        echo $key . " : " . $value . "<br>";
    }
    echo "<hr>";
}
?>
```

## ۴-۱۳. نکات مهم

1. آرایه چندبعدی، آرایه‌ای است که عناصر آن آرایه هستند.
2. برای دسترسی به عناصر، کلیدها را به ترتیب می‌نویسیم.
3. برای پیمایش آرایه دوبعدی از دو حلقه تودرتو استفاده می‌کنیم.
4. `count` به‌طور پیش‌فرض فقط سطح اول را می‌شمارد.
5. برای شمارش بازگشتی از `COUNT_RECURSIVE` استفاده می‌کنیم.
6. آرایه دوبعدی با کلید انجمنی برای نگهداری رکوردها بسیار مناسب است.
7. استفاده از آرایه‌های چندبعدی عمیق معمولاً توصیه نمی‌شود؛ در چنین مواردی ساختارهای ساده‌تر خواناتر هستند.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

آرایهٔ دوبعدی چگونه ساخته می‌شود؟

- الف) با حذف کلیدها
- ب) با قرار دادن آرایه‌ها درون آرایه
- ج) فقط با دو متغیر عددی
- د) فقط با اتصال دو رشته

### سؤال ۲

در `$a = [["Ali", 17], ["Sara", 18]];` مقدار `$a[1][0]` چیست؟

- الف) `Sara`
- ب) `Ali`
- ج) `18`
- د) `17`

### سؤال ۳

با همان آرایه، مقدار `$a[0][1]` چیست؟

- الف) `Ali`
- ب) `Sara`
- ج) `17`
- د) `18`

### سؤال ۴

کدام دستور سن Sara را در همین آرایه ۱۹ می‌کند؟

- الف) `$a[0][0] = 19;`
- ب) `$a[1][0] = 19;`
- ج) `$a[0][1] = 19;`
- د) `$a[1][1] = 19;`

### سؤال ۵

دستور `$a[] = ["Reza", 16];` چه می‌کند؟

- الف) یک سطر جدید می‌افزاید
- ب) سطر اول را حذف می‌کند
- ج) یک ستون به تمام سطرها می‌افزاید
- د) آرایه را رشته می‌کند

### سؤال ۶

دستور `$a[0][] = "Computer";` چه می‌کند؟

- الف) سن همه را عوض می‌کند
- ب) همهٔ سطرها را حذف می‌کند
- ج) یک عنصر به سطر اول می‌افزاید
- د) یک سطر جدید می‌سازد

### سؤال ۷

برای حذف تمام سطر دوم کدام دستور درست است؟

- الف) `unset($a[0]);`
- ب) `unset($a[1]);`
- ج) `$a[1][1] = 0;`
- د) `unset($a[1][0]);`

### سؤال ۸

برای پیمایش تک‌تک خانه‌های آرایهٔ دوبعدی کدام روش مناسب است؟

- الف) یک define
- ب) یک echo روی نام آرایه
- ج) یک شرط بدون حلقه
- د) دو foreach تودرتو

### سؤال ۹

برای `$a = [[1, 2], [3, 4]];` مقدار `count($a)` چیست؟

- الف) `1`
- ب) `4`
- ج) `6`
- د) `2`

### سؤال ۱۰

در `$students = [["name" => "Ali", "age" => 17]];` دسترسی درست به نام چیست؟

- الف) `$students[0]["age"]`
- ب) `$students[0]["name"]`
- ج) `$students[1]["name"]`
- د) `$students["name"][0]`

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ب | هر سطر می‌تواند یک آرایهٔ داخلی باشد. |
| ۲ | الف | اندیس اول سطر دوم و اندیس دوم عنصر اول آن را انتخاب می‌کند. |
| ۳ | ج | این نشانی به عنصر دوم سطر اول اشاره دارد. |
| ۴ | د | سن Sara در سطر دوم و ستون دوم است. |
| ۵ | الف | عنصر جدید آرایهٔ بیرونی، خودش یک آرایه است. |
| ۶ | ج | کروشهٔ خالی درون سطر صفر عنصر اضافه می‌کند. |
| ۷ | ب | حذف عنصر آرایهٔ بیرونی کل سطر را حذف می‌کند. |
| ۸ | د | حلقهٔ بیرونی سطرها و حلقهٔ داخلی عناصر سطر را پیمایش می‌کند. |
| ۹ | د | count معمولی فقط عناصر سطح اول را می‌شمارد. |
| ۱۰ | ب | ابتدا سطر صفر و سپس کلید name انتخاب می‌شود. |
