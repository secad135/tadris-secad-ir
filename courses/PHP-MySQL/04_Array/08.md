# بخش هشتم: مرتب‌سازی آرایه‌ها

## ۸-۱. مفهوم مرتب‌سازی

مرتب‌سازی به معنای چیدن عناصر آرایه بر اساس یک نظم مشخص است؛ مثلاً از کوچک به بزرگ، از بزرگ به کوچک یا بر اساس حروف الفبا. PHP مجموعه‌ای از توابع آماده برای مرتب‌سازی آرایه‌ها دارد. توابعی که در این درس معرفی می‌شوند، آرایهٔ اصلی را تغییر می‌دهند.

در این بخش، پرکاربردترین توابع مرتب‌سازی معرفی می‌شوند.

## ۸-۲. تابع sort

عناصر آرایه را از کوچک به بزرگ (صعودی) مرتب می‌کند. این تابع کلیدها را حذف می‌کند و کلیدهای عددی جدید از صفر می‌سازد.

```php
<?php
$numbers = [40, 10, 30, 20];
sort($numbers);

print_r($numbers);
?>
```

خروجی:

```
Array
(
    [0] => 10
    [1] => 20
    [2] => 30
    [3] => 40
)
```

### مرتب‌سازی رشته‌ها

```php
<?php
$colors = ["زرد", "آبی", "قرمز"];
sort($colors);
print_r($colors);
?>
```

**نکته:** `sort` برای آرایه‌های انجمنی مناسب نیست، زیرا کلیدها را از بین می‌برد.

## ۸-۳. تابع rsort

عناصر آرایه را از بزرگ به کوچک (نزولی) مرتب می‌کند. مانند `sort`، کلیدها را حذف می‌کند.

```php
<?php
$numbers = [40, 10, 30, 20];
rsort($numbers);

print_r($numbers);
?>
```

خروجی:

```
Array
(
    [0] => 40
    [1] => 30
    [2] => 20
    [3] => 10
)
```

## ۸-۴. تابع asort

آرایه را بر اساس مقدارها به‌صورت صعودی مرتب می‌کند، اما **کلیدها را حفظ می‌کند**. این تابع برای آرایه‌های انجمنی مناسب است.

```php
<?php
$ages = [
    "علی"  => 17,
    "رضا"  => 20,
    "مریم" => 16
];

asort($ages);

print_r($ages);
?>
```

خروجی:

```
Array
(
    [مریم] => 16
    [علی] => 17
    [رضا] => 20
)
```

## ۸-۵. تابع arsort

آرایه را بر اساس مقدارها به‌صورت نزولی مرتب می‌کند و کلیدها را حفظ می‌کند.

```php
<?php
$ages = [
    "علی"  => 17,
    "رضا"  => 20,
    "مریم" => 16
];

arsort($ages);

print_r($ages);
?>
```

خروجی:

```
Array
(
    [رضا] => 20
    [علی] => 17
    [مریم] => 16
)
```

## ۸-۶. تابع ksort

آرایه را بر اساس کلیدها به‌صورت صعودی مرتب می‌کند.

```php
<?php
$student = [
    "name"  => "علی",
    "age"   => 17,
    "field" => "کامپیوتر"
];

ksort($student);

print_r($student);
?>
```

خروجی:

```
Array
(
    [age] => 17
    [field] => کامپیوتر
    [name] => علی
)
```

## ۸-۷. تابع krsort

آرایه را بر اساس کلیدها به‌صورت نزولی مرتب می‌کند.

```php
<?php
$student = [
    "name"  => "علی",
    "age"   => 17,
    "field" => "کامپیوتر"
];

krsort($student);

print_r($student);
?>
```

خروجی:

```
Array
(
    [name] => علی
    [field] => کامپیوتر
    [age] => 17
)
```

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

نتیجهٔ مقادیر `[40, 10, 30, 20]` پس از sort چیست؟

- الف) ۴۰، ۳۰، ۲۰، ۱۰
- ب) ۱۰، ۲۰، ۳۰، ۴۰
- ج) ۴۰، ۱۰، ۳۰، ۲۰
- د) ۲۰، ۳۰، ۱۰، ۴۰

### سؤال ۲

کدام تابع مقدارها را نزولی و با بازشماری کلیدها مرتب می‌کند؟

- الف) `sort()`
- ب) `asort()`
- ج) `ksort()`
- د) `rsort()`

### سؤال ۳

کدام تابع مرتب‌سازی صعودی بر اساس مقدار با حفظ کلیدها را انجام می‌دهد؟

- الف) `asort()`
- ب) `krsort()`
- ج) `rsort()`
- د) `sort()`

### سؤال ۴

کدام تابع مرتب‌سازی نزولی بر اساس مقدار با حفظ کلیدها را انجام می‌دهد؟

- الف) `sort()`
- ب) `asort()`
- ج) `ksort()`
- د) `arsort()`

### سؤال ۵

کدام تابع آرایه را بر اساس کلیدها به‌صورت صعودی مرتب می‌کند؟

- الف) `sort()`
- ب) `arsort()`
- ج) `ksort()`
- د) `rsort()`

### سؤال ۶

کدام تابع مرتب‌سازی نزولی کلیدها را انجام می‌دهد؟

- الف) `asort()`
- ب) `ksort()`
- ج) `sort()`
- د) `krsort()`

### سؤال ۷

پس از `$a = [5 => 20, 9 => 10]; sort($a);` آرایه چیست؟

- الف) `[0 => 10, 1 => 20]`
- ب) `[9 => 10, 5 => 20]`
- ج) `[0 => 20, 1 => 10]`
- د) `[5 => 20, 9 => 10]`

### سؤال ۸

پس از `$a = ["b" => 20, "a" => 10]; asort($a);` نخستین کلید چیست؟

- الف) `20`
- ب) `b`
- ج) `a`
- د) `0`

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ب | sort مقدارها را صعودی مرتب می‌کند. |
| ۲ | د | rsort برای مرتب‌سازی نزولی مقدارهاست. |
| ۳ | الف | asort ارتباط هر کلید با مقدارش را حفظ می‌کند. |
| ۴ | د | arsort مقدارها را نزولی مرتب و کلیدها را حفظ می‌کند. |
| ۵ | ج | حرف k در این تابع به مرتب‌سازی کلیدها مربوط است. |
| ۶ | د | krsort ترتیب کلیدها را نزولی می‌کند. |
| ۷ | الف | sort کلیدها را بازشماری می‌کند و مقدارها را صعودی می‌چیند. |
| ۸ | ج | مقدار ۱۰ کوچک‌تر است و کلید a حفظ می‌شود. |
