# بخش دوم: آرایه‌های اندیس‌دار (عددی)

## ۲-۱. تعریف آرایه اندیس‌دار

در آرایه اندیس‌دار، کلید هر عنصر یک عدد است. شماره‌گذاری به‌طور پیش‌فرض از صفر شروع می‌شود.

```php
<?php
$colors = ["red", "green", "blue"];
?>
```

در این آرایه:

| کلید | مقدار |
|------|--------|
| 0 | red |
| 1 | green |
| 2 | blue |

> **نکته:** روش ساخت آرایه با `[]` یا `array()` در بخش اول توضیح داده شد. در این بخش فقط با عملیات مخصوص آرایهٔ اندیس‌دار کار می‌کنیم.

## ۲-۲. خواندن مقدار یک عنصر

برای خواندن مقدار یک عنصر، کلید آن را داخل کروشه می‌نویسیم.

```php
<?php
$colors = ["red", "green", "blue"];

echo $colors[0]; // red
echo $colors[1]; // green
echo $colors[2]; // blue
?>
```

اگر کلیدی وجود نداشته باشد، PHP هشدار می‌دهد و مقدار خالی برمی‌گرداند.

```php
<?php
$colors = ["red", "green", "blue"];
echo $colors[5]; // Warning: key 5 does not exist
?>
```

## ۲-۳. تغییر مقدار یک عنصر

با مشخص کردن کلید، مقدار عنصر تغییر می‌کند.

```php
<?php
$colors = ["red", "green", "blue"];
$colors[1] = "yellow";

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => red
    [1] => yellow
    [2] => blue
)
```

## ۲-۴. افزودن عنصر جدید

### افزودن عنصر به انتهای آرایه

اگر داخل کروشه کلیدی ننویسیم، PHP عنصر را به انتهای آرایه اضافه می‌کند و کلید بعدی را خودش انتخاب می‌کند.

```php
<?php
$colors = ["red", "green", "blue"];
$colors[] = "yellow";
$colors[] = "black";

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => red
    [1] => green
    [2] => blue
    [3] => yellow
    [4] => black
)
```

### افزودن عنصر با کلید مشخص

```php
<?php
$colors = ["red", "green", "blue"];
$colors[10] = "pink";

print_r($colors);
?>
```

در این حالت عنصر با کلید 10 اضافه می‌شود. کلیدهای 3 تا 9 خالی می‌مانند.

> **مطالعه تکمیلی:** آرایه‌ای که بعضی کلیدهای آن خالی باشد، آرایه تُنُک نامیده می‌شود. این حالت مجاز است، اما در بیشتر برنامه‌ها از آن استفاده نمی‌شود. برای مرتب‌سازی مجدد کلیدها می‌توان از تابع `array_values` استفاده کرد. توضیح کامل این تابع در بخش ششم آمده است.

## ۲-۵. حذف عنصر

برای حذف یک عنصر از آرایه، از `unset` استفاده می‌کنیم.

```php
<?php
$colors = ["red", "green", "blue"];
unset($colors[1]);

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => red
    [2] => blue
)
```

**نکته مهم:** بعد از حذف، کلیدهای آرایه به‌طور خودکار مرتب نمی‌شوند. در مثال بالا، کلید 1 حذف شده و کلیدهای 0 و 2 باقی مانده‌اند.

### حذف کل آرایه

```php
<?php
$colors = ["red", "green", "blue"];
unset($colors);
?>
```

> **نکته:** برای مرتب کردن مجدد کلیدها پس از حذف، از `array_values` استفاده کنید (همان‌طور که در بخش قبل گفته شد).

## ۲-۶. مثال کامل

```php
<?php
$scores = [18, 15, 20, 12];

$scores[] = 17;
$scores[1] = 16;
unset($scores[3]);

print_r($scores);
?>
```

خروجی:

```
Array
(
    [0] => 18
    [1] => 16
    [2] => 20
    [4] => 17
)
```

## ۲-۷. نکات مهم

1. کلید آرایه اندیس‌دار معمولاً عدد صحیح است.
2. شماره‌گذاری پیش‌فرض از صفر شروع می‌شود.
3. با `$array[] = value` عنصر به انتهای آرایه اضافه می‌شود.
4. با `unset` عنصر حذف می‌شود، اما کلیدها دوباره مرتب نمی‌شوند.
5. برای شمارش عناصر و بررسی وجود کلید، بخش ششم را ببینید.
6. برای پیمایش آرایه، بخش پنجم را ببینید.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

در `$a = [10, 20, 30];` مقدار `$a[1]` چیست؟

- الف) `1`
- ب) `20`
- ج) `30`
- د) `10`

### سؤال ۲

با همان آرایه، کدام دستور عنصر اول را ۹۹ می‌کند؟

- الف) `$a = 99;`
- ب) `$a[0] = 99;`
- ج) `$a[1] = 99;`
- د) `$a[] = 99;`

### سؤال ۳

دستور `$a[] = 40;` روی `[10, 20, 30]` چه می‌کند؟

- الف) همه عناصر را ۴۰ می‌کند
- ب) ۴۰ را با کلید ۳ اضافه می‌کند
- ج) آرایه را مرتب می‌کند
- د) عنصر اول را حذف می‌کند

### سؤال ۴

پس از `$a = [10, 20, 30]; unset($a[1]);` کدام کلیدها باقی می‌مانند؟

- الف) ۰ و ۲
- ب) ۱ و ۲
- ج) ۰ و ۱
- د) فقط ۱

### سؤال ۵

پس از `$a = [10, 20, 30]; unset($a[1]);` مقدار `$a[2]` چیست؟

- الف) `20`
- ب) `30`
- ج) `null`
- د) هشدار

### سؤال ۶

برای افزودن عنصر با کلید ۱۰ کدام دستور درست است؟

- الف) `$a[] = "X";`
- ب) `$a[10] = "X";`
- ج) `$a = "X";`
- د) `$a[0] = 10;`

### سؤال ۷

در `$a = [5 => "A", 8 => "B"];` مقدار `$a[8]` چیست؟

- الف) `8`
- ب) `5`
- ج) `B`
- د) `A`

### سؤال ۸

دسترسی به کلیدی که در آرایه وجود ندارد چه نتیجه‌ای دارد؟

- الف) برنامه همیشه متوقف می‌شود
- ب) هشدار می‌دهد و مقدار خالی برمی‌گرداند
- ج) مقدار صفر برمی‌گرداند
- د) کلید را خودکار می‌سازد

### سؤال ۹

کدام دستور متغیر آرایه را کاملاً حذف می‌کند؟

- الف) `unset($a[0]);`
- ب) `$a = [];`
- ج) `unset($a);`
- د) `$a[] = null;`

### سؤال ۱۰

پس از `$a = [10, 20]; $a[1] = 50;` کدام کلیدها وجود دارند؟

- الف) فقط ۰
- ب) ۰ و ۱
- ج) ۱ و ۲
- د) ۰، ۱ و ۲

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ب | عنصر دوم این آرایه اندیس ۱ دارد. |
| ۲ | ب | عنصر اول با اندیس صفر قابل دسترسی است. |
| ۳ | ب | کروشهٔ خالی یک عنصر با کلید عددی بعدی اضافه می‌کند. |
| ۴ | الف | unset کلیدهای باقی‌مانده را بازشماری نمی‌کند. |
| ۵ | ب | کلید ۲ حذف نشده و مقدارش ۳۰ است. |
| ۶ | ب | با نوشتن کلید مشخص، عنصر با همان کلید ذخیره می‌شود. |
| ۷ | ج | دسترسی بر اساس کلید مشخص‌شده انجام می‌شود. |
| ۸ | ب | PHP برای کلید ناموجود هشدار می‌دهد. |
| ۹ | ج | unset روی خود متغیر، کل آرایه را حذف می‌کند. |
| ۱۰ | ب | تغییر مقدار کلید موجود، عنصر تازه‌ای اضافه نمی‌کند. |
