# بخش دوم: آرایه‌های اندیس‌دار (عددی)

## ۲-۱. تعریف آرایه اندیس‌دار

در آرایه اندیس‌دار، کلید هر عنصر یک عدد است. شماره‌گذاری به‌طور پیش‌فرض از صفر شروع می‌شود.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
?>
```

در این آرایه:

| کلید | مقدار |
|------|--------|
| 0 | قرمز |
| 1 | سبز |
| 2 | آبی |

## ۲-۲. ساخت آرایه اندیس‌دار

### روش اول: استفاده از کروشه

```php
<?php
$numbers = [10, 20, 30, 40];
?>
```

### روش دوم: استفاده از array

```php
<?php
$numbers = array(10, 20, 30, 40);
?>
```

هر دو روش یک آرایه با کلیدهای 0، 1، 2 و 3 می‌سازند.

### ساخت آرایه خالی

```php
<?php
$items = [];
?>
```

یا:

```php
<?php
$items = array();
?>
```

## ۲-۳. خواندن مقدار یک عنصر

برای خواندن مقدار یک عنصر، کلید آن را داخل کروشه می‌نویسیم.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];

echo $colors[0]; // قرمز
echo $colors[1]; // سبز
echo $colors[2]; // آبی
?>
```

اگر کلیدی وجود نداشته باشد، PHP هشدار می‌دهد و مقدار خالی برمی‌گرداند.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
echo $colors[5]; // هشدار: کلید 5 وجود ندارد
?>
```

## ۲-۴. تغییر مقدار یک عنصر

با مشخص کردن کلید، مقدار عنصر تغییر می‌کند.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
$colors[1] = "زرد";

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => قرمز
    [1] => زرد
    [2] => آبی
)
```

## ۲-۵. افزودن عنصر جدید

### افزودن عنصر به انتهای آرایه

اگر داخل کروشه کلیدی ننویسیم، PHP عنصر را به انتهای آرایه اضافه می‌کند و کلید بعدی را خودش انتخاب می‌کند.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
$colors[] = "زرد";
$colors[] = "مشکی";

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => قرمز
    [1] => سبز
    [2] => آبی
    [3] => زرد
    [4] => مشکی
)
```

### افزودن عنصر با کلید مشخص

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
$colors[10] = "صورتی";

print_r($colors);
?>
```

در این حالت عنصر با کلید 10 اضافه می‌شود. کلیدهای 3 تا 9 خالی می‌مانند.

> **مطالعه تکمیلی:** آرایه‌ای که بعضی کلیدهای آن خالی باشد، آرایه تُنُک نامیده می‌شود. این حالت مجاز است، اما در بیشتر برنامه‌ها از آن استفاده نمی‌شود. برای مرتب‌سازی مجدد کلیدها می‌توان از تابع `array_values` استفاده کرد.

## ۲-۶. حذف عنصر

برای حذف یک عنصر از آرایه، از `unset` استفاده می‌کنیم.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
unset($colors[1]);

print_r($colors);
?>
```

خروجی:

```
Array
(
    [0] => قرمز
    [2] => آبی
)
```

**نکته مهم:** بعد از حذف، کلیدهای آرایه به‌طور خودکار مرتب نمی‌شوند. در مثال بالا، کلید 1 حذف شده و کلیدهای 0 و 2 باقی مانده‌اند.

### حذف کل آرایه

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
unset($colors);
?>
```

> **مطالعه تکمیلی:** برای مرتب کردن مجدد کلیدها پس از حذف، می‌توان از `array_values` استفاده کرد:
> ```php
> <?php
> $colors = ["قرمز", "سبز", "آبی"];
> unset($colors[1]);
> $colors = array_values($colors);
> print_r($colors);
> ?>
> ```
> خروجی کلیدها دوباره از صفر شروع می‌شود.

## ۲-۷. تعداد عناصر آرایه

برای شمارش تعداد عناصر آرایه از `count` استفاده می‌کنیم.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];
echo count($colors); // 3
?>
```

## ۲-۸. بررسی وجود یک کلید

### استفاده از isset

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];

if (isset($colors[1])) {
    echo "کلید 1 وجود دارد.";
} else {
    echo "کلید 1 وجود ندارد.";
}
?>
```

`isset` بررسی می‌کند که کلید وجود داشته باشد و مقدار آن `null` نباشد.

### استفاده از array_key_exists

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];

if (array_key_exists(1, $colors)) {
    echo "کلید 1 وجود دارد.";
}
?>
```

> **مطالعه تکمیلی:** تفاوت `isset` و `array_key_exists` در این است که اگر مقدار عنصر `null` باشد، `isset` مقدار `false` برمی‌گرداند، اما `array_key_exists` مقدار `true` برمی‌گرداند؛ زیرا فقط وجود کلید را بررسی می‌کند.

## ۲-۹. پیمایش ساده آرایه اندیس‌دار

برای مرور همه عناصر آرایه اندیس‌دار می‌توان از حلقه `for` استفاده کرد.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];

for ($i = 0; $i < count($colors); $i++) {
    echo $colors[$i] . "<br>";
}
?>
```

خروجی:

```
قرمز
سبز
آبی
```

همچنین می‌توان از `foreach` استفاده کرد.

```php
<?php
$colors = ["قرمز", "سبز", "آبی"];

foreach ($colors as $color) {
    echo $color . "<br>";
}
?>
```

> **مطالعه تکمیلی:** اگر کلیدهای آرایه پیوسته و از صفر تا `count - 1` نباشند، استفاده از حلقه `for` ممکن است به عناصر خالی برخورد کند. در چنین شرایطی `foreach` مناسب‌تر است.

## ۲-۱۰. مثال کامل

```php
<?php
$scores = [18, 15, 20, 12];

echo "تعداد نمرات: " . count($scores) . "<br>";

$scores[] = 17;
$scores[1] = 16;

unset($scores[3]);

echo "نمرات پس از تغییر:<br>";

foreach ($scores as $key => $value) {
    echo "کلید " . $key . " : " . $value . "<br>";
}
?>
```

خروجی:

```
تعداد نمرات: 4
نمرات پس از تغییر:
کلید 0 : 18
کلید 1 : 16
کلید 2 : 20
کلید 4 : 17
```

## ۲-۱۱. نکات مهم

1. کلید آرایه اندیس‌دار معمولاً عدد صحیح است.
2. شماره‌گذاری پیش‌فرض از صفر شروع می‌شود.
3. با `$array[] = value` عنصر به انتهای آرایه اضافه می‌شود.
4. با `unset` عنصر حذف می‌شود، اما کلیدها دوباره مرتب نمی‌شوند.
5. برای شمارش عناصر از `count` استفاده می‌کنیم.
6. برای بررسی وجود کلید از `isset` یا `array_key_exists` استفاده می‌کنیم.
7. برای پیمایش آرایه، `foreach` ساده‌ترین و مطمئن‌ترین روش است.

## نمونه سؤال‌های چهارگزینه‌ای

برای هر سؤال فقط یک گزینهٔ درست انتخاب کنید. پاسخ‌نامه در پایان این بخش آمده است.

### سؤال ۱

در `$a = [10, 20, 30];` مقدار `$a[1]` چیست؟

- الف) `1`
- ب) `20`
- ج) `30`
- د) `10`

### سؤال ۲

با همان آرایه، کدام دستور عنصر اول را ۹۹ می‌کند؟

- الف) `$a = 99;`
- ب) `$a[0] = 99;`
- ج) `$a[1] = 99;`
- د) `$a[] = 99;`

### سؤال ۳

دستور `$a[] = 40;` روی `[10, 20, 30]` چه می‌کند؟

- الف) همه عناصر را ۴۰ می‌کند
- ب) ۴۰ را با کلید ۳ اضافه می‌کند
- ج) آرایه را مرتب می‌کند
- د) عنصر اول را حذف می‌کند

### سؤال ۴

پس از `$a = [10, 20, 30]; unset($a[1]);` کدام کلیدها باقی می‌مانند؟

- الف) ۰ و ۲
- ب) ۱ و ۲
- ج) ۰ و ۱
- د) فقط ۱

### سؤال ۵

پس از حذف یک عنصر از آرایهٔ سه‌عضوی، `count($a)` چند است؟

- الف) `0`
- ب) `3`
- ج) `1`
- د) `2`

### سؤال ۶

برای پیوسته کردن دوبارهٔ اندیس‌ها پس از حذف، کدام تابع مناسب است؟

- الف) `array_values()`
- ب) `array_keys()`
- ج) `array_sum()`
- د) `in_array()`

### سؤال ۷

در `$a = [5 => "A", 8 => "B"];` مقدار `$a[8]` چیست؟

- الف) `8`
- ب) `5`
- ج) `B`
- د) `A`

### سؤال ۸

در `$a = ["A", "B"];` نتیجهٔ `isset($a[1])` چیست؟

- الف) `false`
- ب) `null`
- ج) `true`
- د) `2`

### سؤال ۹

برای پیمایش آرایهٔ بدون شکاف با n عضو، شرط درست for با شروع i=0 چیست؟

- الف) `$i < $n`
- ب) `$i > $n`
- ج) `$i <= $n`
- د) `$i == $n`

### سؤال ۱۰

پس از `$a = [10, 20]; $a[1] = 50;` تعداد عناصر چند است؟

- الف) `3`
- ب) `50`
- ج) `1`
- د) `2`

### پاسخ‌نامهٔ سؤال‌های چهارگزینه‌ای

| سؤال | گزینهٔ درست | توضیح کوتاه |
| --- | --- | --- |
| ۱ | ب | عنصر دوم این آرایه اندیس ۱ دارد. |
| ۲ | ب | عنصر اول با اندیس صفر قابل دسترسی است. |
| ۳ | ب | کروشهٔ خالی یک عنصر با کلید عددی بعدی اضافه می‌کند. |
| ۴ | الف | unset کلیدهای باقی‌مانده را بازشماری نمی‌کند. |
| ۵ | د | count تعداد عناصر موجود را می‌شمارد. |
| ۶ | الف | array_values مقدارها را با کلیدهای عددی تازه برمی‌گرداند. |
| ۷ | ج | دسترسی بر اساس کلید مشخص‌شده انجام می‌شود. |
| ۸ | ج | این کلید وجود دارد و مقدارش null نیست. |
| ۹ | الف | آخرین اندیس چنین آرایه‌ای n منهای یک است. |
| ۱۰ | د | تغییر مقدار کلید موجود عنصر تازه‌ای اضافه نمی‌کند. |
