# ۴. تنظیمات نوشته و انتشار

[فهرست دوره](../README.md) · [درس قبل](03-new-post.md) · [درس بعد](05-taxonomies.md)

هدف: تشخیص تنظیمات کل نوشته از تنظیمات یک بلوک و انتخاب درست زمان و شیوهٔ انتشار.

## پنل نوشته

پنل تنظیمات ویرایشگر را باز کنید و زبانهٔ «نوشته / Post» را انتخاب کنید. زبانهٔ «بلوک / Block» فقط عنصر انتخاب‌شده را تنظیم می‌کند. محل دقیق گزینه‌ها با نسخه و پوسته تغییر می‌کند.

| گزینه | معنی و کاربرد |
| --- | --- |
| نامک / Slug | بخش خوانای نشانی نوشته؛ کوتاه و مرتبط انتخاب کنید |
| تصویر شاخص / Featured Image | تصویر معرفی نوشته؛ محل نمایش آن را پوسته تعیین می‌کند |
| چکیده / Excerpt | معرفی کوتاه مقاله برای بخش‌هایی که از چکیده استفاده می‌کنند |
| دسته و برچسب | تعیین موضوع و ارتباط نوشته با مطالب دیگر |
| گفت‌وگو / Discussion | کنترل پذیرش دیدگاه برای همین نوشته |
| نویسنده / Author | تعیین نویسنده، در صورت داشتن دسترسی |
| قالب / Template | تعیین قالب نمایش، اگر سایت این امکان را ارائه کند |
| بازبینی‌ها / Revisions | بررسی نسخه‌های ذخیره‌شدهٔ قبلی، در صورت موجود بودن |

تصویر شاخص را با تصویر داخل بدنه اشتباه نگیرید. برای مثال، تصویر جلد دوره می‌تواند شاخص باشد و نمودار برنامهٔ مطالعه داخل مقاله قرار بگیرد. چکیده نیز لزوماً در همهٔ پوسته‌ها نمایش داده نمی‌شود.

## وضعیت و قابلیت مشاهده

نوشتهٔ عمومی برای بازدیدکنندگان قابل مشاهده است. نوشتهٔ خصوصی برای کاربران دارای مجوز مناسب قابل دسترسی است. نوشتهٔ رمزدار برای دیدن محتوای محافظت‌شده رمز می‌خواهد؛ این گزینه به‌تنهایی فایل‌های بارگذاری‌شده و نشانی مستقیم آن‌ها را خصوصی نمی‌کند.

اگر نقش شما اجازهٔ انتشار نداشته باشد، ممکن است گزینهٔ ارسال برای بررسی ببینید. این رفتار با خرابی ویرایشگر تفاوت دارد.

## زمان‌بندی و به‌روزرسانی

تاریخ آینده را در بخش انتشار انتخاب کنید و عمل زمان‌بندی را تأیید کنید. منطقهٔ زمانی سایت را در تنظیمات عمومی بررسی کنید. اجرای انتشار زمان‌بندی‌شده ممکن است به سازوکار زمان‌بندی میزبان و مراجعه به سایت وابسته باشد؛ نتیجه را در موعد مقرر بررسی کنید.

برای اصلاح مقالهٔ منتشرشده، همان نوشته را ویرایش و ذخیره/به‌روزرسانی کنید. نسخهٔ تکراری نسازید. تغییر نامک مقالهٔ منتشرشده می‌تواند پیوندهای قبلی را تحت تأثیر قرار دهد؛ در تمرین، نامک را پیش از انتشار نهایی کنید.

## تمرین و بررسی

برای مقالهٔ دوره، یک چکیدهٔ دو جمله‌ای، تصویر شاخص و نامک مرتبط تعیین کنید. پیش‌نمایش مقاله و فهرست وبلاگ را جداگانه ببینید و ثبت کنید تصویر شاخص و چکیده کجا نمایش داده می‌شوند. انتشار را فقط پس از بررسی عنوان، پیوندها، دسته و زمان انجام دهید.
