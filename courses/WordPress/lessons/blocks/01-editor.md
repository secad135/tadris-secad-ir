# ۶. کار با ویرایشگر بلوکی

[فهرست دوره](../../README.md) · [درس قبل](../05-taxonomies.md) · [درس بعد](02-text.md)

هدف: افزودن، انتخاب، جابه‌جایی و تنظیم بلوک‌ها.

## بلوک چیست؟

هر بخش محتوا یک بلوک است: پاراگراف، تیتر، تصویر یا جدول. بعضی بلوک‌ها ظرف بلوک‌های دیگرند؛ برای مثال ستون‌ها شامل ستون و هر ستون شامل متن یا تصویر است.

با `+` نام بلوک را جست‌وجو کنید. در یک پاراگراف خالی می‌توانید `/` و نام بلوک را بنویسید. اگر نام فارسی پیدا نشد، نام انگلیسی را امتحان کنید.

## انتخاب و تنظیم

نوار ابزار کنار بلوک، کارهای سریع را ارائه می‌کند و زبانهٔ بلوک در پنل کناری تنظیمات بیشتری دارد. رنگ، تایپوگرافی، اندازه و فاصله در همهٔ بلوک‌ها یکسان نیستند و ممکن است پوسته برخی کنترل‌ها را ارائه نکند.

از «نمای فهرست / List View» برای دیدن ساختار تو‌در‌تو استفاده کنید. اگر می‌خواهید رنگ کل گروه را تغییر دهید، والد گروه را انتخاب کنید؛ انتخاب پاراگراف فقط همان متن را هدف می‌گیرد.

منوی بلوک می‌تواند گزینه‌هایی مانند تکثیر، جابه‌جایی، درج قبل و بعد، تبدیل نوع و حذف داشته باشد. هنگام حذف ظرفی مانند گروه، محتوای داخل آن را نیز بررسی کنید. برای بازگرداندن اشتباه از واگرد استفاده کنید.

## الگو و قفل

الگو / Pattern ترکیبی آماده از بلوک‌هاست. الگوی همگام‌شده می‌تواند تغییرات را در محل‌های استفادهٔ آن منعکس کند؛ پیش از ویرایش، نوع الگو را تشخیص دهید. قفل بلوک ممکن است جابه‌جایی یا حذف را محدود کند و به معنی خصوصی بودن محتوا نیست.

## تنظیمات پیشرفته

اگر «لنگر HTML» موجود است، شناسه‌ای یکتا مانند `study-plan` بدهید و از پیوند `#study-plan` برای رفتن به همان بخش استفاده کنید. کلاس CSS اضافی فقط وقتی ظاهر را تغییر می‌دهد که سبک مربوط در سایت تعریف شده باشد.

## تمرین

یک گروه با تیتر، پاراگراف و تصویر بسازید. از نمای فهرست ترتیب تصویر و پاراگراف را عوض کنید. سپس گروه را تکثیر و نسخهٔ دوم را حذف کنید. معیار موفقیت: نسخهٔ اول و ترتیب محتوای آن حفظ شود.
