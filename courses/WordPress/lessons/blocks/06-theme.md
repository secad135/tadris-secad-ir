# ۱۱. بلوک‌های پوسته و محتوای پویا

[فهرست دوره](../../README.md) · [درس قبل](05-widgets-embeds.md) · [درس بعد](../06-settings.md)

هدف: شناخت بلوک‌هایی که مقدار خود را از سایت، نوشته یا فهرست نتایج دریافت می‌کنند. این فصل مرجع مقدماتی است؛ طراحی کامل قالب در مراحل بعد آموزش داده می‌شود.

## زمینهٔ نمایش چیست؟

پاراگراف معمولی متن ثابت دارد؛ «عنوان نوشته» عنوان نوشتهٔ جاری را می‌گیرد. در یک حلقهٔ چندنوشته‌ای، همان بلوک برای هر نوشته عنوان متفاوتی نمایش می‌دهد. بسیاری از بلوک‌های این فصل در ویرایشگر سایت یا داخل والد مناسب کاربرد دارند و ممکن است در بدنهٔ مقاله در دسترس نباشند.

نام‌های داخل جدول، نام نمایشی یا معادل انگلیسی رایج‌اند؛ عبارت داخل پرانتز در موارد لازم به شناسایی نام فنی کمک می‌کند.

| راهبری / Navigation | پیوندها را در ظرف راهبری قرار دهید؛ چیدمان و رفتار موبایل را بررسی کنید | فهرست اصلی؛ روی صفحهٔ کوچک باز و بسته شدن آن را آزمایش کنید |
| پیوند راهبری / Navigation Link | متن و مقصد یک مورد را مشخص کنید | پیوند «وبلاگ»؛ مقصد باید موجود باشد |

| ورود و خروج / Login/out | پیوند متناسب با وضعیت ورود بازدیدکننده نمایش دهید | با حساب واردشده و پنجرهٔ مهمان مقایسه کنید |
| بخش قالب / Template Part | بخش موجودی مانند سربرگ را انتخاب کنید | تغییر بخش مشترک ممکن است روی چند صفحه اثر بگذارد |

## اطلاعات نوشته

| بلوک | روش استفاده و تنظیم مهم | مثال و نکته |
| --- | --- | --- |
| عنوان نوشته / Post Title | در زمینهٔ نوشته قرار دهید؛ سطح تیتر و پیوند را تنظیم کنید | در کارت فهرست می‌تواند به مقاله پیوند داشته باشد |
| محتوای نوشته / Post Content | در قالب تک‌نوشته برای نمایش بدنه قرار می‌گیرد | به جای کپی دستی متن؛ در بدنهٔ همان نوشته استفادهٔ معمول ندارد |
| چکیدهٔ نوشته / Post Excerpt | گزیدهٔ مطلب را نمایش دهید؛ طول یا ادامهٔ مطلب را طبق گزینه‌ها تنظیم کنید | چکیدهٔ کارت‌ها را از نظر قطع جمله بررسی کنید |
| تصویر شاخص نوشته / Post Featured Image | اندازه، نسبت و پیوند را در صورت وجود تنظیم کنید | نبود تصویر شاخص می‌تواند کارت را بدون تصویر کند |
| تاریخ نوشته / Post Date | قالب تاریخ و در صورت پشتیبانی نوع تاریخ را تعیین کنید | تاریخ انتشار با تاریخ آخرین ویرایش فرق دارد |
| نویسندهٔ نوشته / Post Author | اطلاعات نویسنده و گزینه‌های نمایشی موجود را انتخاب کنید | ممکن است نام، تصویر یا توضیح را کنار هم نشان دهد |
| نام نویسنده / Post Author Name | فقط نام نمایشی نویسنده را بیاورید؛ پیوند را بررسی کنید | مناسب سطر اطلاعات مقاله |
| زندگی‌نامهٔ نویسنده / Post Author Biography | توضیح پروفایل نویسنده را نمایش دهید | اگر پروفایل خالی باشد، محتوای مفیدی نمایش نمی‌یابد |
| آواتار / Avatar | تصویر کاربر را در زمینهٔ مناسب نمایش دهید | اندازه را برای کارت نویسنده یا دیدگاه تنظیم کنید |
| اصطلاح‌های نوشته / Post Terms | دسته یا برچسب را انتخاب و جداکننده را تنظیم کنید | دسته‌ها را دستی در متن تکرار نکنید |
| نوشتهٔ قبلی/بعدی / Post Navigation Link | نوع قبلی یا بعدی و متن پیوند را تنظیم کنید | پیمایش بین مقاله‌ها؛ با صفحه‌بندی یک مقاله فرق دارد |
| ادامهٔ مطلب / Read More | در زمینهٔ نوشته، پیوند ورود به مطلب کامل بسازید | با بلوک More که محل قطع متن را مشخص می‌کند فرق دارد |

## حلقهٔ پرس‌وجو / Query Loop

این بلوک فهرستی از محتوا را بر اساس یک پرس‌وجو می‌سازد. بلوک را اضافه کنید، چیدمان اولیه را انتخاب و تنظیمات نوع محتوا، ترتیب، تعداد و فیلترهای موجود را بررسی کنید. در قالب بایگانی، گزینهٔ ارث‌بری پرس‌وجو تعیین می‌کند فهرست از زمینهٔ صفحه پیروی کند یا تنظیم مستقل داشته باشد.

مثال آموزشی: فهرست سه نوشتهٔ تازه با عنوان، تصویر شاخص و چکیده. ابتدا روی سایت دارای چند نوشتهٔ آزمایشی انجام دهید تا تفاوت نتایج دیده شود.

| زیر‌بلوک | کاربرد و روش بررسی |
| --- | --- |
| قالب نوشته / Post Template | ساختار کارت تکرارشونده است؛ بلوک عنوان و چکیده را داخل آن بچینید تا برای هر نتیجه تکرار شوند |
| صفحه‌بندی / Query Pagination | ظرف کنترل‌های جابه‌جایی بین صفحه‌های نتایج است؛ با تعداد نوشتهٔ بیش از ظرفیت یک صفحه آزمایش کنید |
| قبلی / Query Pagination Previous | پیوند صفحهٔ قبلی نتایج؛ در اولین صفحه ممکن است مقصد قبلی نداشته باشد |
| شماره‌ها / Query Pagination Numbers | شمارهٔ صفحه‌ها؛ تعداد صفحه از نتایج و اندازهٔ صفحه می‌آید |
| بعدی / Query Pagination Next | رفتن به صفحهٔ بعد نتایج؛ با نوشتهٔ بعدی متفاوت است |
| بدون نتیجه / Query No Results | محتوا برای حالت نتیجهٔ خالی؛ متنی مانند «مطلبی پیدا نشد» داخل آن قرار دهید |
| عنوان پرس‌وجو / Query Title | عنوان مرتبط با بایگانی یا جست‌وجو را نمایش می‌دهد؛ در زمینهٔ مربوط بررسی کنید |
| توضیح اصطلاح / Term Description | توضیح دسته یا برچسب جاری را نمایش می‌دهد؛ ابتدا توضیح آن اصطلاح را تکمیل کنید |

## بلوک‌های دیدگاه

| بلوک | کاربرد و نکتهٔ اجرا |
| --- | --- |
| دیدگاه‌ها / Comments | ظرف بخش دیدگاه؛ چیدمان زیر‌بلوک‌ها را درون آن تنظیم کنید |
| عنوان دیدگاه‌ها / Comments Title | عنوان بخش را با اطلاعات زمینهٔ نوشته نمایش می‌دهد |
| قالب دیدگاه / Comment Template | ساختاری است که برای هر دیدگاه تکرار می‌شود |
| نام نویسندهٔ دیدگاه / Comment Author Name | نام ارسال‌کننده را در زمینهٔ هر دیدگاه نمایش می‌دهد |
| محتوای دیدگاه / Comment Content | متن دیدگاه را نمایش می‌دهد؛ پاراگراف ثابت جای آن نیست |
| تاریخ دیدگاه / Comment Date | تاریخ دیدگاه را با قالب موجود نشان می‌دهد |
| پیوند ویرایش دیدگاه / Comment Edit Link | برای کاربر دارای مجوز، دسترسی به ویرایش فراهم می‌کند |
| پیوند پاسخ / Comment Reply Link | امکان رفتن به پاسخ دیدگاه را ارائه می‌کند؛ تنظیمات گفت‌وگو را هم بررسی کنید |
| صفحه‌بندی دیدگاه‌ها / Comments Pagination | ظرف کنترل‌های قبلی، شماره‌ها و بعدی برای چند صفحه دیدگاه است |
| قبلی، شماره‌ها، بعدی / Comments Pagination Previous, Numbers, Next | به‌ترتیب پیمایش عقب، انتخاب صفحه و پیمایش جلو؛ با دیدگاه‌های کافی قابل ارزیابی‌اند |
| فرم دیدگاه نوشته / Post Comments Form | فرم ارسال نظر را نمایش می‌دهد؛ بسته بودن دیدگاه یا الزام ورود روی خروجی اثر دارد |

در قالب‌های قدیمی‌تر ممکن است بلوک قدیمی «دیدگاه‌های نوشته / Post Comments» دیده شود. برای ساخت تازه، بلوک ارائه‌شده توسط ویرایشگر همان سایت را مبنا قرار دهید؛ جایگزینی قالب قدیمی را بدون بررسی خروجی انجام ندهید.

## بلوک‌های وابسته به نسخه و محیط

برخی موارد مانند «فهرست مطالب»، «زمان مطالعه»، بلوک‌های تعاملی تازه یا بلوک‌های فرم ممکن است در نسخه‌ها، افزونه‌ها یا محیط‌های خاص عرضه شوند. وجود آن‌ها را از نام یا تصویر یک آموزش نتیجه نگیرید. ابتدا نام، ارائه‌دهنده و راهنمای همان بلوک را بررسی کنید. این فصل مرجع همهٔ بلوک‌های افزونه‌ها نیست.

## تمرین

اگر سایت آزمایشی شما ویرایشگر سایت دارد، یک قالب موجود را باز کنید و فقط از نمای فهرست، عنوان نوشته، محتوای نوشته و بخش دیدگاه را شناسایی کنید. اگر این محیط در دسترس نیست، تمرین Query Loop را در یک پیش‌نویس مجاز انجام دهید. معیار موفقیت: بتوانید توضیح دهید چرا عنوان در هر کارت تغییر می‌کند، اما متن یک پاراگراف ثابت تکرار می‌شود.
