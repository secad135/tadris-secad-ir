## معرفی دوره‌ی آموزشی وردپرس وردپرس

### به دوره‌ی «توسعه‌دهنده سیستم‌های مدیریت محتوا با وردپرس» خوش آمدید!

#### این دوره برای چه کسانی است؟
این دوره برای **دانش‌آموزان پایه دوازدهم رشته کامپیوتر (شاخه کاردانش – توسعه وب)** طراحی شده است. اگر تا حالا با HTML و CSS آشنا شده‌اید و می‌خواهید یاد بگیرید چگونه یک وب‌سایت واقعی و حرفه‌ای بسازید، این دوره دقیقاً برای شماست. **هیچ نیازی به دانش قبلی وردپرس ندارید**؛ از صفر شروع می‌کنیم و قدم‌به‌قدم تا ساخت یک فروشگاه اینترنتی کامل پیش می‌رویم.

#### وردپرس چیست و چرا آن را یاد می‌گیریم؟
**وردپرس** محبوب‌ترین سیستم مدیریت محتوا (CMS) در جهان است؛ بیش از **۴۳ درصد** از کل وب‌سایت‌های دنیا با آن ساخته شده‌اند. از وبلاگ‌های شخصی گرفته تا سایت‌های خبری بزرگ و فروشگاه‌های اینترنتی، همه از وردپرس استفاده می‌کنند. دلیلش هم ساده است: **با وردپرس می‌توانید بدون نیاز به کدنویسی تخصصی، یک سایت کامل بسازید و مدیریت کنید**. این مهارت امروز یکی از پرتقاضاترین مهارت‌ها در بازار کار طراحی و توسعه وب است.

#### در این دوره چه چیزهایی یاد می‌گیرید؟

| مرحله | موضوعات |
| :--- | :--- |
| **آماده‌سازی** | آشنایی با مفاهیم پایه وب (سرور، هاست، دامنه، DNS، CMS) و راه‌اندازی محیط تمرین با **XAMPP** |
| **شروع کار** | نصب وردپرس روی لوکال‌هاست، آشنایی با پیشخوان و تنظیمات اولیه |
| **مدیریت محتوا** | ساخت نوشته‌ها، برگه‌ها، مدیریت رسانه (تصاویر) و دسته‌بندی‌ها |
| **ظاهر سایت** | نصب و تنظیم پوسته‌ها، سفارشی‌ساز، ابزارک‌ها و منوها |
| **قدرت وردپرس** | نصب و مدیریت افزونه‌ها، معرفی افزونه‌های ضروری، بهینه‌سازی و بومی‌سازی فارسی |
| **قالب‌های پیش‌فرض** | کار با قالب کلاسیک **Twenty Seventeen** و قالب بلوکی مدرن **Twenty Twenty-Five** |
| **کاربران** | مدیریت کاربران و سطوح دسترسی |
| **فروشگاه‌سازی** | نصب ووکامرس، ساخت محصول ساده و متغیر، مدیریت سفارش‌ها و گزارش‌ها |
| **امنیت** | سخت‌سازی وردپرس، رمز عبور امن، 2FA و پشتیبان‌گیری |
| **بازار ایران** | دریافت **اینماد**، اتصال درگاه پرداخت بانکی (زرین‌پال) و الزامات قانونی فروشگاه |

#### در پایان دوره چه کارهایی می‌توانید انجام دهید؟
- یک وب‌سایت شخصی یا شرکتی کامل با وردپرس بسازید و مدیریت کنید.
- نوشته، برگه، تصویر و منوهای سایت را بدون کدنویسی مدیریت کنید.
- پوسته‌ها را نصب و شخصی‌سازی کنید و ظاهر سایت را تغییر دهید.
- افزونه‌های ضروری (سئو، امنیت، فرم تماس، کش) را نصب و تنظیم کنید.
- یک **فروشگاه اینترنتی** با ووکامرس راه‌اندازی کنید و درگاه پرداخت ایرانی به آن متصل کنید.
- سایت خود را از محیط لوکال به **هاست واقعی** منتقل کنید و از آن **پشتیبان** بگیرید.
- اصول **امنیت** و **بومی‌سازی فارسی** را رعایت کنید.
- برای ورود به بازار کار یا ادامه‌ی تحصیل در رشته‌های مرتبط آماده شوید.

#### ویژگی‌های این دوره
- **پروژه‌محور:** هر جزوه با تمرین عملی همراه است و شما روی سایت خودتان کار می‌کنید.
- **زبان ساده:** مفاهیم تخصصی با زبان روان و مثال‌های قابل‌درک توضیح داده شده‌اند.
- **آزمون تستی:** در پایان هر جزوه، ۱۰ سؤال تستی برای مرور و تثبیت مطالب ارائه شده است.
- **متناسب با بازار ایران:** مباحث بومی‌سازی فارسی، درگاه پرداخت ایرانی و اینماد به طور اختصاصی پوشش داده شده است.
- **به‌روز:** مطالب با نسخه‌های جدید وردپرس (از جمله قالب بلوکی Twenty Twenty-Five) هم‌راستا هستند.
